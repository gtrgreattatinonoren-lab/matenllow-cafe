# 抹天狼 -MATENRO- Tea & Sweets Cafe

添付いただいたロゴ(赤ずきん×狼×月夜の森)の世界観をモチーフにした、カフェのホームページです。
フレームワーク不要の静的サイト(HTML / CSS / JavaScriptのみ)なので、そのままブラウザで開けば動作します。

## ファイル構成

```
matenllow-cafe/
├── index.html        ページ本体
├── css/
│   └── style.css     デザイン(色・レイアウト・アニメーション)
├── js/
│   └── main.js        メニュー切り替え・スクロール演出などの動き
├── assets/
│   └── logo.png       ← ★ 実際のロゴ画像をここに置いてください(下記参照)
└── README.md
```

## ロゴ画像の反映方法(重要)

このAIの作業環境からは、チャットに添付いただいた画像ファイルをそのまま保存することができませんでした。
そのため、いただいたロゴの構図(月・森・狼・赤ずきん・薔薇・ティーセット)を再現したイラストをCSS/SVGで自作し、
ロゴが無い状態でも見た目が崩れないようにしてあります。

実際のロゴ画像をそのまま使いたい場合は、以下の手順で反映できます。

1. お手元のロゴ画像ファイルを `logo.png` という名前にする(背景透過PNG推奨)
2. `matenllow-cafe/assets/` フォルダの中に、その `logo.png` を置く
3. `index.html` を保存し直す必要はありません。`assets/logo.png` が存在すれば自動的に、
   - ヘッダー左上のアイコン
   - トップページ中央の紋章(エンブレム)
   の部分に実際のロゴ画像が表示されます(画像が無い間は自作イラストが代わりに表示され続けます)。

VSCodeでの置き方:
- 左側のエクスプローラーで `assets` フォルダを右クリック → 「ここにファイルをドラッグ&ドロップ」でもOKです。

GitHubのWeb画面から置く場合:
- リポジトリの `assets` フォルダを開く → 「Add file」→「Upload files」→ `logo.png` をアップロード → Commit

## 動作確認方法(パソコンで見る)

ファイルをダブルクリックするだけでも表示はされますが、フォントや一部の機能を正しく確認したい場合は
簡易サーバーを立てるのがおすすめです。

VSCodeを使っている場合:
1. 拡張機能「Live Server」をインストール
2. `index.html` を右クリック →「Open with Live Server」

またはターミナルで(Pythonが入っている場合):
```
cd matenllow-cafe
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開く。

## 中身を書き換えたいとき

- **お店の文章・メニュー・料金・住所・営業時間**: `index.html` の中の日本語部分を直接書き換えてください。
  (例: `〒000-0000 ○○県○○市○○町0-0-0` の部分を実際の住所に変更)
- **色味**: `css/style.css` の一番上、`:root{ ... }` の中にある色の変数(`--wine`, `--gold`, `--cream` など)を
  変更すると、サイト全体の配色が一括で変わります。
- **地図**: `access-map` セクション(`index.html` 内、`id="access"` の中)に、Googleマップの
  「共有 > 地図を埋め込む」で取得した `<iframe>` コードを貼り付けると実際の地図に差し替えられます。

## エラーが出たときの考え方(初心者向け)

- 画面が真っ白 / 崩れる → まずブラウザの開発者ツール(F12)の「Console」タブを見て、赤字のエラーを確認してください。
  - `Failed to load resource` と出ている場合は、ファイルパスのタイプミス(大文字小文字の違いなど)が多いです。
- ロゴが表示されない → `assets/logo.png` という名前・場所になっているか、拡張子が `.png` になっているかを確認してください。
- スマホ表示が崩れる → `css/style.css` 内の `@media (max-width: ...)` の範囲を調整してください。
