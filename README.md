# 抹天狼 -MATENRO- Tea & Sweets Cafe

添付いただいたロゴ(赤ずきん×狼×月夜の森)の世界観をモチーフにした、カフェのホームページです。
フレームワーク不要の静的サイト(HTML / CSS / JavaScriptのみ)なので、そのままブラウザで開けば動作します。

## ファイル構成

```
matenllow-cafe/
├── index.html        ページ本体
├── css/
│   └── style.css     デザイン(色・レイアウト・アニメーション)
├── js/
│   ├── main.js         メニュー切り替え・スクロール演出などの動き
│   └── sheet-data.js   Googleスプレッドシートの内容を読み込んでサイトに反映する
├── assets/
│   └── logo.png       ← ★ 実際のロゴ画像をここに置いてください(下記参照)
└── README.md
```

## ロゴ画像の反映方法(重要)

このAIの作業環境からは、チャットに添付いただいた画像ファイルをそのまま保存することができませんでした。
そのため、いただいたロゴの構図(月・森・狼・赤ずきん・薔薇・ティーセット)を再現したイラストをCSS/SVGで自作し、
ロゴが無い状態でも見た目が崩れないようにしてあります。

実際のロゴ画像をそのまま使いたい場合は、以下の手順で反映できます。

1. お手元のロゴ画像ファイルを `logo.png` という名前にする(背景透過PNG推奨)
2. `matenllow-cafe/assets/` フォルダの中に、その `logo.png` を置く
3. `index.html` を保存し直す必要はありません。`assets/logo.png` が存在すれば自動的に、
   - ヘッダー左上のアイコン
   - トップページ中央の紋章(エンブレム)
   の部分に実際のロゴ画像が表示されます(画像が無い間は自作イラストが代わりに表示され続けます)。

VSCodeでの置き方:
- 左側のエクスプローラーで `assets` フォルダを右クリック → 「ここにファイルをドラッグ&ドロップ」でもOKです。

GitHubのWeb画面から置く場合:
- リポジトリの `assets` フォルダを開く → 「Add file」→「Upload files」→ `logo.png` をアップロード → Commit

## 動作確認方法(パソコンで見る)

ファイルをダブルクリックするだけでも表示はされますが、フォントや一部の機能を正しく確認したい場合は
簡易サーバーを立てるのがおすすめです。

VSCodeを使っている場合:
1. 拡張機能「Live Server」をインストール
2. `index.html` を右クリック →「Open with Live Server」

またはターミナルで(Pythonが入っている場合):
```
cd matenllow-cafe
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開く。

## 中身を書き換えたいとき

- **住所・営業時間・電話番号・メニュー・見出しや本文、お客様の声など**: 下記「スプレッドシートで中身を管理する」を
  参照してください。コードを触らずに、Googleスプレッドシートを編集するだけで反映されます。
- **色味**: `css/style.css` の一番上、`:root{ ... }` の中にある色の変数(`--wine`, `--gold`, `--cream` など)を
  変更すると、サイト全体の配色が一括で変わります。
- **地図**: `access-map` セクション(`index.html` 内、`id="access"` の中)に、Googleマップの
  「共有 > 地図を埋め込む」で取得した `<iframe>` コードを貼り付けると実際の地図に差し替えられます。
- **写真・ロゴ**: `assets/` フォルダの画像を同じファイル名で差し替えれば、それだけで反映されます。

## スプレッドシートで中身を管理する(重要・要設定)

住所・営業時間・メニューに加えて、見出しや紹介文、お客様の声、ギャラリーの説明文まで、
サイトのほぼすべての文字情報は3つのGoogleスプレッドシートから自動的に読み込まれる仕組みになっています。
スプレッドシートを編集して保存するだけで、サイト側は**コードを一切触らずに**内容が更新されます
(ページを再読み込みしたタイミングで反映されます)。

- 店舗情報シート: https://docs.google.com/spreadsheets/d/1PNuc2e-PoYrmZ3a3JEbBDPVqXBBGOOY7Ibj0-UIiCHQ/edit
  - `key` 列は変更しないでください。`value` 列だけを書き換えます。
  - 住所は `郵便番号` と `住所` の2行に分かれています。
- サイト文言シート: https://docs.google.com/spreadsheets/d/1XKFs5faHGa-t2X3AhGIUbDHfvvT-FqiwDziS42yDO2Q/edit
  - `key` 列は変更しないでください。`value` 列だけを書き換えます。
  - ヒーローの見出し・物語セクションの本文・メニューの見出し/注記・ギャラリーの見出しとキャプション5つ・
    お客様の声(見出し+3件分の感想と属性)・アクセスの見出し、が含まれます。
  - セル内で改行したい場合は、そのセルの中で **Shift + Enter** を押すと、サイト上でも改行されます。
- メニューシート: https://docs.google.com/spreadsheets/d/11cEjHiagWheVKINwyapnzW0RxTal7Pv-LyiU5ozSPZ8/edit
  - 列は `category(タブの名前), name(商品名), price(税込価格・数字のみ), unit(「/ 1名」のような補足・空欄可), note(説明文)` です。
  - `category` の値ごとに、メニューのタブが自動的に作られます。新しいカテゴリ名を書けばタブが増え、
    行を削除すればその商品は消えます。並び順はシート内の行の順番がそのまま使われます。

### 最初に1回だけ必要な設定(これをしないと反映されません)

サイトはログインなしで誰でも見られる必要があるため、3つのスプレッドシートすべてを
「リンクを知っている人は誰でも閲覧できる」設定にする必要があります。
共有相手が具体的な内容を編集できるわけではなく、**閲覧のみ**です。

1. 上記のスプレッドシートを開く
2. 右上の「共有」ボタンをクリック
3. 「一般的なアクセス」を「制限付き」→「リンクを知っている全員」に変更
4. 権限は「閲覧者」のままでOK(「完了」を押す)
5. **店舗情報シート・サイト文言シート・メニューシートの3つすべて**で同じ設定をする

これで、シートを保存し直すだけで実際のサイトにも反映されるようになります。
(設定前や、通信できない環境では、`index.html` に書かれている初期表示の内容がそのまま表示されます。サイトが壊れることはありません。)

## エラーが出たときの考え方(初心者向け)

- 画面が真っ白 / 崩れる → まずブラウザの開発者ツール(F12)の「Console」タブを見て、赤字のエラーを確認してください。
  - `Failed to load resource` と出ている場合は、ファイルパスのタイプミス(大文字小文字の違いなど)が多いです。
- ロゴが表示されない → `assets/logo.png` という名前・場所になっているか、拡張子が `.png` になっているかを確認してください。
- スマホ表示が崩れる → `css/style.css` 内の `@media (max-width: ...)` の範囲を調整してください。
