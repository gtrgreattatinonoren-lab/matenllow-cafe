# 資格対策 教科書（5冊）

日本安全食料料理協会（JSFCA）の次の資格試験に向けた、独自の学習テキストです（協会の公式教材ではありません）。

| ファイル | 内容 |
|---|---|
| `pdf/00_5資格まとめ_教科書.pdf` | 5冊をまとめた1冊（しおり付き） |
| `pdf/01_日本茶セレクター_教科書.pdf` | 日本茶セレクター |
| `pdf/02_手作りパンソムリエ_教科書.pdf` | 手作りパンソムリエ |
| `pdf/03_製菓アドバイザー_教科書.pdf` | 製菓アドバイザー |
| `pdf/04_カップケーキソムリエ_教科書.pdf` | カップケーキソムリエ |
| `pdf/05_コーヒーソムリエ_教科書.pdf` | コーヒーソムリエ |

各冊の構成：試験概要 → 出題範囲ごとの章（「ここを覚える」まとめ付き）→ 練習問題（記述10問＋○×10問）→ 解答と解説 → 用語集。A4縦で印刷できます。

## 原稿を直してPDFを作り直す

原稿は `src/*.md`（Markdown）です。

```bash
pip install markdown pypdf
python3 build.py      # src/*.md → build/*.html
node build_pdf.js     # build/*.html → pdf/*.pdf（Playwright + Chromium が必要）
```

試験の日程・受験料・出題形式は変わることがあります。受験前に必ず協会の公式サイトで確認してください。
