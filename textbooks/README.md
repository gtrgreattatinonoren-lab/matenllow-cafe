各冊の構成：試験概要と勉強の進め方 → 出題範囲ごとの章（「ここを覚える」まとめ付き）→ 模擬試験3回分（各回 記述10問＋○×10問）→ 解答と解説 → 付録（年表・用語集・精査メモと参考情報）。A4縦で印刷できます。

第2版では、統計・制度・試験日程などを2026年10月時点の情報で確認し直し、第1版の古い情報を訂正しました（各冊の「精査メモ」に訂正一覧があります）。

## 原稿を直してPDFを作り直す

原稿は `src/*.md`（Markdown）です。

```bash
pip install markdown pypdf
python3 build.py      # src/*.md → build/*.html
node build_pdf.js     # build/*.html → pdf/*.pdf（Playwright + Chromium が必要）
```

試験の日程・受験料・出題形式は変わることがあります。受験前に必ず協会の公式サイトで確認してください。
