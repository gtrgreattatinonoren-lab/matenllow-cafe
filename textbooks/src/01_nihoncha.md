# 第1章 日本茶の歴史

## 1-1 お茶はどこから来たのか

お茶の原産地は、中国南西部（雲南省あたり）からその周辺地域と考えられています。中国では古くから薬として、のちに嗜好品として飲まれました。唐の時代（8世紀）には陸羽（りくう）が世界最古の茶の専門書といわれる『茶経（ちゃきょう）』を書いています。

## 1-2 奈良・平安時代 ── 遣唐使と僧侶が伝えた

- 日本へは、遣唐使や留学僧が中国から持ち帰ったと考えられています。
- 文献で確認できる古い記録として、『日本後紀』に **815年（弘仁6年）、僧の永忠（えいちゅう）が嵯峨天皇に茶を煎じて差し上げた** という記述があります。
- 最澄（さいちょう）や空海（くうかい）が茶の種を持ち帰ったという話も伝わっていますが、はっきりした証拠は少なく「伝承」として扱われます。
- この時代のお茶は、固めた茶（団茶）を砕いて煮出すもので、貴族や僧侶など一部の人だけのものでした。

## 1-3 鎌倉時代 ── 栄西と『喫茶養生記』

- **栄西（えいさい／ようさい）** は臨済宗を日本に伝えた僧で、1191年に宋から帰国した際に茶の種と、抹茶のように粉にした茶を湯に点（た）てて飲む方法を伝えたとされます。
- 栄西は **『喫茶養生記（きっさようじょうき）』** を著し、お茶が体に良いことを説きました。1214年には二日酔いに苦しむ将軍・源実朝に茶とこの書を献上したと『吾妻鏡』に記されています。
- **明恵上人（みょうえしょうにん）** は栄西から茶の種を譲り受け、京都・栂尾（とがのお）の高山寺に植えたと伝えられます。栂尾の茶は「本茶」、それ以外は「非茶」と呼ばれ、茶の産地を当てる遊び **「闘茶（とうちゃ）」** も流行しました。

## 1-4 室町〜安土桃山時代 ── 茶の湯の成立

- 足利将軍家では、中国から渡った高価な道具（**唐物（からもの）**）を飾り、豪華な茶会が開かれました。
- **村田珠光（むらたじゅこう）** は、豪華さよりも簡素さと心を重んじる **「侘び茶（わびちゃ）」** の祖とされます。
- **武野紹鴎（たけのじょうおう）** が侘び茶を発展させ、その弟子の **千利休（せんのりきゅう）** が茶の湯を大成しました。
- 利休の考えは、のちに **表千家・裏千家・武者小路千家（三千家）** に受け継がれています。

## 1-5 江戸時代 ── 煎茶の誕生と庶民への広がり

- 1654年に来日した中国の僧 **隠元（いんげん）** は、茶葉に湯を注いで飲む方法（淹茶法）を伝えたとされ、のちに **煎茶道の祖** とされました。
- **売茶翁（ばいさおう）** は京都で煎茶を売り歩き、煎茶文化を広めました。
- **1738年、宇治田原の永谷宗円（ながたにそうえん）** が、蒸した茶葉を揉みながら乾かす **「青製煎茶製法（宇治製法）」** を考案しました。色・香り・味の良い煎茶が作れるようになり、これが現在の煎茶製法の基礎になっています。
- **玉露** は江戸時代後期（1830年代ごろ）に生まれたとされます。山本山の六代目・山本嘉兵衛が考案したという説が知られていますが、諸説あります。

## 1-6 明治以降 ── 輸出品から日常の飲み物へ

- 幕末から明治にかけて、お茶は生糸と並ぶ重要な輸出品でした。
- 明治維新で職を失った旧幕臣などが、静岡県の **牧之原台地** を開墾して茶園を作りました。
- 大正・昭和にかけて機械による製茶が広がり、お茶は家庭の日常的な飲み物になりました。1980年代以降は缶やペットボトルの緑茶飲料が普及しています。

## 1-7 日本茶と仏教の関係

お茶の歴史は、仏教（特に禅宗）と深く結びついています。

| 人物・言葉 | 仏教との関わり |
|---|---|
| 永忠 | 唐で学んだ僧。嵯峨天皇に茶を献上した記録が残る |
| 栄西 | 臨済宗を伝えた禅僧。抹茶の飲み方と『喫茶養生記』 |
| 明恵 | 華厳宗の僧。栂尾・高山寺で茶を栽培したと伝わる |
| 叡尊（えいそん） | 奈良・西大寺の僧。大きな茶碗で茶をふるまう「大茶盛（おおちゃもり）」の由来とされる |
| 茶礼（されい） | 禅寺で修行の一部として茶を飲む作法 |
| 茶禅一味（ちゃぜんいちみ） | 茶の湯と禅の精神は同じであるという考え方 |
| 一休宗純 | 村田珠光が一休に参禅したと伝えられる |

禅寺ではお茶が **眠気覚まし** として修行に役立ち、また **心を落ち着ける作法** として重んじられました。これが茶の湯の精神（**和敬清寂（わけいせいじゃく）**、**一期一会（いちごいちえ）** など）にもつながっています。

> **ここを覚える**
> - 815年 永忠が嵯峨天皇に献茶（文献上の古い記録）
> - 栄西＝臨済宗・『喫茶養生記』・抹茶の飲み方
> - 明恵＝栂尾高山寺・本茶と非茶・闘茶
> - 珠光（侘び茶の祖）→ 紹鴎 → 利休（大成）→ 三千家
> - 1738年 永谷宗円の青製煎茶製法　／　隠元＝煎茶道の祖

# 第2章 茶の木と栽培

## 2-1 茶の木の基本

- 学名は **カメリア・シネンシス（Camellia sinensis）**。**ツバキ科ツバキ属** の常緑樹です。
- 緑茶・紅茶・ウーロン茶は、どれも **同じ茶の木の葉** から作られます。違いは **製法（発酵の度合い）** です。
- 大きく分けて、葉が小さく寒さに強い **中国種**（日本の緑茶のほとんど）と、葉が大きく暑い地域に向く **アッサム種**（紅茶向き）があります。

| お茶の種類 | 発酵（酸化）の度合い | 例 |
|---|---|---|
| 不発酵茶 | 摘んですぐ加熱して酵素の働きを止める | 緑茶（煎茶・玉露など） |
| 半発酵茶 | 途中まで酸化させる | ウーロン茶、包種茶 |
| 発酵茶 | しっかり酸化させる | 紅茶 |
| 後発酵茶 | 加熱後に微生物で発酵させる | プーアル茶、碁石茶 |

※お茶の「発酵」は、多くの場合、微生物ではなく茶葉の中の酵素による **酸化** のことです（後発酵茶を除く）。

## 2-2 主な品種

| 品種 | 特徴 |
|---|---|
| やぶきた | 静岡の杉山彦三郎が選抜した品種。香り・味のバランスが良く、日本の茶園面積の約7割前後を占める代表品種（近年は割合が下がりつつある） |
| さえみどり | 鮮やかな緑色、渋みが少なく旨味が強い |
| おくみどり | 晩生（おくて）品種。すっきりした味 |
| ゆたかみどり | 鹿児島で多く栽培。深蒸しやかぶせ茶向き |
| あさつゆ | 「天然玉露」と呼ばれるほど旨味が強い |
| つゆひかり | 明るい水色と爽やかな香り |
| さやまかおり | 埼玉（狭山）生まれ。香りが強い |
| べにふうき | 紅茶・半発酵茶向き。メチル化カテキンを多く含む |

## 2-3 主な産地

| 産地 | 代表的な銘柄・特徴 |
|---|---|
| 静岡県 | 日本を代表する大産地。本山茶、川根茶、掛川茶など。牧之原台地は深蒸し煎茶で有名 |
| 鹿児島県 | 静岡と並ぶ大産地。知覧茶など。近年は生産量で静岡を上回る年もある |
| 三重県 | 伊勢茶。かぶせ茶の生産が多い |
| 京都府 | 宇治茶。玉露・抹茶（碾茶）の高級茶で有名 |
| 福岡県 | 八女茶。玉露の産地として有名 |
| 埼玉県 | 狭山茶。「狭山火入れ」と呼ばれる強めの火入れ |
| 佐賀県・長崎県 | 嬉野茶、そのぎ茶。玉緑茶・釜炒り茶 |
| 宮崎県 | 釜炒り茶（高千穂・五ヶ瀬など） |

「**色は静岡、香りは宇治よ、味は狭山でとどめさす**」という言葉があり、静岡・宇治・狭山は **日本三大銘茶** と呼ばれることがあります。

## 2-4 栽培方法 ── 「露天」と「被覆（ひふく）」

| 栽培方法 | 内容 | 主なお茶 |
|---|---|---|
| 露天栽培 | 日光を当てて育てる | 煎茶、番茶 |
| 被覆栽培（短期） | 摘む前に約1週間前後、覆いをかける | かぶせ茶 |
| 被覆栽培（長期） | 摘む前に約20日以上、覆いをかけて光をさえぎる | 玉露、碾茶（抹茶の原料） |

**なぜ覆いをかけるのか**　茶葉の旨味成分 **テアニン** は、日光を浴びると渋み成分 **カテキン** に変わっていきます。光をさえぎるとテアニンが多く残り、**旨味が強く渋みが少ない** お茶になります。被覆したお茶には、青のりのような独特の香り（**覆い香（おおいか）**）があります。

## 2-5 茶摘みの時期

| 呼び名 | 時期（目安） | 特徴 |
|---|---|---|
| 一番茶（新茶） | 4月下旬〜5月 | 冬の間に蓄えた養分で旨味が豊富。最も品質が高いとされる |
| 二番茶 | 6月〜7月 | 一番茶の後に伸びた芽。カテキンがやや多く渋みが出やすい |
| 三番茶 | 7月〜8月 | 主に番茶や飲料用 |
| 秋冬番茶 | 9月〜10月ごろ | 番茶やほうじ茶の原料 |

- **八十八夜** は立春から数えて88日目（毎年5月2日ごろ）。この時期に摘んだお茶は縁起が良いとされます。
- 時期は地域によって違い、鹿児島など南の産地は早く、北の産地は遅くなります。
- 摘み方には手摘み（高級茶）と機械摘み（乗用型・可搬型摘採機）があります。

> **ここを覚える**
> - 茶の木＝カメリア・シネンシス（ツバキ科）。緑茶・紅茶・ウーロン茶は同じ木
> - 代表品種はやぶきた（杉山彦三郎）
> - 被覆栽培でテアニンが残る → 旨味が強い（玉露は約20日以上、かぶせ茶は約1週間）
> - 一番茶（新茶）＝4月下旬〜5月／八十八夜＝5月2日ごろ

# 第3章 日本茶の種類と製法

## 3-1 製法の流れ

日本茶は、まず生産地で **荒茶（あらちゃ）** という半製品に加工され、その後、茶問屋などで **仕上げ茶** になります。

**荒茶の工程（煎茶の場合）**

1. **蒸熱（じょうねつ）** ── 摘んだ葉をすぐに蒸して、酸化（発酵）を止める
2. **冷却** ── 蒸した葉を冷まし、表面の水分を取る
3. **粗揉（そじゅう）** ── 熱風を当てながら揉んで乾かす
4. **揉捻（じゅうねん）** ── 力を加えて揉み、水分を均一にする
5. **中揉（ちゅうじゅう）** ── もう一度熱風の中で揉む
6. **精揉（せいじゅう）** ── 形を細くまっすぐに整える
7. **乾燥** ── 水分を5％程度まで乾かす

**仕上げの工程**

- **選別** ── ふるいや風を使って、大きさや形をそろえ、茎・粉・芽を分ける
- **火入れ（ひいれ）** ── 加熱して香りを引き出し、保存性を高める
- **合組（ごうぐみ）** ── 複数の茶葉をブレンドして、味と品質を安定させる

## 3-2 主な日本茶の種類

| 種類 | 作り方の特徴 | 味・香り |
|---|---|---|
| 煎茶 | 露天栽培の葉を蒸して揉んで乾燥。日本で最も多く飲まれる | 爽やかな香りと、旨味・渋みのバランス |
| 深蒸し煎茶 | 蒸し時間を普通の煎茶の約2〜3倍にする | 水色は濃い緑、渋みが少なくまろやか。茶葉は細かい |
| 玉露 | 約20日以上被覆した新芽を使う | 強い旨味と甘み、覆い香 |
| かぶせ茶 | 約1週間被覆 | 煎茶と玉露の中間 |
| 碾茶（てんちゃ） | 被覆した葉を揉まずに乾燥させる | 抹茶の原料 |
| 抹茶 | 碾茶を石臼などで細かく挽く | 茶葉を丸ごと飲む。茶道で使う |
| 番茶 | 硬くなった葉や遅い時期の葉で作る | あっさりした味。地域ごとに定義が違う |
| ほうじ茶 | 番茶や煎茶を強火で焙じる | 香ばしい香り、苦み・渋みが少ない。カフェインも比較的少なめ |
| 玄米茶 | 番茶や煎茶に炒った玄米を混ぜる | 香ばしくあっさり |
| 茎茶（棒茶） | 仕上げで分けた茎を集める | すっきりとした甘み。玉露の茎茶は「雁ヶ音（かりがね）」 |
| 芽茶 | 芽の先の丸まった部分を集める | 濃厚な味 |
| 粉茶 | 仕上げで出た細かい粉を集める | 短時間で濃く出る。寿司店の「あがり」 |
| 玉緑茶（ぐり茶） | 精揉をせず、勾玉のような丸い形に仕上げる | まろやか。佐賀・長崎などで多い |
| 釜炒り茶 | 蒸さずに釜で炒って酸化を止める | 「釜香（かまか）」と呼ばれる香ばしい香り。佐賀・宮崎など |

> **ポイント**　「蒸す」か「炒る」かが大きな違いです。日本の緑茶の多くは **蒸し製**、中国の緑茶の多くは **釜炒り製** です。

## 3-3 お茶の成分と味

| 成分 | 味 | 特徴 |
|---|---|---|
| カテキン（タンニンの一種） | 渋み | 日光を浴びると増える。高温の湯でよく溶け出す |
| カフェイン | 苦み | 高温の湯でよく溶け出す |
| テアニン（アミノ酸） | 旨味・甘み | 低めの温度でもよく溶け出す。被覆で多く残る |
| ビタミンC | ── | 緑茶に多い（蒸して作るため壊れにくい） |

**湯の温度で味が変わる理由**　低い温度では旨味（テアニン）が先に出て、渋み（カテキン）や苦み（カフェイン）は出にくくなります。だから **玉露はぬるめ**、**番茶やほうじ茶は熱湯** で淹れます。

> **ここを覚える**
> - 荒茶：蒸熱 → 冷却 → 粗揉 → 揉捻 → 中揉 → 精揉 → 乾燥
> - 仕上げ：選別・火入れ・合組
> - 深蒸し＝蒸し時間が約2〜3倍／碾茶＝揉まない／抹茶＝碾茶を挽く
> - 渋み＝カテキン、苦み＝カフェイン、旨味＝テアニン

# 第4章 淹れ方の基本と注意点

## 4-1 お茶ごとの淹れ方の目安

下の表は一般的な目安（一例）です。茶葉の品質や好みで調整してください。

| お茶 | 湯の温度 | 浸出時間 | 茶葉と湯の量（目安） |
|---|---|---|---|
| 玉露（上級） | 50〜60℃ | 約2分〜2分30秒 | 茶葉10g／湯60ml（3人分） |
| 上級煎茶 | 70〜80℃ | 約1分〜2分 | 茶葉6g／湯170ml（3人分） |
| 中級煎茶 | 80〜90℃ | 約1分 | 茶葉10g／湯430ml（5人分） |
| 深蒸し煎茶 | 70〜80℃ | 約30秒〜1分（短め） | 煎茶と同程度 |
| 番茶・ほうじ茶・玄米茶 | 熱湯（約95℃以上） | 約30秒 | 茶葉15g／湯650ml（5人分） |
| 抹茶（薄茶） | 約80℃ | ── | 抹茶約2g／湯約60〜70ml |

## 4-2 おいしく淹れる手順（煎茶）

1. 湯を沸かす（水道水は **沸騰後に数分沸かし続ける** とカルキ臭が抜ける）
2. 湯を湯のみに注いで、**器を温めながら湯を冷ます**
3. 急須に茶葉を入れる
4. 湯のみの湯を急須に注ぎ、ふたをして待つ（蒸らす）
5. 少しずつ順番に注ぎ分け、**濃さを均一にする（廻し注ぎ）**
6. **最後の一滴まで注ぎ切る**（最後の一滴に旨味が詰まっているとされる）

- 湯を別の器に1回移すごとに、温度は **約5〜10℃** 下がるのが目安です。
- 最後まで注ぎ切ると、2煎目もおいしく淹れられます。2煎目は **少し高めの温度で短め** が基本です。

## 4-3 水の選び方

- 日本茶には **軟水** が向いています。日本の水道水の多くは軟水です。
- 硬度の高い水（硬水）は、お茶の香りや味が出にくく、水色が濁りやすくなります。
- 浄水器を通した水や、軟水のミネラルウォーターもおすすめです。
- 汲み置きの水や、一度沸かした湯を何度も沸かし直すのは避けます。

## 4-4 そのほかの淹れ方

| 淹れ方 | 方法 | 特徴 |
|---|---|---|
| 水出し | 茶葉を水に入れて冷蔵庫で数時間 | 渋み・苦みが少なく、旨味と甘みが出る |
| 氷出し | 茶葉に氷をのせ、溶けるのを待つ | 濃厚な旨味。玉露で行うことも |
| 冷茶（急冷） | 濃いめに淹れたお茶を氷に注ぐ | 香りが立ちやすい |

## 4-5 よくある失敗と原因

| 失敗 | 主な原因 | 直し方 |
|---|---|---|
| 渋すぎる・苦すぎる | 湯の温度が高い、時間が長い | 湯を冷ます、時間を短く |
| 味が薄い | 茶葉が少ない、時間が短い、温度が低すぎる | 量・時間を見直す |
| 湯のみごとに濃さが違う | 1杯ずつ注ぎ切っている | 廻し注ぎをする |
| 2煎目がおいしくない | 1煎目で湯が残った | 最後の一滴まで注ぎ切る |

> **ここを覚える**
> - 玉露＝低温（50〜60℃）でじっくり、番茶・ほうじ茶＝熱湯で短く
> - 器に移すと約5〜10℃下がる／最後の一滴まで注ぎ切る
> - 日本茶には軟水

# 第6章 茶道具の正しい手入れ

## 6-1 急須

- 使ったらすぐに茶殻を捨て、**水かぬるま湯ですすぐ**。
- **洗剤は基本的に使わない**（素焼きに近い急須は洗剤のにおいを吸ってしまうため）。
- 茶こしの目詰まりは、柔らかいブラシや歯ブラシで取る。ひどい場合は **重曹を溶かしたぬるま湯** につけ置きする。
- ふたを外し、**よく乾かしてから** しまう（湿ったままだとカビやにおいの原因）。

## 6-2 湯のみ・茶碗（陶器）

- 陶器は水を吸いやすいので、**使う前に水かぬるま湯にくぐらせる** と、茶渋やシミがつきにくくなります。
- 茶渋は、重曹や **酸素系漂白剤** で落とせます。金彩・銀彩のある器や、貫入（かんにゅう：表面の細かいひび模様）のある器は、漂白剤を避けるのが無難です。
- 乾燥させてからしまいます。

## 6-3 茶筅

- 使い終わったら **ぬるま湯で穂先を振り洗い** する（洗剤は使わない）。
- **茶筅立て（くせ直し）** に立てて、形を整えながら陰干しする。
- 直射日光や高温の場所は避ける（割れや変形の原因）。
- 茶筅は消耗品です。穂先が折れてきたら交換します。

## 6-4 そのほかの道具

- **茶杓** ── 乾いた布でふく。水洗いは避ける。
- **棗（漆器）** ── 柔らかい布でから拭き。直射日光や乾燥に注意。
- **鉄瓶** ── 使った後は湯を捨て、余熱で中を乾かす。内側をこすらない（湯垢が錆を防ぐ）。

> **ここを覚える**
> - 急須は洗剤を使わず、よく乾かす
> - 陶器の器は使う前に水にくぐらせる
> - 茶筅はぬるま湯で振り洗い → 茶筅立てで陰干し

# 第7章 良質なお茶の見分け方と値段の相場

## 7-1 良いお茶の見分け方

お茶の品質は、プロの審査（**官能審査**）では主に次の点で判断します。

| 見るところ | 良いお茶の特徴（煎茶の場合） |
|---|---|
| 形状（外観） | 細くよく撚れて（よれて）いて、色が濃い緑でつやがある。粉や茎が少ない |
| 香気（香り） | 新鮮で爽やか。こげ臭・湿気臭などの異臭がない |
| 水色（すいしょく） | 澄んでいて、透明感のある黄緑〜緑色（深蒸しは濃い緑でやや濁るのが特徴） |
| 滋味（じみ） | 旨味・甘み・渋みのバランスが良く、後味がすっきり |

- 茶葉を手に取って、**重みがあり、乾燥していてパリッとしている** ものは良い状態です。
- 赤っぽい茶葉や、色がくすんだ茶葉は、古いか保存状態が悪い可能性があります。

## 7-2 値段の相場（目安）

お茶の値段は、品種・産地・摘んだ時期・栽培方法・手間によって大きく変わります。下の表は **一般的な小売価格の目安（推測を含む）** で、実際の価格は店や年によって大きく違います。

| 種類 | 100gあたりの目安 |
|---|---|
| 番茶・ほうじ茶・玄米茶 | 数百円〜1,000円前後 |
| 煎茶（日常用） | 500円〜1,500円前後 |
| 煎茶（上級・新茶） | 1,500円〜3,000円以上 |
| 玉露 | 2,000円〜数千円以上 |
| 抹茶 | 30gで1,000円〜数千円（用途で大きく違う） |

**値段が高くなる理由**

- 一番茶（新茶）は量が少なく品質が高い
- 被覆栽培（玉露・碾茶）は手間とコストがかかる
- 手摘みは機械摘みより手間がかかる
- 品評会で評価された茶園や、限られた産地のもの

## 7-3 保存方法

お茶の大敵は **「高温」「湿気」「光」「酸素」「におい（移り香）」** の5つです。

- **未開封** ── 冷蔵庫や冷凍庫での保存も可能。
- **冷蔵庫から出したら** ── 袋を開ける前に **常温に戻す**（すぐに開けると結露して湿気る）。
- **開封後** ── 茶筒など密閉できる容器に入れ、常温の冷暗所で保存し、なるべく早く（2週間〜1か月程度を目安に）飲み切る。
- 茶葉は **においを吸いやすい** ので、香りの強い食品の近くに置かない。

> **ここを覚える**
> - 審査の4項目：形状・香気・水色・滋味
> - 保存の大敵：高温・湿気・光・酸素・移り香
> - 冷蔵保存したら常温に戻してから開封
