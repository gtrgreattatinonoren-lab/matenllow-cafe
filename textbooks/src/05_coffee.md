# 第1章 コーヒーの歴史

## 1-1 コーヒーの発見（伝説）

- コーヒーの木（アラビカ種）の原産地は、**エチオピア** とされています。
- **ヤギ飼いカルディの伝説** ── エチオピアのヤギ飼いカルディが、赤い実を食べたヤギが興奮して跳ね回るのを見て、コーヒーの実を発見したという話。
- **僧侶シーク・オマールの伝説** ── イエメンのモカで、追放された僧侶オマールが鳥のついばむ実を煮て飲み、元気を取り戻したという話。
- どちらも **伝説** で、史実として確かめられたものではありません。

## 1-2 イスラム世界から世界へ

| 時代 | 出来事 |
|---|---|
| 15世紀ごろ | イエメンで、イスラム教の修行者（スーフィー）が夜の祈りの眠気覚ましにコーヒーを飲んでいたとされる |
| 16世紀 | メッカ、カイロ、イスタンブールへ広まる。1554年ごろにイスタンブールに **コーヒーハウス** が開かれたとされる |
| 17世紀 | ヨーロッパへ。イギリス（オックスフォード、ロンドン）、フランス（パリの「カフェ・プロコープ」1686年ごろ）、ウィーンにコーヒーハウスが生まれる。ロンドンのコーヒーハウスからは、保険の「ロイズ」が生まれた |
| 17世紀末〜18世紀 | オランダがジャワ島（インドネシア）で栽培を始める。フランスの海軍士官 **ガブリエル・ド・クリュー** が苗木をカリブ海のマルティニーク島に運んだという話が有名 |
| 1727年ごろ | ブラジルにコーヒーが伝わる。のちに世界最大の生産国になる |

**モカの由来**　イエメンの **モカ港** から積み出されたコーヒーを「モカ」と呼んだのが始まりです。現在はイエメンやエチオピアのコーヒーの名前として使われています。

## 1-3 日本のコーヒーの歴史

| 年代 | 出来事 |
|---|---|
| 江戸時代 | 長崎の **出島** でオランダ人が飲んでいたとされる |
| 1804年 | 文人・**大田南畝（蜀山人）** が、オランダ船でコーヒーを飲み、「焦げくさくて味わうに堪えない」という感想を書き残した（日本人による古い飲用記録の一つ） |
| 1888年 | 東京・上野（下谷黒門町）に、**鄭永慶（てい えいけい）** が日本初の本格的な喫茶店とされる **「可否茶館（かひいさかん）」** を開いた |
| 1901年 | アメリカで日本人の **加藤サトリ** がインスタントコーヒーの技術を発表したとされる |
| 1911年 | 銀座に「カフェー・プランタン」「カフェーパウリスタ」などが開店 |
| 1969年 | **UCC上島珈琲** がミルク入り缶コーヒーを発売（世界初の缶コーヒーとされることが多いが、それ以前の商品をあげる説もある） |
| 1983年 | 全日本コーヒー協会が **10月1日を「コーヒーの日」** に制定（国際コーヒー機関（ICO）は2015年から10月1日を「国際コーヒーの日」としている） |

> **ここを覚える**
> - 原産地＝エチオピア／カルディの伝説（伝説であり史実ではない）
> - モカ＝イエメンのモカ港が由来
> - 日本初の本格的な喫茶店＝可否茶館（1888年、鄭永慶）
> - 10月1日＝コーヒーの日

# 第2章 コーヒーの木と豆の種類

## 2-1 コーヒーの木

- **アカネ科コフィア（コーヒーノキ）属** の常緑樹です。
- 白い花が咲き、その後に **コーヒーチェリー** と呼ばれる赤い実（黄色の品種もある）がなります。
- 主に **赤道をはさんで北緯25度〜南緯25度あたり**（おおむね北回帰線と南回帰線の間）で栽培されます。この地域を **「コーヒーベルト」** といいます。

## 2-2 コーヒーチェリーの構造

外側から順に、

1. **外皮** ── 赤い皮
2. **果肉（パルプ）** ── 甘い果肉
3. **ミューシレージ** ── ぬるぬるした粘液質
4. **パーチメント（内果皮）** ── 種を包む硬い殻
5. **シルバースキン（銀皮）** ── 種に張りついた薄い皮
6. **生豆（なままめ／きまめ）** ── 種子。これを焙煎したものがコーヒー豆

- 1つの実には、通常 **2粒の種** が向かい合って入っています（**フラットビーン**、平豆）。
- ときどき種が **1粒だけ丸く** 育つものがあり、**ピーベリー（丸豆）** と呼ばれます。

## 2-3 コーヒーの三原種

| | アラビカ種 | カネフォラ種（ロブスタ） | リベリカ種 |
|---|---|---|---|
| 原産地 | エチオピア | 中央アフリカ（コンゴなど） | 西アフリカ（リベリアなど） |
| 生産量の割合（目安） | 約6割 | 約4割 | ごくわずか |
| 栽培に向く場所 | **標高の高い所**（目安：約1,000〜2,000m）。暑さ・寒さ・病気に **弱い** | **低地** でも育つ。病気・害虫に **強い** | 低地。病気に弱い |
| 味 | 香りが豊か、**酸味** と甘み | **苦み** が強く、麦茶のような香ばしさ（「ロブ臭」と呼ばれることも） | 苦みが強い |
| カフェイン（目安） | 約1〜1.5％ | 約2〜2.5％（アラビカの約2倍） | ── |
| 主な用途 | レギュラーコーヒー、スペシャルティコーヒー | インスタントコーヒー、缶コーヒー、ブレンド、エスプレッソ | 生産国で消費されることが多い |

※割合や数値は年や資料によって違います。

## 2-4 アラビカ種の主な品種

| 品種 | 特徴 |
|---|---|
| ティピカ | アラビカ種の原型に近い古い品種。上品な香りと酸味。病気に弱く収量が少ない |
| ブルボン | ティピカの突然変異。甘みとコク。ブルボン島（現在のレユニオン島）が名前の由来 |
| カトゥーラ | ブルボンの突然変異。木が小さく、収量が多い |
| ムンド・ノーボ | ティピカとブルボンの自然交配。ブラジルで多い |
| カトゥアイ | ムンド・ノーボとカトゥーラの交配 |
| ゲイシャ（ゲシャ） | エチオピアのゲシャ地区が由来とされる。パナマで2000年代に高い評価を受け、花のような香りで有名 |
| パカマラ | パカスとマラゴジッペの交配。豆が大きい |
| SL28・SL34 | ケニアで開発された品種 |

## 2-5 精製方法（実から生豆を取り出す方法）

| 方法 | やり方 | 味の傾向 |
|---|---|---|
| **ナチュラル（乾燥式・非水洗式）** | 実をそのまま天日などで乾燥させてから、殻と皮を取り除く | 甘く、フルーティーで、独特の香り。ブラジル、エチオピアなど |
| **ウォッシュト（水洗式）** | 果肉を取り除き、水槽で発酵させてミューシレージを取ってから乾燥 | すっきりして、**酸味がきれい**。品質が安定しやすい。コロンビア、中米など |
| **パルプドナチュラル／ハニー** | 果肉を取り除き、ミューシレージを残したまま乾燥 | ナチュラルとウォッシュトの中間。甘み |
| **スマトラ式（ウェットハル）** | パーチメントを半乾きの状態で取り除いてから乾燥 | 独特の土っぽさ、重いコク。インドネシア（マンデリンなど） |

## 2-6 生豆の選び方

- **色と形がそろっている** ── 大きさ（スクリーン）がそろっていると、焙煎ムラが出にくい
- **欠点豆が少ない** ── 黒豆（発酵しすぎ）、発酵豆、虫食い豆、カビ豆、未熟豆、割れ豆、貝殻豆、石や枝などの異物
- **においに異常がない** ── カビ臭・発酵臭がない
- **収穫からの時間** ── 収穫後1年以内のものを「**ニュークロップ**」といい、水分が多く緑色が濃い。古い豆（オールドクロップ）は黄色っぽく、香りが少ない
- 焙煎の前に **ハンドピック（手で欠点豆を取り除く作業）** を行うと、雑味が減ります

**等級（格付け）の基準は国によって違う**

| 基準 | 例 |
|---|---|
| 豆の大きさ（スクリーン） | コロンビア：スプレモ（大粒）、エクセルソ。ケニア・タンザニア：AA、AB など。スクリーン1は1/64インチ（約0.4mm） |
| 栽培地の標高 | グアテマラ・コスタリカなど：SHB（ストリクトリー・ハード・ビーン、高地産の硬い豆）、HB など |
| 欠点豆の数 | ブラジル：No.2（欠点が最も少ない）〜。インドネシア：G1（グレード1）〜 |

> **ここを覚える**
> - アカネ科、コーヒーベルト（北緯25度〜南緯25度）
> - アラビカ＝高地・酸味と香り・約6割／ロブスタ＝低地・苦み・カフェイン約2倍・インスタント
> - 1粒の丸い豆＝ピーベリー
> - ナチュラル＝甘くフルーティー、ウォッシュト＝すっきりきれいな酸味

## 3-1 主な生産国

- 生産量が多いのは **ブラジル（1位）**、**ベトナム（2位、ロブスタが中心）**、その次にコロンビアやインドネシアなどが続きます（順位は年によって変わることがあります）。

## 3-3 豆どうしの相性（ブレンドの考え方）

**ブレンドとは**　複数の産地の豆を組み合わせて、味のバランスを整えたり、新しい味を作ったりすることです。

**ブレンドの基本**

1. **ベース（土台）になる豆** を決める（全体の4〜6割程度が目安）── クセの少ない **ブラジル** や **コロンビア** がよく使われる
2. **個性を加える豆** を組み合わせる
   - 酸味を加える → エチオピア（モカ）、ケニア、キリマンジャロ
   - 苦みとコクを加える → マンデリン、深煎りの豆
   - 甘い香りを加える → コロンビア、グアテマラ
3. 同じ傾向の豆どうしより、**長所を補い合う組み合わせ** を考える

**有名なブレンド**

- **モカ・ジャバ** ── エチオピア（イエメン）のモカと、インドネシアのジャワを合わせたもの。**世界最古のブレンド** といわれます。モカの酸味とジャワのコクが補い合います。

| 目的 | 組み合わせの例 |
|---|---|
| バランスの良いマイルドなブレンド | ブラジル＋コロンビア |
| 酸味が華やかなブレンド | ブラジル＋エチオピア（モカ） |
| 苦みのしっかりしたブレンド | ブラジル＋マンデリン（深煎り） |
| アイスコーヒー向き | 深煎りのブラジル＋マンデリン など |

> **ポイント**　ブレンドには、生豆の段階で混ぜてから焼く **「プレミックス」** と、豆ごとに焼いてから混ぜる **「アフターミックス」** があります。豆の硬さや大きさが違うときは、アフターミックスのほうがそれぞれに合った焙煎ができます。

> **ここを覚える**
> - ブラジル＝世界1位・ブレンドのベース
> - ブルーマウンテン＝ジャマイカ（樽詰め）、キリマンジャロ＝タンザニア、マンデリン＝インドネシア（スマトラ）、コナ＝ハワイ
> - モカ・ジャバ＝世界最古のブレンド

# 第4章 焙煎（ロースト）

## 4-1 焙煎とは

生豆を加熱して、コーヒー特有の **色・香り・味** を作り出す工程です。生豆は緑色っぽく、そのままでは香りがほとんどありません。

**焙煎中に起こること**

- 水分が抜けて、豆の重さが **約15〜20％ 減る**（深煎りほど多く減る）
- 豆がふくらみ、体積が大きくなる
- **メイラード反応**（糖とアミノ酸の反応）や **カラメル化** で、茶色い色と香ばしい香りが生まれる
- 酸味のもとになる **クロロゲン酸** などが分解され、深煎りになるほど **酸味が減り、苦みが増える**
- 炭酸ガスが豆の中にたまる

**ハゼ（爆ぜ）**

| | 1ハゼ | 2ハゼ |
|---|---|---|
| 音 | 「パチッ、パチッ」と大きめの音 | 「ピチピチ」と細かい音 |
| 起こること | 豆の中の水分が水蒸気になってふくらみ、はじける | 豆の組織が壊れ、ガスが出てくる。表面に油が出始める |
| 焙煎度の目安 | 1ハゼが終わるころ＝ミディアム〜ハイロースト | 2ハゼが始まるころ＝シティ〜フルシティロースト |

## 4-2 焙煎度（8段階）

日本でよく使われる8段階の分け方です（浅い順）。

| 焙煎度 | 区分 | 色 | 味の特徴 |
|---|---|---|---|
| ① ライトロースト | 浅煎り | 黄色っぽい小麦色 | 香り・コクがまだ弱い。ほとんど飲用されない |
| ② シナモンロースト | 浅煎り | シナモン色 | **強い酸味**、軽い |
| ③ ミディアムロースト | 中煎り | 栗色 | 酸味が主体、ほのかな苦み。アメリカンコーヒー向き |
| ④ ハイロースト | 中煎り | 茶色 | 酸味と苦みのバランス。甘みが出る |
| ⑤ シティロースト | 中深煎り | 濃い茶色 | 苦みが酸味より勝つ。日本で人気が高い |
| ⑥ フルシティロースト | 深煎り | こげ茶色 | **苦み・コク** が強い。アイスコーヒーにも |
| ⑦ フレンチロースト | 深煎り | 黒に近いこげ茶。表面に油 | 強い苦み、スモーキー。カフェオレ向き |
| ⑧ イタリアンロースト | 深煎り | ほぼ黒 | 最も強い苦み。エスプレッソ向き（ただし最近は中深煎りのエスプレッソも多い） |

**覚え方**　**「浅煎り＝酸味、深煎り＝苦み」**。焙煎が深くなるほど、酸味は減り、苦みとコクが増えます。

## 4-3 豆の違いによる焙煎

| 豆の性質 | 向く焙煎の傾向（一般論） |
|---|---|
| **標高が高い所の、硬くて密度の高い豆**（グアテマラ SHB、コロンビア、ケニアなど） | 熱が中まで伝わりにくいので、しっかり火力をかけられる。浅煎りで酸味を楽しむことも、深煎りにすることもできる（幅広い焙煎に耐えられる） |
| **標高が低い所の、柔らかい豆**（ブラジルの一部など） | 火が通りやすく焦げやすいので、火力を控えめに。中煎り〜中深煎りが向くことが多い |
| **酸味が魅力の豆**（エチオピア、ケニアなど） | 浅煎り〜中煎りで個性を生かす |
| **苦み・コクが魅力の豆**（マンデリンなど） | 深煎りで個性を生かす |
| **水分の多いニュークロップ** | 水分を抜く時間を長めにとる |
| **大きさがそろっていない豆** | 焙煎ムラが出やすい（ブレンドではアフターミックスが向く） |

## 4-4 焙煎機の種類

| 方式 | しくみ | 特徴 |
|---|---|---|
| 直火式 | 穴のあいたドラムで、炎が直接豆に当たる | 個性が強く香ばしい。ムラが出やすく、技術が必要 |
| 半熱風式 | 穴のないドラムを外から熱し、熱風も送り込む | 安定して焼ける。多くの店で使われる |
| 熱風式 | 熱風だけで焼く | 短時間で均一に焼ける。大量生産向き |

家庭では、手網やフライパンで焙煎することもできます（煙やチャフ（はがれた薄皮）が出るので注意）。

## 4-5 焙煎後の豆と保存

- 焙煎直後の豆は **炭酸ガス** を多く含みます。ドリップのときに粉がふくらむのはこのガスのためで、**新鮮さの目安** になります。
- 焙煎してから数日たつと、味が落ち着いて飲みごろになるといわれます（豆や焙煎度で違う）。
- **保存の大敵は「酸素」「湿気」「光」「高温」**。
- **豆のまま** 保存し、飲む直前に挽くのがおすすめです（粉にすると表面積が増えて、劣化が早い）。
- 密閉容器に入れて冷暗所で保存。長期保存なら **冷凍**（小分けにし、出し入れによる結露に注意）。
- 目安として、豆は焙煎後 **2週間〜1か月程度**、粉はもっと早く飲み切ります（推測を含む一般的な目安）。

> **ここを覚える**
> - 焙煎の8段階：ライト → シナモン → ミディアム → ハイ → シティ → フルシティ → フレンチ → イタリアン
> - 浅煎り＝酸味、深煎り＝苦み・コク
> - 1ハゼ＝パチパチ、2ハゼ＝ピチピチ
> - 硬い高地の豆は幅広い焙煎に耐える、柔らかい豆は火力控えめ

# 第5章 挽き方と淹れ方（抽出）

## 5-1 挽き方（粒度）と抽出方法

| 挽き方 | 粒の大きさ | 向いている抽出方法 |
|---|---|---|
| 極細挽き | パウダー状 | エスプレッソ、トルココーヒー（さらに細かい） |
| 細挽き | グラニュー糖より細かい | エスプレッソ、水出しコーヒーの一部 |
| 中細挽き | グラニュー糖くらい | **ペーパードリップ**、コーヒーメーカー |
| 中挽き | グラニュー糖とザラメの間 | ネルドリップ、サイフォン |
| 粗挽き | ザラメくらい | **フレンチプレス**、パーコレーター |

**ミル（グラインダー）の種類**

| 種類 | 特徴 |
|---|---|
| プロペラ式 | 刃を回して砕く。安いが粒の大きさがそろいにくい |
| フラットカッター式（臼式） | 2枚の平らな刃で挽く。粒がそろいやすい |
| コニカル式（円すい臼式） | 円すい形の刃で挽く。手動ミルにも多い。熱が出にくい |

**粒の大きさをそろえる理由**　細かい粉は早く、粗い粉はゆっくり成分が出るため、大きさがバラバラだと、**えぐみ（出すぎ）と薄さ（出なさすぎ）が混ざった味** になります。**微粉（とても細かい粉）** は雑味の原因になります。

## 5-2 抽出方法の分類

| 分類 | しくみ | 主な器具 |
|---|---|---|
| **透過式（ドリップ式）** | 粉の層に湯を通して成分を出す | ペーパードリップ、ネルドリップ、コーヒーメーカー |
| **浸漬式（しんしせき）** | 粉を湯に浸して成分を出す | フレンチプレス、サイフォン、水出しコーヒー（浸漬タイプ） |
| **加圧式** | 圧力をかけて短時間で出す | エスプレッソマシン、マキネッタ（直火式エスプレッソメーカー） |
| 煮出し式 | 粉を湯で煮る | トルココーヒー、パーコレーター |

## 5-3 ペーパードリップ

**ドリッパーの種類**

| ドリッパー | 形・穴 | 特徴 |
|---|---|---|
| メリタ | 台形・**1つ穴** | 1908年、ドイツのメリタ・ベンツが考案したペーパードリップの元祖。湯がゆっくり落ち、味が安定しやすい |
| カリタ | 台形・**3つ穴** | 湯が落ちる速さが中くらい。日本で広く使われる |
| ハリオ V60 | 円すい形・大きな1つ穴、らせん状の溝 | 湯を注ぐ速さで味を調整しやすい |
| コーノ（KONO） | 円すい形・1つ穴 | ネルドリップに近い味を目指したもの |

**淹れ方の目安（一例・1杯分）**

| 項目 | 目安 |
|---|---|
| 粉の量 | 約10〜12g（中細挽き） |
| 湯の量 | 約120〜150ml |
| 湯の温度 | 約85〜95℃（**浅煎りは高め、深煎りは低め** にすると、それぞれ飲みやすくなる） |
| 蒸らし | 粉全体を湿らせる程度の湯を注ぎ、**約20〜30秒** 待つ |

**手順**

1. ペーパーフィルターの接着部分を折り、ドリッパーにセットする。
2. 粉を入れ、表面を平らにする。
3. 少量の湯を注いで **蒸らす**（粉がふくらむのは炭酸ガスが出ているため）。
4. 中心から「の」の字を描くように、**細く、ゆっくり** 注ぐ。フィルターに直接湯をかけない。
5. 決めた量が落ちたら、**最後まで落とし切らずに** ドリッパーを外す（最後のほうは雑味が多いとされる）。

## 5-4 そのほかの抽出器具

| 器具 | 特徴 |
|---|---|
| ネルドリップ | 布（フランネル）のフィルター。とろりとまろやかでコクのある味。布は使った後に水につけて冷蔵保存する |
| フレンチプレス | 粗挽きの粉と湯を入れて約4分待ち、金属フィルターを押し下げる。**コーヒーオイル** も出るので、豆の個性がそのまま出る |
| サイフォン | 下のフラスコの湯が蒸気の圧力で上に上がり、粉と混ざる。火を止めると下に落ちる。見た目が楽しく、香りが立つ |
| エスプレッソマシン | 細かい粉に **約9気圧** の圧力をかけ、**約25〜30秒** で約30mlを抽出。表面の泡を **クレマ** という |
| マキネッタ | 直火にかけて、蒸気の圧力でエスプレッソ風のコーヒーを作る |
| 水出し（コールドブリュー） | 水でゆっくり時間をかけて抽出。苦みや酸味が穏やかでまろやか |

## 5-5 淹れ方と味の関係

| 条件 | 成分が出やすい（濃い・苦い） | 成分が出にくい（薄い・酸っぱい） |
|---|---|---|
| 挽き方 | 細かい | 粗い |
| 湯の温度 | 高い | 低い |
| 抽出時間 | 長い | 短い |
| 粉の量 | 多い | 少ない |

- **出すぎ（過抽出）** ── 苦み・えぐみ・渋みが強くなる
- **出なさすぎ（未抽出）** ── 薄く、酸っぱく、物足りない
- 味の調整は、**一度に1つの条件だけを変える** と原因が分かりやすくなります。

## 5-6 水

- コーヒーには **軟水** が向いているといわれます（日本の水道水の多くは軟水）。
- 硬水は苦みが強く出やすく、軟水は酸味や香りが出やすい傾向があります。
- 水道水を使うときは、浄水器を通すか、しっかり沸騰させてカルキ臭を抜きます。

> **ここを覚える**
> - ペーパードリップ＝中細挽き、フレンチプレス＝粗挽き、エスプレッソ＝極細〜細挽き
> - メリタ＝1つ穴（元祖）、カリタ＝3つ穴、ハリオV60＝円すい
> - 蒸らし約20〜30秒、浅煎りは高め・深煎りは低めの湯
> - エスプレッソ＝約9気圧、約25〜30秒、クレマ
> - 細かく・高温・長時間＝濃く苦い

# 第6章 エスプレッソメニューとラテアート

## 6-1 エスプレッソを使ったメニュー

| メニュー | 内容 |
|---|---|
| エスプレッソ | 約30mlの濃いコーヒー。デミタスカップで |
| ドッピオ | エスプレッソのダブル（2杯分） |
| リストレット | 抽出量を少なくした、より濃いエスプレッソ |
| ルンゴ | 抽出量を多くしたエスプレッソ |
| カフェ・アメリカーノ | エスプレッソをお湯で割ったもの |
| **カプチーノ** | エスプレッソ＋スチームミルク＋**厚めのミルクフォーム**。昔ながらのものは、エスプレッソ・ミルク・泡が約1：1：1 |
| **カフェラテ** | エスプレッソ＋**たっぷりのスチームミルク**＋薄いフォーム。カプチーノよりミルクが多い |
| カフェ・マキアート | エスプレッソに **少量のミルクフォーム** をのせたもの（マキアート＝「しみをつけた」） |
| ラテ・マキアート | ミルクにエスプレッソを注いで、層を作ったもの |
| フラットホワイト | オーストラリア・ニュージーランド発祥。きめ細かい薄いフォーム |
| カフェモカ | カフェラテ＋チョコレートソース |
| アフォガート | バニラアイスにエスプレッソをかけたデザート |

※カフェオレは、エスプレッソではなく **ドリップコーヒー＋牛乳**（フランス発祥）です。

## 6-2 ミルクのスチーミング

- スチームノズルで、牛乳を温めながら泡立てます。
- 最初にノズルの先を表面近くにして **空気を入れ**（ストレッチ）、その後ノズルを少し沈めて **うずを作り、泡をきめ細かくする**（ロール）。
- 仕上がりの温度は **約60〜65℃** が目安です。**約70℃を超えると甘みが減り、においが出やすく** なります。
- 理想は、つやがあり、液体のように流れる **きめ細かい泡（マイクロフォーム）** です。
- 牛乳は **冷たい状態** から始めると、泡立てる時間を長くとれます。

## 6-3 ラテアートの種類

| 種類 | 方法 | 代表的な絵柄 |
|---|---|---|
| **フリーポア** | ミルクピッチャーから注ぐミルクの動きだけで模様を描く | **ハート**、**リーフ（ロゼッタ）**、**チューリップ** |
| **エッチング** | ピック（竹串のような道具）で、泡の表面に線を描く | 動物、キャラクター、花 |
| **デザインカプチーノ（3Dラテアート）** | 泡を盛り上げて立体的な形を作る | 立体の動物など |

**フリーポアの基本の流れ（ハート）**

1. カップを傾け、少し高い位置から細く注いで、エスプレッソとミルクをなじませる（ベースを作る）。
2. カップの半分ほどになったら、ピッチャーをカップに **近づけ**、注ぐ量を増やすと白い円が浮かぶ。
3. 円が広がったら、ピッチャーを持ち上げて **細く注ぎながら、円を切るように** 手前から奥へ抜く。

**きれいに描くためのポイント**

- **新鮮なエスプレッソ** で、**クレマ** がしっかりあること
- **きめ細かいミルクフォーム**（大きな泡があると描けない）
- ミルクとエスプレッソを **すぐに** 合わせる（時間がたつと分離する）
- 注ぐ **高さ・速さ・位置** を調整する

> **ここを覚える**
> - カプチーノ＝泡が多い、カフェラテ＝ミルクが多い、マキアート＝少量の泡
> - スチームミルクは約60〜65℃
> - フリーポア（ハート・リーフ・チューリップ）／エッチング（ピックで描く）／3Dラテアート

# 第8章 香りと味の評価・世界のコーヒー文化

## 8-1 コーヒーの味わいの言葉

| 言葉 | 意味 |
|---|---|
| アロマ | 淹れたコーヒーの香り（挽いた粉の香りはフレグランスと呼んで分けることもある） |
| フレーバー | 口に含んだときの香りと味の総合的な印象 |
| アシディティ（酸味） | 明るさ、さわやかさ。良い酸味は「フルーティー」「ジューシー」などと表現する |
| ボディ（コク） | 口の中で感じる重さ、とろみ、質感 |
| アフターテイスト | 飲んだ後に残る味と香り |
| スウィートネス（甘さ） | 自然な甘みの感じ |
| クリーンカップ | 雑味やにごりがないこと |
| バランス | 味の要素の調和 |

## 8-2 カッピング

コーヒーの品質を評価するための、決まった手順のテイスティング方法です。

**一般的な流れ（例）**

1. 豆を挽いて、粉の香り（**フレグランス**）を確かめる。
2. 湯を注ぎ、数分（約4分）待つ。
3. 表面にできた粉の層をスプーンで崩し（**ブレイク**）、立ち上る香り（**アロマ**）を確かめる。
4. 表面の泡や粉を取り除く。
5. スプーンですくい、「ズズッ」と **勢いよくすすって**、口全体に広げて味わう。
6. 温度が下がるにつれての変化も確かめ、評価シートに点数をつける。

**スペシャルティコーヒー**　生産地から、カップの中の味まで、品質がしっかり管理された高品質なコーヒーのことです。スペシャルティコーヒー協会（SCA）の評価方式で **80点以上** のものがスペシャルティとされてきました（評価方式は見直しが進んでいるため、最新の基準は要確認）。

**フレーバーホイール**　コーヒーの香りや味を表す言葉を、円形に整理した図です。「フルーティー → ベリー → ブルーベリー」のように、大まかな分類から細かい言葉へとたどれます。

## 8-3 世界のコーヒー文化

| 国・地域 | 文化 |
|---|---|
| **エチオピア** | **コーヒーセレモニー** ── 生豆をその場で煎り、つぶして、「ジェベナ」というポットで煮出し、何杯もふるまう、おもてなしの儀式 |
| **トルコ** | **ジェズベ（イブリック）** という小さな鍋で、とても細かい粉を砂糖と一緒に煮出し、上澄みを飲む。飲み終わった粉で占いをする習慣も。トルココーヒーの文化と伝統は、ユネスコの無形文化遺産に登録されている（2013年） |
| **イタリア** | **バール** でエスプレッソを立ったまま素早く飲む。朝のカプチーノ |
| **フランス** | カフェ文化。朝食にカフェオレをボウルで |
| **オーストリア（ウィーン）** | 伝統的なカフェハウス文化（ユネスコ無形文化遺産としてオーストリアの国内リストに登録）。ウィンナーコーヒーに近いものは現地では「アインシュペナー」などと呼ばれる |
| **アメリカ** | マグカップでたっぷり。シアトル系コーヒーチェーン、サードウェーブ（産地や豆の個性を重視する流れ） |
| **ベトナム** | **フィン** という金属フィルターで濃く淹れ、**練乳（コンデンスミルク）** を入れて飲む |
| **北欧** | コーヒーの消費量が多い。スウェーデンの「フィーカ」（コーヒーとお菓子で休む時間） |
| **日本** | 喫茶店文化、缶コーヒー、自動販売機、ハンドドリップ（ペーパー・ネル）の技術、サイフォンの普及 |

## 8-4 コーヒーと健康

- カフェインには覚醒作用・利尿作用があります。
- ドリップコーヒー100mlあたりのカフェインは約60mg（日本食品標準成分表の浸出液の値）です。
- 欧州食品安全機関（EFSA）は、健康な成人で **1日400mg程度まで**（妊娠中は200mg程度まで）なら健康への悪影響の心配は少ないとしています。
- ポリフェノールの一種 **クロロゲン酸** を含みます。

> **注意**　健康についての説明は、病気が治るなどと言い切らないようにしましょう。

## ○×問題（10問）

1. アラビカ種は、ロブスタ種より病気に強く、低地でもよく育つ。
2. ロブスタ種は、インスタントコーヒーや缶コーヒーによく使われる。
3. 浅煎りのコーヒーは酸味が強く、深煎りのコーヒーは苦みが強い傾向がある。
4. ペーパードリップには、粗挽きの粉が最も適している。
5. フレンチプレスは、粉を湯に浸して成分を出す「浸漬式」の器具である。

9. デミタスカップは、主にエスプレッソを飲むときに使う。
10. コーヒー豆は、粉にして保存するほうが、豆のまま保存するより長持ちする。

## ○×問題

| 番号 | 解答 | 解説 |
|---|---|---|
| 1 | × | 病気に強く低地で育つのは **ロブスタ（カネフォラ）種** |
| 2 | ○ | 苦みが強く安価で、カフェインも多い |
| 3 | ○ | 焙煎が進むと酸味成分が分解される |
| 4 | × | ペーパードリップは **中細挽き**。粗挽きはフレンチプレス |
| 5 | ○ | サイフォンも浸漬式 |
| 6 | × | メリタは **1つ穴**。3つ穴はカリタ |
| 7 | ○ | 時間が長い・粉が多い場合も同じ |
| 8 | × | 約60〜65℃が目安。70℃を超えると **甘みが減る** |
| 9 | ○ | デミタス＝半分のカップ |
| 10 | × | 粉は表面積が大きく **劣化が早い**。豆のまま保存して直前に挽く |
