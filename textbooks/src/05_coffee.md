# 第1章 コーヒーの歴史

## 1-1 コーヒーの発見（伝説）

- コーヒーの木（**アラビカ種**）の原産地は、**エチオピア**（アビシニア高原）とされています。
- **ヤギ飼いカルディの伝説** ── エチオピアのヤギ飼いの少年 **カルディ** が、赤い実を食べたヤギが興奮して跳ね回るのを見て、その実を修道院の僧に伝え、眠気覚ましとして使われるようになったという話。
- **僧侶シーク・オマールの伝説** ── イエメンの **モカ** で、追放された僧侶 **シーク・オマール** が、鳥がついばむ赤い実を見つけて煮て飲み、元気を取り戻したという話。
- どちらも **伝説** で、史実として確かめられたものではありません。

## 1-2 イスラム世界での広がり

| 時代 | 出来事 |
|---|---|
| 10世紀ごろ | ペルシャの医学者 **ラーズィー（ラーゼス）** が、「バン」「ブンカム」と呼ばれる飲み物について記したとされ、これがコーヒーについての古い記録ではないかといわれる（諸説ある） |
| 15世紀ごろ | **イエメン** で、イスラム教の神秘主義者（**スーフィー**）が、**夜の祈りや修行の眠気覚まし** に、コーヒーの実から作った飲み物を飲んでいたとされる。このころには、焙煎した豆を煮出す飲み方が広まっていったと考えられている |
| 15〜16世紀 | コーヒーは、**メッカ・カイロ・イスタンブール** などイスラム世界の各地に広まる |
| 1554年ごろ | **イスタンブール（コンスタンティノープル）** に、**コーヒーハウス** が開かれたとされる。人々が集まって話をしたり、ゲームをしたりする社交の場となった |
| 16〜17世紀 | イエメンの **モカ港** が、コーヒーの積み出し港として栄える。イスラム世界では、コーヒーの苗木や生豆の持ち出しが厳しく制限されていたといわれる |

**「コーヒー」という言葉の由来**　アラビア語の「**カフワ（qahwa）**」が、トルコ語の「カフヴェ」、ヨーロッパの言葉（イタリア語「カッフェ」、オランダ語「コーフィー」など）を経て、日本語の「コーヒー」になったとされます。カフワは、もともとワインを指す言葉だったともいわれます。

**「モカ」の由来**　イエメンの **モカ港** から積み出されたコーヒーを「モカ」と呼んだのが始まりです。現在は、イエメンやエチオピアのコーヒーの名前として使われています。

## 1-3 ヨーロッパへの広がり

| 年代 | 出来事 |
|---|---|
| 17世紀初め | ヴェネツィアの商人などを通じて、コーヒーがヨーロッパに伝わる。当初は「イスラム教徒の飲み物」として反対する声もあったが、ローマ教皇クレメンス8世が飲んで認めた、という話が伝わる（逸話） |
| 1645年ごろ | ヴェネツィアにコーヒーハウスができたとされる |
| **1650年** | イギリス・**オックスフォード** に、イギリス初のコーヒーハウスができたとされる |
| **1652年** | **ロンドン** に初のコーヒーハウス。その後、ロンドンには多くのコーヒーハウスが生まれ、**情報交換・商談の場** となった。「**ペニー・ユニバーシティ**（1ペニーで知識が得られる大学）」と呼ばれた。コーヒーハウス「ロイズ」からは、のちに保険組合の **ロイズ** が生まれた |
| **1686年ごろ** | パリに「**カフェ・プロコープ**」が開店。現存するパリ最古のカフェの一つとされ、のちに文化人や思想家が集まった |
| 1683年 | オスマン帝国軍のウィーン包囲の後、ウィーンにコーヒーハウスが生まれたという話が知られる（諸説ある） |
| 18世紀 | ヨーロッパ各地にコーヒーハウスやカフェが広まる。バッハの『コーヒー・カンタータ』（1730年代）など、文化にも登場する |

## 1-4 栽培の世界への広がり

| 年代 | 出来事 |
|---|---|
| 17世紀 | インドの聖者 **ババ・ブーダン** が、メッカ巡礼の帰りに7粒の種を持ち帰り、インドで栽培が始まったという伝説がある |
| 17世紀末 | **オランダ** が、インドからコーヒーの苗木を **ジャワ島（インドネシア）** に持ち込み、植民地での大規模な栽培を始める |
| 1706年ごろ | ジャワの苗木がオランダの **アムステルダムの植物園** に送られる |
| 1714年 | アムステルダム市長が、フランス国王 **ルイ14世** にコーヒーの木を贈ったとされる |
| 1720年代 | フランスの海軍士官 **ガブリエル・ド・クリュー** が、パリの植物園の苗木をカリブ海の **マルティニーク島** に運んだとされる。航海中、自分の飲み水を苗木に分け与えたという話が有名。これが中南米のコーヒー栽培の広がりにつながったといわれる |
| **1727年ごろ** | **ブラジル** にコーヒーが伝わる（ポルトガルの軍人 **フランシスコ・デ・メロ・パリェタ** が持ち込んだという話が知られる）。のちにブラジルは **世界最大の生産国** になる |
| 19世紀 | 中南米・アフリカ・アジアで栽培が広がる。**セイロン（スリランカ）** は大産地だったが、**さび病（コーヒーさび病）** の大流行（1860〜1870年代〜）でコーヒー園が壊滅し、**紅茶の栽培に転換** した |

## 1-5 日本のコーヒーの歴史

| 年代 | 出来事 |
|---|---|
| 江戸時代 | 長崎の **出島** でオランダ人が飲んでいたとされる。一部の通訳や遊女などが口にしたといわれる |
| **1804年** | 文人・**大田南畝（蜀山人：しょくさんじん）** が、長崎でオランダ船の「カウヒイ」を飲み、「**焦げくさくて味わうに堪えない**」という意味の感想を『瓊浦又綴（けいほゆうてつ）』に書き残した。日本人による古い飲用記録の一つ |
| 江戸時代後期 | シーボルトが、薬としてのコーヒーの効用を日本に紹介したともいわれる |
| 幕末・明治初期 | 開港により、外国人居留地などでコーヒーが飲まれ、輸入も始まる |
| **1888年** | 東京・下谷黒門町（現在の上野あたり）に、**鄭永慶（てい えいけい）** が、日本初の本格的な喫茶店とされる **「可否茶館（かひいさかん）」** を開いた。数年で閉店した |
| **1911年** | 東京・銀座に「**カフェー・プランタン**」「**カフェーパウリスタ**」などが開店。パウリスタは、ブラジル政府から無償でコーヒー豆の提供を受け、安い価格でコーヒーを提供して、コーヒーを広めたとされる |
| **1901年** | アメリカで、日本人化学者の **加藤サトリ** が、溶けるコーヒー（インスタントコーヒー）を発表したとされる（世界初のインスタントコーヒーとされることが多い） |
| 大正〜昭和初期 | 都市部に喫茶店やカフェーが増える |
| 戦時中 | コーヒー豆の輸入が止まる |
| 1950年 | 戦後、コーヒー豆の輸入が再開される |
| **1961年ごろ** | インスタントコーヒーの輸入が自由化され、家庭にコーヒーが広まる |
| **1969年** | **UCC上島珈琲** が、ミルク入りの **缶コーヒー** を発売（世界初の缶コーヒーとされることが多いが、それ以前の商品をあげる説もある） |
| 1970年代〜 | 喫茶店ブーム。全国の喫茶店の数は **1981年ごろに約15万店** でピークを迎えたとされる。自動販売機の缶コーヒーが普及 |
| **1983年** | **全日本コーヒー協会** が、**10月1日を「コーヒーの日」** に制定（国際協定によって、コーヒーの新しい年度が始まる日であることなどにちなむ） |
| 1996年 | アメリカのシアトル系コーヒーチェーン（スターバックス）が日本に1号店（銀座）を出し、エスプレッソを使ったメニューやテイクアウトが広まる |
| 2010年代 | コンビニエンスストアの店頭で淹れるコーヒーが普及。**サードウェーブ** の考え方を持つ店が増える |
| **2015年〜** | 国際コーヒー機関（ICO）が、**10月1日を「国際コーヒーの日（International Coffee Day）」** とした |

## 1-6 コーヒーの「ウェーブ」

| 波 | 時期（目安） | 特徴 |
|---|---|---|
| **ファーストウェーブ** | 19世紀〜1960年代ごろ | 大量生産・大量消費。真空パックやインスタントコーヒーで、コーヒーが家庭に広まる |
| **セカンドウェーブ** | 1970年代〜 | **シアトル系** のコーヒーチェーン。深煎りの **エスプレッソ** とミルクを使ったメニュー（カフェラテなど）、テイクアウト |
| **サードウェーブ** | 2000年代〜 | **豆の産地や農園、品種、精製方法** などの個性を重視。**シングルオリジン**、**浅煎り〜中煎り**、**ハンドドリップ** で1杯ずつ丁寧に淹れる |

> - 1804年 大田南畝「焦げくさくて味わうに堪えない」／1888年 可否茶館（鄭永慶）／1911年 カフェーパウリスタ

> - 10月1日＝コーヒーの日（1983年 全日本コーヒー協会）、国際コーヒーの日（2015年〜 ICO）

# 第2章 コーヒーの木と豆の種類

## 2-1 コーヒーの木

| 項目 | 内容 |
|---|---|
| 分類 | **アカネ科コフィア（コーヒーノキ）属** の常緑樹 |
| 高さ | 野生では数m〜10m以上になることもあるが、農園では収穫しやすいように **2m前後** に剪定することが多い |
| 花 | **白い花** が咲く。**ジャスミンのような甘い香り**。花は数日で散る |
| 実 | 花が散った後、緑色の実がなり、熟すと **赤く**（品種によっては黄色に）なる。**サクランボ** に似ていることから「**コーヒーチェリー**」と呼ばれる |
| 収穫まで | 開花から収穫まで、アラビカ種で約6〜9か月程度（品種や環境で違う） |
| 植えてから | 苗木を植えてから実がなるまで、約3〜4年とされる |

**コーヒーベルト**　コーヒーは、主に **赤道をはさんで北緯25度〜南緯25度あたり**（おおむね北回帰線と南回帰線の間）の地域で栽培されます。この地域を **「コーヒーベルト」** といいます。

**栽培に適した条件（アラビカ種の一般的な目安）**

| 条件 | 内容 |
|---|---|
| 気温 | 年平均気温 約15〜24℃程度。暑すぎず、寒すぎない。**霜に弱い** |
| 雨 | 年間降水量 約1,500〜2,000mm程度。**雨季と乾季** があると、開花がそろいやすい |
| 土 | 水はけが良く、肥えた土（**火山灰土壌** など） |
| 日光 | 強すぎる日差しは苦手。**シェードツリー**（日陰を作る木）を植えることもある |
| 標高 | 熱帯では、標高の高い場所（**昼夜の寒暖差** があり、実がゆっくり熟して、味が濃くなる） |

## 2-2 コーヒーチェリーの構造

外側から順に、

| 順 | 部分 | 説明 |
|---|---|---|
| 1 | **外皮** | 赤い皮 |
| 2 | **果肉（パルプ）** | 甘い果肉。乾燥させたものは「**カスカラ**」と呼ばれ、お茶のように飲まれることもある |
| 3 | **ミューシレージ** | ぬるぬるした粘液質（糖分を含む） |
| 4 | **パーチメント（内果皮）** | 種を包む、羊皮紙のような硬い殻 |
| 5 | **シルバースキン（銀皮）** | 種に張りついた薄い皮。焙煎すると「**チャフ**」としてはがれる |
| 6 | **生豆（なままめ／きまめ）** | **種子**。これを焙煎したものが、私たちが使う **コーヒー豆** |

- 1つの実には、通常 **2粒の種** が、平らな面を向かい合わせて入っています。これを **フラットビーン（平豆）** といいます。
- ときどき種が **1粒だけ丸く** 育つものがあり、**ピーベリー（丸豆）** と呼ばれます。全体の約5〜10％程度とされ、選別して販売されることもあります。

## 2-3 コーヒーの三原種

| | **アラビカ種** | **カネフォラ種（ロブスタ）** | **リベリカ種** |
|---|---|---|---|
| 学名 | Coffea arabica | Coffea canephora | Coffea liberica |
| 原産地 | **エチオピア** | **中央アフリカ・西アフリカ**（コンゴなど） | **西アフリカ**（リベリアなど） |
| 世界の生産量の割合（目安） | **約6割前後**（年によって変わる） | **約4割前後** | ごくわずか |
| 栽培に向く場所 | **標高の高い所**（目安：約800〜2,000m以上）。**暑さ・寒さ・病気・害虫に弱い** | **低地** でも育つ。**病気（さび病など）・害虫・暑さに強い** | 低地。高温多湿に強いが、さび病に弱い |
| 受粉 | **自家受粉**（自分の花粉で実がなる） | 他家受粉（別の木の花粉が必要） | 他家受粉 |
| 染色体 | 44本（四倍体） | 22本（二倍体） | 22本（二倍体） |
| 豆の形 | 平たい楕円形、センターカットがS字に曲がることが多い | 丸みがあり小さめ、センターカットがまっすぐ | 大きい |
| 味 | 香りが豊か、**酸味** と甘み、複雑な風味 | **苦み** が強く、麦茶のような香ばしさ（「**ロブ臭**」と呼ばれることも）。コクが強い | 苦みが強い |
| カフェイン（目安） | 約1〜1.5％ | **約2〜2.5％**（アラビカの約2倍） | ── |
| 主な用途 | レギュラーコーヒー、スペシャルティコーヒー | **インスタントコーヒー**、**缶コーヒー**、ブレンドの一部、イタリアのエスプレッソのブレンド | 生産国で消費されることが多い |
| 主な生産国 | ブラジル、コロンビア、エチオピア、中米など | **ベトナム**、ブラジル、インドネシア、ウガンダなど | フィリピン、マレーシアなど |

**ハイブリッド・ティモール**　アラビカ種とカネフォラ種が自然に交配したもので、さび病に強い。これをもとに、**カティモール** などのさび病に強い品種が作られました。

## 2-4 アラビカ種の主な品種

| 品種 | 特徴 |
|---|---|
| **ティピカ** | アラビカ種の原型に近い **古い品種**。**上品な香りと酸味**。病気に弱く、収量が少ない。ブルーマウンテンやハワイ・コナの主な品種として知られる |
| **ブルボン** | ティピカの **突然変異**。インド洋の **ブルボン島（現在のレユニオン島）** で生まれたことが名前の由来。**甘みとコク** |
| **カトゥーラ** | ブルボンの突然変異。**木が低く**、収量が多い。ブラジルで発見された |
| **ムンド・ノーボ** | ティピカとブルボンの **自然交配**。ブラジルで多く栽培。「新世界」の意味 |
| **カトゥアイ** | ムンド・ノーボとカトゥーラの交配 |
| **ゲイシャ（ゲシャ）** | エチオピアの **ゲシャ地区** の野生種が由来とされる。**パナマ** で栽培されたものが **2004年の品評会で高い評価** を受け、一躍有名に。**ジャスミンのような花の香り、紅茶やかんきつのような風味**。非常に高価で取引される |
| **パカマラ** | **パカス**（ブルボンの変異種）と **マラゴジッペ**（ティピカの変異種で、豆がとても大きい）の交配。**豆が大きい**。エルサルバドルで開発 |
| **SL28・SL34** | **ケニア** で開発された品種。はっきりした酸味 |
| **カティモール** | ハイブリッド・ティモールとカトゥーラの交配。**さび病に強い** |
| **エチオピア原種（在来種）** | エチオピアには、数千種ともいわれる多様な在来の品種がある |

> **ここを覚える**
> - アカネ科コフィア属。白い花はジャスミンの香り。実はコーヒーチェリー
> - コーヒーベルト＝北緯25度〜南緯25度
> - 構造：外皮→果肉→ミューシレージ→パーチメント→シルバースキン→生豆
> - フラットビーン（2粒）・ピーベリー（1粒の丸豆）
> - アラビカ＝エチオピア原産・高地・酸味と香り・病気に弱い・約6割・自家受粉
> - ロブスタ（カネフォラ）＝低地・苦み・病気に強い・カフェイン約2倍・インスタント・缶コーヒー・ベトナム
> - ティピカ（原型）→ ブルボン（突然変異）→ カトゥーラ／ゲイシャ＝パナマ・花の香り

# 第3章 精製方法と生豆の選び方

## 3-1 収穫

| 方法 | 特徴 |
|---|---|
| **手摘み（ハンドピッキング）** | **熟した実だけを選んで** 摘む。品質が高いが、手間とコストがかかる。中米・コロンビア・エチオピアなど |
| **しごき摘み（ストリッピング）** | 枝の実を **まとめてしごき取る**。熟していない実も混ざる |
| **機械収穫** | 大型の機械で木をゆすって実を落とす。**ブラジル** の平らな大農園など |

## 3-2 精製方法（実から生豆を取り出す方法）

| 方法 | やり方 | 味の傾向 | 主な産地 |
|---|---|---|---|
| **ナチュラル（乾燥式・非水洗式）** | 実を **そのまま天日などで乾燥** させてから、脱穀機で殻と皮をまとめて取り除く | **甘く、フルーティー**、ボディが強い。独特の発酵感のある香り。品質にばらつきが出やすい | ブラジル、エチオピア、イエメン |
| **ウォッシュト（水洗式）** | 果肉を機械で取り除き、**水槽で発酵** させてミューシレージを分解し、**水で洗い流して** から乾燥 | **すっきり、クリーン**、**酸味がきれい**。品質が安定しやすい。大量の水が必要 | コロンビア、中米、ケニア、エチオピア |
| **パルプドナチュラル／ハニープロセス** | 果肉を取り除き、**ミューシレージを残したまま** 乾燥 | ナチュラルとウォッシュトの **中間**。**甘み** がある。ミューシレージの残し具合で、ホワイト・イエロー・レッド・ブラックハニーなどと呼ぶ | ブラジル（パルプドナチュラル）、コスタリカ（ハニー） |
| **スマトラ式（ウェットハル）** | パーチメントがついたまま半乾き（水分が多い状態）で **脱穀** し、生豆の状態で乾燥させる | 独特の **土っぽさ、ハーブのような香り**、**重いコク**、酸味は少ない。生豆は濃い緑色 | **インドネシア（スマトラ島・マンデリンなど）** |
| **アナエロビック（嫌気性発酵）など** | 実や豆を密閉したタンクで、酸素を遮断して発酵させる | 独特の強い風味。近年広まっている新しい精製方法 | 各地 |

**乾燥**　精製した豆は、天日（パティオ＝コンクリートの乾燥場、アフリカンベッド＝高床式の網の棚）や機械で、**水分が約10〜12％程度** になるまで乾燥させます。

**パーチメントコーヒーの保管**　乾燥した豆は、パーチメントをつけたまま（**パーチメントコーヒー**）で保管すると品質が保たれやすく、出荷の直前に脱穀（**ハリング**）します。

## 3-3 選別と等級（格付け）

出荷前に、**大きさ・重さ・色・欠点** などで選別し、等級をつけます。**等級の基準は国によって違います**。

| 基準 | 内容・例 |
|---|---|
| **スクリーンサイズ（豆の大きさ）** | 穴の大きさの違うふるい（スクリーン）で分ける。**スクリーン1＝1/64インチ（約0.4mm）**。例：スクリーン17＝約6.75mm。**コロンビア**：**スプレモ**（大粒：スクリーン17以上）、**エクセルソ**（スクリーン14〜16程度）。**ケニア・タンザニア**：**AA**（大粒）、AB など |
| **栽培地の標高** | **グアテマラ・コスタリカ・ホンジュラスなど**：**SHB（ストリクトリー・ハード・ビーン）**＝標高の高い所でとれた硬く密度の高い豆。HB（ハード・ビーン）など。**メキシコ・エルサルバドルなど**：**SHG（ストリクトリー・ハイ・グロウン）** など |
| **欠点豆の数** | 一定量のサンプルに含まれる欠点豆を点数化する。**ブラジル**：**No.2（最も欠点が少ない）**〜No.8。**エチオピア・インドネシア**：**G1（グレード1：最上級）**〜 など |
| 味（カップ評価） | 実際に淹れて味をみる。「ストリクトリー・ソフト」（ブラジル）など |

※具体的な数値（標高・スクリーン）は国や年で違うので、目安として理解しましょう。

## 3-4 欠点豆の種類

| 欠点豆 | 状態 | 味への影響 |
|---|---|---|
| **黒豆（ブラック・ビーン）** | 発酵しすぎたり、木から落ちた実が土の上で傷んだりして黒くなった豆 | 強い不快な臭い、えぐみ |
| **発酵豆（サワー・ビーン）** | 精製中に発酵しすぎた豆。茶色っぽい | 酸っぱい・発酵臭 |
| **カビ豆** | カビが生えた豆 | カビ臭 |
| **虫食い豆** | 虫（コーヒーベリーボーラーなど）が食べて穴があいた豆 | 雑味・濁り |
| **未熟豆** | 熟す前に収穫された豆。色が薄く、しわがある | 青臭さ・渋み |
| **貝殻豆（シェル）** | 貝殻のように内側が空洞になった豆 | 焙煎ムラ・焦げ |
| **割れ豆・欠け豆** | 脱穀などで割れた豆 | 焙煎ムラ・焦げ |
| **死豆（デッド・ビーン）** | 成熟しなかった豆。焙煎しても色がつかない | 渋み・雑味 |
| **パーチメント付き豆** | 殻が残った豆 | 焙煎ムラ |
| **異物** | 石、枝、殻など | 焙煎機やミルを傷める |

## 3-5 生豆の選び方

| 見るところ | 良い生豆 |
|---|---|
| **色** | 種類や精製方法に応じた、**ムラのない色**（ウォッシュトは青緑〜緑、ナチュラルは黄緑〜黄色っぽい） |
| **大きさ・形** | **大きさ（スクリーン）がそろっている** と、焙煎ムラが出にくい |
| **欠点豆** | **少ない** |
| **におい** | **カビ臭・発酵臭など異常なにおいがない** |
| **水分** | 適度な水分（約10〜12％程度） |
| **収穫からの時間** | **ニュークロップ**（その年に収穫された新しい豆。水分が多く緑色が濃い、香りが豊か）。収穫から時間がたった **パーストクロップ**、**オールドクロップ**（黄色っぽく、水分が少なく、香りが弱い） |
| **産地・農園の情報** | 産地・農園・品種・精製方法・標高などが明らかな豆（**トレーサビリティ**） |

**ハンドピック**　焙煎の **前と後** に、**手で欠点豆や異物を取り除く** 作業です。雑味が減り、きれいな味になります。焙煎前は見つけにくい欠点豆（未熟豆など）が、焙煎後に色の違いで見つかることもあります。

**生豆の保存**　**高温・多湿・直射日光** を避け、風通しの良い場所で保存します。生豆は焙煎豆より日持ちしますが、時間とともに **香りが弱く、色が黄色っぽく** なっていきます。

> **ここを覚える**
> - ナチュラル＝実ごと乾燥・甘くフルーティー（ブラジル・エチオピア）
> - ウォッシュト＝果肉を除き水槽で発酵・水洗・すっきりきれいな酸味（コロンビア・中米）
> - ハニー（パルプドナチュラル）＝ミューシレージを残して乾燥・甘み
> - スマトラ式＝半乾きで脱穀・土っぽさ・重いコク（マンデリン）
> - スクリーン1＝1/64インチ。スプレモ（コロンビア・大粒）、AA（ケニア・タンザニア）、SHB（標高・硬い豆）、No.2（ブラジル）、G1（エチオピア・インドネシア）
> - 欠点豆：黒豆・発酵豆・カビ豆・虫食い豆・未熟豆・貝殻豆など
> - 良い生豆：色と大きさがそろう、欠点豆が少ない、異臭なし、ニュークロップ
> - ハンドピック＝焙煎の前後に手で欠点豆を取り除く

# 第5章 豆どうしの相性とブレンド

## 5-1 ストレートとブレンド

| 種類 | 説明 |
|---|---|
| **ストレート（シングルオリジン）** | **1つの産地（国・地域・農園）の豆だけ** を使う。産地の個性をそのまま楽しめる |
| **ブレンド** | **複数の産地の豆を組み合わせる**。味のバランスを整えたり、新しい味を作ったり、**品質と価格を安定** させたりする |

※「シングルオリジン」は、特に **農園や生産者、品種、精製方法まで分かる** 豆を指して使われることが多い言葉です。

## 5-2 ブレンドの目的

1. **味のバランスを整える**（酸味・苦み・コク・香りの長所を組み合わせ、短所を補う）
2. **新しい味・店独自の味を作る**
3. **品質を安定させる**（収穫年や入荷による味の変化を、配合で調整する）
4. **価格を調整する**（高価な豆に、手ごろな豆を組み合わせる）
5. **用途に合わせる**（エスプレッソ用、アイスコーヒー用、ミルクに合うものなど）

## 5-3 ブレンドの基本の考え方

1. **ベース（土台）になる豆を決める**
   - 全体の **約4〜6割** を目安に、**クセが少なく、バランスの良い豆** を使う。
   - よく使われる豆：**ブラジル**、**コロンビア**
2. **個性を加える豆を組み合わせる**

| 加えたい味 | 合う豆の例 |
|---|---|
| **酸味・華やかな香り** | エチオピア（モカ）、ケニア、タンザニア（キリマンジャロ）、イエメン |
| **苦み・重いコク** | インドネシア（マンデリン）、深煎りの豆、ロブスタ種 |
| **甘い香り・まろやかさ** | コロンビア、グアテマラ、ブラジル |
| **上品さ・バランス** | ジャマイカ（ブルーマウンテン）、ハワイ（コナ） |
| **ボディ（とろみ）・クレマ** | ブラジル、ロブスタ種（エスプレッソ用） |

3. **相性の考え方**
   - **似た傾向の豆どうし** より、**長所を補い合う組み合わせ** を考える（例：酸味の豆＋コクの豆）。
   - 個性の強い豆どうしを多く組み合わせると、味がぼやけたり、ぶつかったりすることがある。
   - **使う豆の種類は3〜5種類程度** が扱いやすいといわれる。
   - 配合を少しずつ変えて、**実際に淹れて味を確かめる**（カッピング）。

## 5-4 有名なブレンドと組み合わせの例

- **モカ・ジャバ** ── イエメン（エチオピア）の **モカ** と、インドネシアの **ジャワ** を合わせたもの。**世界最古のブレンド** といわれます。モカの酸味と香りに、ジャワのコクが補い合います。

| 目的 | 組み合わせの例（一例） |
|---|---|
| **バランスの良いマイルドなブレンド** | ブラジル＋コロンビア（＋グアテマラ） |
| **酸味が華やかなブレンド** | ブラジル＋エチオピア（モカ） |
| **苦みのしっかりしたブレンド** | ブラジル＋マンデリン（深煎り） |
| **アイスコーヒー向き** | 深煎りのブラジル＋マンデリン＋コロンビアなど（冷やすと苦みが和らぎ、酸味が目立つため、深煎りが向く） |
| **エスプレッソ向き** | ブラジル（ベース）＋コロンビア＋エチオピアなど。イタリアではロブスタ種を少量加えて、クレマとコクを出すことも |
| **カフェオレ（ミルク）向き** | 深煎りでコクのある豆（ミルクに負けない） |

## 5-5 プレミックスとアフターミックス

| 方法 | やり方 | 長所 | 短所 |
|---|---|---|---|
| **プレミックス（焙煎前に混ぜる）** | **生豆の段階で混ぜてから** 一緒に焙煎する | 作業が **簡単**、効率的。味がなじむ | 豆の硬さ・大きさ・水分が違うと **焙煎ムラ** が出る |
| **アフターミックス（焙煎後に混ぜる）** | **豆ごとに焙煎してから** 混ぜる | **それぞれの豆に合った焙煎** ができる。焙煎度の違う豆を組み合わせられる | 手間がかかる。在庫の管理が複雑 |

> **ポイント**　豆の **硬さ・大きさ・水分量が大きく違う** ときは、アフターミックスのほうが、それぞれの個性を生かせます。

> **ここを覚える**
> - ストレート（シングルオリジン）＝1つの産地、ブレンド＝複数を組み合わせる
> - ブレンドの目的：バランス・独自の味・品質の安定・価格・用途
> - ベース（4〜6割）＝ブラジル・コロンビア
> - 酸味＝モカ・ケニア・キリマンジャロ、コク＝マンデリン・深煎り
> - 長所を補い合う組み合わせ、3〜5種類程度
> - モカ・ジャバ＝世界最古のブレンド
> - プレミックス（生豆で混ぜる・簡単・ムラ）／アフターミックス（焙煎後に混ぜる・豆に合った焙煎）

# 第6章 焙煎（ロースト）

## 6-1 焙煎とは

**生豆を加熱して、コーヒー特有の色・香り・味を作り出す工程** です。生豆は緑色っぽく、青臭く、そのまま挽いて湯を注いでもコーヒーの味にはなりません。焙煎によって、**約800〜1,000種類以上** ともいわれる香りの成分が生まれます。

## 6-2 焙煎中に起こること

| 変化 | 説明 |
|---|---|
| **水分が抜ける** | 生豆の水分（約10〜12％）が蒸発する |
| **重さが減る** | 水分などが抜けて、重さが **約12〜20％** 減る（**深煎りほど多く** 減る） |
| **ふくらむ** | 豆の中のガスや水蒸気で、**体積が約1.5〜2倍** になる |
| **色が変わる** | 緑 → 黄色 → 茶色 → こげ茶 → 黒っぽく |
| **香りが生まれる** | **メイラード反応**（糖とアミノ酸の反応）や **カラメル化**（糖が焦げる反応）などで、茶色い色素と香ばしい香りが生まれる |
| **酸味が変わる** | 酸味のもとになる成分が、焙煎が進むと **分解されて減る** |
| **苦みが増える** | 苦み成分が増える |
| **クロロゲン酸が減る** | 生豆に多い **クロロゲン酸**（ポリフェノールの一種）が、焙煎が進むと分解されて減る |
| **炭酸ガスができる** | 豆の中に炭酸ガスがたまる |
| **チャフがはがれる** | シルバースキン（銀皮）が「**チャフ**」としてはがれる |
| **油が出る** | 深煎りになると、豆の表面に **油（コーヒーオイル）** がにじみ出る |

## 6-3 焙煎の段階とハゼ

| 段階 | 起こること |
|---|---|
| ① 水抜き | 豆の水分が抜け、色が緑から黄色っぽくなる。青臭いにおい |
| ② 色づき | 黄色から茶色へ。パンを焼いたような香ばしい香り |
| ③ **1ハゼ** | 豆の中の水分が水蒸気になってふくらみ、「**パチッ、パチッ**」と大きめの音を立ててはじける（豆の温度の目安：約190〜200℃前後） |
| ④ 1ハゼ〜2ハゼ | 香ばしさが増し、酸味が減り、苦みが増していく |
| ⑤ **2ハゼ** | 豆の組織が壊れ、ガスが出てくる。「**ピチピチ、チリチリ**」と細かい音（目安：約220〜230℃前後）。表面に油が出始める |
| ⑥ 2ハゼ以降 | 色が黒っぽくなり、煙が多くなる。苦みとスモーキーな香り |

※温度は焙煎機や豆によって違う目安です。

## 6-4 焙煎度（8段階）

日本でよく使われる8段階の分け方です（浅い順）。

| 焙煎度 | 区分 | 色 | 味の特徴 | 向いている飲み方 |
|---|---|---|---|---|
| ① **ライトロースト** | 浅煎り | 黄色っぽい小麦色 | 香り・コクがまだ弱く、青臭さも残る。ほとんど飲用されない | ── |
| ② **シナモンロースト** | 浅煎り | シナモン色 | **強い酸味**、軽い | 酸味を楽しむ浅煎り |
| ③ **ミディアムロースト** | 中煎り | 栗色 | **酸味が主体**、ほのかな苦み | **アメリカンコーヒー** |
| ④ **ハイロースト** | 中煎り | 茶色 | 酸味と苦みのバランス。甘みが出る | ドリップ（日本の喫茶店で一般的） |
| ⑤ **シティロースト** | 中深煎り | 濃い茶色 | **苦みが酸味より勝つ**。バランスが良く、日本で人気が高い | ドリップ、ブレンド |
| ⑥ **フルシティロースト** | 深煎り | こげ茶色 | **苦み・コク** が強い | **アイスコーヒー**、カフェオレ |
| ⑦ **フレンチロースト** | 深煎り | 黒に近いこげ茶。**表面に油** | 強い苦み、スモーキー | **カフェオレ**、ウィンナーコーヒー |
| ⑧ **イタリアンロースト** | 深煎り | ほぼ黒。油でつやつや | **最も強い苦み** | **エスプレッソ**（ただし、近年は中深煎りのエスプレッソも多い） |

**覚え方**

- 「**ラ・シ・ミ・ハ・シ・フ・フ・イ**」（**ラ**イト・**シ**ナモン・**ミ**ディアム・**ハ**イ・**シ**ティ・**フ**ルシティ・**フ**レンチ・**イ**タリアン）
- **浅煎り＝酸味、深煎り＝苦み・コク**。焙煎が深くなるほど、酸味は減り、苦みとコクが増えます。
- **カフェインの量** は、焙煎度による差は大きくないといわれます（深煎りで「苦い」ことと、カフェインが多いことは別）。

## 6-5 豆の違いによる焙煎

豆の性質（硬さ・密度・大きさ・水分量）によって、向いている焙煎のしかたが違います。

| 豆の性質 | 焙煎のポイント（一般論） |
|---|---|
| **標高が高い所の、硬くて密度が高い豆**（グアテマラSHB、コロンビア、ケニア、エチオピアの高地産など） | **熱が中まで伝わりにくい** ので、**しっかり火力をかけられる**。浅煎りで酸味や香りを楽しむことも、深煎りにすることもでき、**幅広い焙煎に耐えられる** |
| **標高が低い所の、柔らかく密度が低い豆**（ブラジルの一部、低地産など） | **火が通りやすく、焦げやすい** ので、**火力を控えめ** に。中煎り〜中深煎りが向くことが多い。深煎りにしすぎると風味が抜けやすい |
| **酸味や花の香りが魅力の豆**（エチオピア、ケニア、ゲイシャなど） | **浅煎り〜中煎り** で個性を生かす |
| **苦み・コクが魅力の豆**（マンデリンなど） | **中深煎り〜深煎り** で個性を生かす |
| **バランス型の豆**（ブラジル、コロンビアなど） | 中煎り〜深煎りまで幅広く |
| **水分の多いニュークロップ** | **水抜き** の時間を長めにとる |
| **水分の少ないオールドクロップ** | 火が通りやすいので、火力に注意 |
| **大きい豆・小さい豆が混ざっている** | **焙煎ムラ** が出やすい（ブレンドではアフターミックスが向く） |
| **ピーベリー** | 丸く転がりやすいので、均一に焼けやすいといわれる |
| **ロブスタ種** | 深煎りにして、エスプレッソやアイス用に使われることが多い |

## 6-6 焙煎機の種類

| 方式 | しくみ | 特徴 |
|---|---|---|
| **直火式** | 穴のあいたドラム（または網）で、**炎が直接豆に当たる** | 豆の個性が出やすく、**香ばしい**。焼きムラが出やすく、技術が必要 |
| **半熱風式** | 穴のない鉄のドラムを外から熱し、ドラム内に **熱風も送り込む** | **安定して** 焼ける。直火と熱風の良さをあわせ持つ。多くの店で使われる |
| **熱風式** | **熱風だけ** で豆を浮かせながら焼く | **短時間で均一に** 焼ける。大量生産向き。工場など |

**家庭での焙煎**　手網、フライパン、手回しの焙煎器、家庭用電動焙煎機などで焙煎できます。**煙やチャフが出る** ので、換気し、火の扱いに注意します。

## 6-7 焙煎後の豆と保存

**焙煎後の変化**

- 焙煎直後の豆は、**炭酸ガス** を多く含んでいます。ドリップのときに粉が **ふくらむ** のはこのガスのためで、**新鮮さの目安** になります。
- 焙煎してから **数日たつと、ガスが抜けて味が落ち着き、飲みごろ** になるといわれます（豆や焙煎度で違う）。
- 時間がたつと、香りが抜け、油が酸化して、**味が落ちて** いきます。

**保存の大敵**　**「酸素」「湿気」「光」「高温」**（＋においの移り）

| 保存のポイント | 理由 |
|---|---|
| **豆のまま** 保存し、**飲む直前に挽く** | **粉にすると表面積が大きくなり**、香りが抜けやすく、酸化が早い |
| **密閉容器** に入れる（ワンウェイバルブ付きの袋なども） | 酸素・湿気を防ぐ |
| **冷暗所** に置く | 光・高温を防ぐ |
| 長期保存なら **冷凍** | 小分けにして密閉し、**出し入れによる結露** に注意する（使う分だけ出し、常温に戻してから開ける） |
| においの強いものの近くに置かない | コーヒーはにおいを吸いやすい |

**飲みごろの目安（一般的な目安で、推測を含む）**

| 状態 | 目安（常温・密閉の場合） |
|---|---|
| 豆 | 焙煎後 **約2週間〜1か月程度** |
| 粉 | **約1週間〜10日程度**（豆よりずっと早い） |

※ワンウェイバルブ：袋の中の炭酸ガスは外に出し、外の空気は入れない弁。

> **ここを覚える**
> - 焙煎＝生豆を加熱して色・香り・味を作る。重さ約12〜20％減、体積は約1.5〜2倍
> - メイラード反応・カラメル化。クロロゲン酸は焙煎が進むと減る
> - 1ハゼ＝パチパチ（水蒸気）、2ハゼ＝ピチピチ（組織が壊れる・油）
> - 8段階：ライト→シナモン→ミディアム→ハイ→シティ→フルシティ→フレンチ→イタリアン（ラ・シ・ミ・ハ・シ・フ・フ・イ）
> - 浅煎り＝酸味、深煎り＝苦み・コク。ミディアム＝アメリカン、フルシティ＝アイス、フレンチ＝カフェオレ、イタリアン＝エスプレッソ
> - 硬い高地の豆＝しっかり火力・幅広い焙煎に耐える／柔らかい低地の豆＝火力控えめ
> - 直火式（香ばしい・ムラ）・半熱風式（安定）・熱風式（均一・大量）
> - 豆のまま保存し飲む直前に挽く。粉は劣化が早い。冷凍は結露に注意

# 第7章 挽き方（グラインド）

## 7-1 挽き方（粒度）と抽出方法

| 挽き方 | 粒の大きさの目安 | 向いている抽出方法 |
|---|---|---|
| **極細挽き** | 小麦粉〜パウダー状 | **エスプレッソ**、**トルココーヒー**（さらに細かいパウダー状） |
| **細挽き** | グラニュー糖より細かい | **エスプレッソ**、マキネッタ、水出しコーヒーの一部 |
| **中細挽き** | **グラニュー糖くらい** | **ペーパードリップ**、**コーヒーメーカー** |
| **中挽き** | グラニュー糖とザラメの間 | **ネルドリップ**、**サイフォン**、ペーパードリップ（大量） |
| **粗挽き** | **ザラメくらい** | **フレンチプレス**、**パーコレーター**、水出し（浸漬式）、カッピング（やや粗め） |

**挽き方の基本の考え方**

- **抽出時間が短い器具ほど細かく、長い器具ほど粗く** 挽きます。
- **細かいほど成分が出やすく（濃く・苦く）**、**粗いほど出にくく（薄く・酸味が目立つ）** なります。

## 7-2 粒の大きさをそろえる理由

- 細かい粉は早く、粗い粉はゆっくり成分が出ます。
- 粒の大きさが **バラバラ** だと、細かい粉からは **出すぎ（えぐみ・雑味）**、粗い粉からは **出なさすぎ（薄さ・酸っぱさ）** の成分が混ざり、**味がぼやけたり、雑味が出たり** します。
- **微粉（とても細かい粉）** は雑味の原因になり、フィルターを詰まらせて抽出時間を長くします。微粉を **茶こしなどでふるって** 取り除く人もいます。

## 7-3 ミル（グラインダー）の種類

| 種類 | しくみ | 特徴 |
|---|---|---|
| **プロペラ式（ブレード式）** | 刃を高速で回して **砕く** | 安価で小型。**粒の大きさがそろいにくく**、微粉が多い。回す時間で粒度を調整する |
| **フラットカッター式（臼式）** | **2枚の平らな刃** の間で挽く | **粒がそろいやすい**。業務用に多い |
| **コニカル式（円すい臼式）** | **円すい形の刃** と外側の刃の間で挽く | 粒がそろいやすく、**熱が出にくい**。**手動ミル** に多い。低速で回転する電動ミルも |
| **カット式（グラインド式）** | 刃で切るように挽く | 粒がそろいやすい |

**ミルを使うときのポイント**

- **挽くときの熱（摩擦熱）** で香りが飛ぶので、熱の出にくいミルや、ゆっくり挽く方法が良いとされます。
- **ミルの中に残った古い粉** は、雑味や酸化臭の原因になるので、こまめに掃除します（ブラシで払う。水洗いできないものが多い）。
- **静電気** で粉が飛び散ることがあります。

> **ここを覚える**
> - 極細＝エスプレッソ・トルココーヒー、中細＝ペーパードリップ、中＝ネル・サイフォン、粗＝フレンチプレス・パーコレーター
> - 抽出時間が短いほど細かく、長いほど粗く
> - 粒がバラバラ＝雑味。微粉は雑味のもと
> - プロペラ式＝粒がそろいにくい、フラット・コニカル＝そろいやすい（コニカルは熱が出にくい）

# 第8章 淹れ方（抽出）と味の関係

## 8-1 抽出方法の分類

| 分類 | しくみ | 主な器具 | 特徴 |
|---|---|---|---|
| **透過式（ドリップ式）** | 粉の層に **湯を通して** 成分を出す | ペーパードリップ、ネルドリップ、コーヒーメーカー | 淹れ方で味を調整しやすい |
| **浸漬式（しんしせき）** | 粉を **湯に浸して** 成分を出す | **フレンチプレス**、**サイフォン**、水出しコーヒー（浸漬タイプ）、カッピング | **味が安定しやすい** |
| **加圧式** | **圧力をかけて** 短時間で出す | **エスプレッソマシン**、マキネッタ（直火式エスプレッソメーカー）、エアロプレス（加圧と浸漬の組み合わせ） | 濃厚。短時間 |
| **煮出し式** | 粉を **湯で煮る** | **トルココーヒー**（ジェズベ）、パーコレーター | 成分がしっかり出る。粉が残ることも |

## 8-2 おいしいコーヒーの目安（ゴールデンカップ）

アメリカのスペシャルティコーヒー協会（現在のSCA）などが示してきた、ドリップコーヒーの **抽出の目安** があります（目安であり、好みで変わります）。

| 項目 | 目安 |
|---|---|
| 粉と湯の割合 | 湯1Lあたり粉 **約55g**（約1：18）前後 |
| **抽出収率** | 粉の重さのうち、**約18〜22％** の成分が溶け出した状態がバランスが良いとされる |
| **濃度（TDS）** | コーヒー液の中の成分の濃さ **約1.15〜1.35％** |

- **抽出収率が低い（約18％未満）** → 成分が出なさすぎ（**未抽出**）：**薄い、酸っぱい、物足りない**
- **抽出収率が高い（約22％超）** → 成分が出すぎ（**過抽出**）：**苦い、えぐい、渋い、雑味**

## 8-3 ペーパードリップ

**ドリッパーの種類**

| ドリッパー | 形・穴 | 特徴 |
|---|---|---|
| **メリタ** | 台形・**1つ穴** | **1908年、ドイツのメリタ・ベンツ** が考案した、**ペーパードリップの元祖**。穴が小さく、湯がゆっくり落ちるので、**味が安定しやすい**（湯を注ぐ速さの影響を受けにくい） |
| **カリタ** | 台形・**3つ穴** | 湯が落ちる速さが中くらい。日本で広く使われる。ウェーブ型（底が平ら）もある |
| **ハリオ V60** | **円すい形**・大きな1つ穴、内側に **らせん状の溝（リブ）** | 2004年に発売。湯の落ちる速さが速く、**注ぐ速さで味を調整しやすい**（技術が必要）。サードウェーブで人気 |
| **コーノ（KONO）名門** | **円すい形**・1つ穴、リブが下部だけ | **ネルドリップに近い味** を目指したもの |

**ペーパーフィルターの種類**

- **漂白（白）** と **無漂白（茶色）** がある。無漂白は紙のにおいが出ることがあるので、**リンス（湯通し）** する人もいる。
- 紙が **コーヒーオイルや微粉を吸着** するため、**すっきり、クリーン** な味になる。

**淹れ方の目安（一例・1杯分）**

| 項目 | 目安 |
|---|---|
| 粉の量 | 約10〜12g（**中細挽き**） |
| 湯の量（抽出量） | 約120〜150ml |
| 湯の温度 | **約85〜95℃**（**浅煎りは高め、深煎りは低め** にすると、それぞれ飲みやすくなる） |
| 蒸らし | 粉全体を湿らせる程度の湯（粉の量の約2倍）を注ぎ、**約20〜30秒** 待つ |
| 抽出時間 | 全体で約2分30秒〜3分程度 |

**手順**

1. **湯を沸かし、器具を温める**（サーバー・カップに湯を注いで温める）。
2. ペーパーフィルターの **接着部分を折り**、ドリッパーにぴったりセットする。
3. 粉を入れ、ドリッパーを軽くゆすって **表面を平らに** する。
4. 少量の湯を **中心から全体に** 注いで **蒸らす**。粉がふくらむのは **炭酸ガスが出ている** ため（新鮮な豆ほどよくふくらむ）。
   - **蒸らしの目的**：ガスを抜いて、**湯と粉がなじみ、成分が出やすくなる** ようにする。
5. 中心から **「の」の字を描くように、細く、ゆっくり** 注ぐ。**フィルターに直接湯をかけない**（湯が粉を通らずに落ちてしまう）。
6. 粉の表面が平らになる前に、何回かに分けて注ぐ。
7. 決めた量が落ちたら、**最後まで落とし切らずに** ドリッパーを外す（最後のほうに落ちる液には、雑味が多いとされる）。
8. サーバーを軽く回して、**濃さを均一にしてから** カップに注ぐ。

## 8-4 そのほかの抽出器具

| 器具 | 淹れ方（目安） | 特徴 |
|---|---|---|
| **ネルドリップ** | 布（**フランネル**）のフィルター。中挽き。湯をゆっくり点滴のように落とす | **とろりとまろやかで、コクのある味**（オイルを適度に通す）。**布は使った後に水洗いし、水につけて冷蔵保存** する（乾かすとにおいがつく） |
| **フレンチプレス** | **粗挽き** の粉と湯を入れて **約4分** 待ち、金属フィルターを押し下げる | 金属フィルターなので **コーヒーオイル** も出て、**豆の個性がそのまま出る**。**技術がいらず、味が安定** しやすい。微粉がカップに入る |
| **サイフォン** | 下のフラスコの湯が **蒸気の圧力で上のロートに上がり**、粉と混ざる（中挽き、約1分）。**火を止めると、フラスコの温度が下がって圧力が下がり、コーヒーが下に落ちる** | **浸漬式**。見た目が楽しく、**香りが立つ**。高温で抽出するのですっきり。日本の喫茶店で広まった |
| **エスプレッソマシン** | **極細〜細挽き** の粉（シングル約7〜10g、ダブル約14〜20g）を **タンピング**（押し固める）し、**約9気圧** の圧力・約90〜96℃の湯で、**約25〜30秒** かけて、約25〜30ml（シングル）を抽出 | 濃厚。表面にきめ細かい泡の層 **クレマ** ができる |
| **マキネッタ（直火式エスプレッソメーカー）** | 下のボイラーの水が沸騰し、**蒸気の圧力** で粉を通って上に上がる | 家庭でエスプレッソ風のコーヒー（圧力はマシンより低い）。イタリアの家庭で一般的 |
| **エアロプレス** | 粉と湯を入れて混ぜ（約1〜2分）、ピストンで押し出す | 2005年にアメリカで発明された。**浸漬＋加圧**。短時間・手軽。持ち運びできる |
| **水出し（コールドブリュー）** | 粗挽き〜中挽きの粉を、水に浸す（約8〜12時間）、または水を一滴ずつ落とす（ダッチコーヒー・ウォータードリップ） | **苦みや酸味が穏やかで、まろやか**。時間がかかる |
| **コーヒーメーカー** | 自動でドリップする | 手軽で味が安定 |
| **パーコレーター** | 湯を循環させて、何度も粉に通す | キャンプなどで使われる。煮詰まりやすい |
| **トルココーヒー** | 極細のパウダー状の粉と水（砂糖）を **ジェズベ（イブリック）** で煮出し、粉が沈んでから上澄みを飲む | 濃厚。粉をこさない |

## 8-5 アイスコーヒーの淹れ方

| 方法 | やり方 | 特徴 |
|---|---|---|
| **急冷式** | 粉を **通常の約1.5〜2倍** にして濃く淹れ、**氷をたっぷり入れたサーバーに直接落として急冷** する | **香りが閉じ込められる**。すぐに作れる。氷で薄まる分、濃く淹れる |
| **水出し式** | 水でゆっくり抽出 | まろやか。苦みや酸味が穏やか |

- アイスコーヒーには、**深煎り** の豆がよく使われます（冷やすと苦みを感じにくく、酸味が目立ちやすいため）。
- 淹れたコーヒーを **ゆっくり冷ます** と、香りが飛び、濁ること（**クリームダウン**）があります。

## 8-6 淹れ方と味の関係（まとめ）

| 条件 | 成分が **出やすい**（濃い・苦い・重い） | 成分が **出にくい**（薄い・酸味が目立つ・軽い） |
|---|---|---|
| **挽き方** | **細かい** | **粗い** |
| **湯の温度** | **高い** | **低い** |
| **抽出時間** | **長い** | **短い** |
| **粉の量** | **多い** | **少ない** |
| **湯の注ぎ方** | ゆっくり（粉と湯が触れる時間が長い） | 速い |
| **焙煎度** | 深煎り（苦み） | 浅煎り（酸味） |

- **出すぎ（過抽出）** ── 苦み・えぐみ・渋みが強くなる。
- **出なさすぎ（未抽出）** ── 薄く、酸っぱく、物足りない。
- 酸味は比較的早く、苦みや雑味は後から出てくるといわれます。
- 味を調整するときは、**一度に1つの条件だけを変える** と、原因が分かりやすくなります。

**よくある味の悩みと調整（一例）**

| 悩み | 調整のしかた |
|---|---|
| 苦すぎる・えぐい | 挽き目を粗く、湯温を下げる、時間を短く、浅めの焙煎の豆に |
| 酸っぱすぎる | 挽き目を細かく、湯温を上げる、時間を長く、深めの焙煎の豆に |
| 薄い | 粉を増やす、挽き目を細かく |
| 濃すぎる | 粉を減らす、湯を増やす（または淹れた後にお湯で割る） |

## 8-7 水

- コーヒーには **軟水** が向いているといわれます（日本の水道水の多くは軟水）。
- **硬水** は、ミネラルの影響で **苦みが強く、重く** 感じやすく、**軟水** は **酸味や香りが出やすく、まろやか** な傾向があります（豆や好みによって違う）。
- エスプレッソマシンでは、硬水は **スケール（ミネラルの固まり）** がたまって故障の原因になるため、浄水フィルターを使うことが多いです。
- 水道水を使うときは、浄水器を通すか、しっかり沸騰させてカルキ臭を抜きます。
- 抽出したコーヒーの約98％以上は水なので、**水の質は味に大きく影響** します。

> **ここを覚える**
> - 透過式（ドリップ）・浸漬式（フレンチプレス・サイフォン）・加圧式（エスプレッソ）・煮出し式（トルココーヒー）
> - ゴールデンカップ：抽出収率約18〜22％、濃度約1.15〜1.35％
> - メリタ＝1つ穴（1908年メリタ・ベンツ、元祖）、カリタ＝3つ穴、ハリオV60＝円すい（2004年）、コーノ＝円すい
> - ペーパードリップ：中細挽き・10〜12g・85〜95℃（浅煎りは高め、深煎りは低め）・蒸らし20〜30秒・「の」の字・落とし切らない
> - ネル＝まろやか（水につけて冷蔵）、フレンチプレス＝粗挽き・4分・オイル、サイフォン＝浸漬式
> - エスプレッソ＝約9気圧・約25〜30秒・クレマ
> - 急冷式＝粉を1.5〜2倍・氷に落とす
> - 細かい・高温・長時間・粉が多い＝濃く苦い。一度に1つだけ変える
> - 軟水が向く

# 第9章 エスプレッソメニューとラテアート

## 9-1 エスプレッソの基本

**エスプレッソ（espresso）** は、イタリア語で「**急行（エクスプレス）**」「特別に（あなたのために）」などの意味があるといわれ、**圧力をかけて短時間で抽出した濃いコーヒー** です。

**エスプレッソマシンの歴史**

| 年 | 出来事 |
|---|---|
| 1884年 | イタリア・トリノの **アンジェロ・モリオンド** が、蒸気を使ったコーヒーマシンの特許を取ったとされる |
| 1901年 | ミラノの **ルイジ・ベゼラ** が、1杯ずつ短時間で抽出するマシンを改良・特許化 |
| 1948年 | **アキーレ・ガジア** が、**レバー式** で高い圧力をかけるマシンを開発し、表面に **クレマ** ができるエスプレッソが広まった |

**おいしいエスプレッソの目安**

| 項目 | 目安 |
|---|---|
| 粉の量 | シングル約7〜10g、**ダブル約14〜20g** |
| 挽き方 | 極細〜細挽き |
| 圧力 | **約9気圧** |
| 湯の温度 | 約90〜96℃ |
| 抽出時間 | **約25〜30秒** |
| 抽出量 | シングル約25〜30ml |
| **クレマ** | 表面の **きめ細かい泡の層**。ヘーゼルナッツ色〜赤茶色で、しっかりした厚みがあるのが良いとされる。**新鮮な豆** ほどクレマが豊か |

**タンピング**　ホルダー（ポルタフィルター）に入れた粉を、**タンパーで均一に押し固める** 作業です。ムラがあると、湯が通りやすい部分だけに流れ（**チャネリング**）、味が薄くなったり雑味が出たりします。

**抽出の調整**

| 状態 | 原因 | 調整 |
|---|---|---|
| 抽出が速すぎる（20秒未満など） | 挽き目が粗い、粉が少ない、タンピングが弱い | 細かく挽く、粉を増やす |
| 抽出が遅すぎる（35秒超など） | 挽き目が細かい、粉が多い | 粗く挽く、粉を減らす |

## 9-2 エスプレッソを使ったメニュー

| メニュー | 内容 |
|---|---|
| **エスプレッソ** | 約30mlの濃いコーヒー。**デミタスカップ** で。砂糖を入れてかき混ぜて飲むことも多い |
| **ドッピオ** | エスプレッソの **ダブル**（2杯分） |
| **リストレット** | 抽出量を **少なく** した、より **濃い** エスプレッソ（「制限された」の意味） |
| **ルンゴ** | 抽出量を **多く** したエスプレッソ（「長い」の意味） |
| **カフェ・アメリカーノ** | エスプレッソを **お湯で割った** もの |
| **カプチーノ** | エスプレッソ＋スチームミルク＋**厚めのミルクフォーム**。伝統的には、**エスプレッソ・ミルク・泡が約1：1：1**。名前は、カプチン会の修道士の服の色に似ていることに由来するといわれる |
| **カフェラテ** | エスプレッソ＋**たっぷりのスチームミルク**＋薄いフォーム。**カプチーノよりミルクが多い**（「ラテ」はイタリア語で牛乳） |
| **カフェ・マキアート** | エスプレッソに **少量のミルクフォーム** をのせたもの（「マキアート」は「**しみをつけた**」の意味） |
| **ラテ・マキアート** | 温めたミルクに **エスプレッソを注いで**、層を作ったもの（ミルクにエスプレッソの「しみ」） |
| **フラットホワイト** | **オーストラリア・ニュージーランド** 発祥とされる。エスプレッソに、**きめ細かく薄い（平らな）フォーム** のミルク。カフェラテよりミルクが少なく、コーヒーの味が強い |
| **カフェ・モカ** | カフェラテ＋**チョコレートソース**（モカの名前は、チョコレートのような風味のモカコーヒーに由来するとされる） |
| **キャラメル・マキアート** | ラテ・マキアートにバニラシロップとキャラメルソース |
| **コン・パンナ** | エスプレッソに **ホイップクリーム** をのせたもの |
| **アフォガート** | **バニラアイスにエスプレッソをかけた** デザート（「溺れた」の意味） |
| **エスプレッソ・トニック** | トニックウォーターにエスプレッソを注いだもの |

**エスプレッソを使わないミルク入りコーヒー**

| メニュー | 内容 |
|---|---|
| **カフェオレ** | **ドリップコーヒー＋温めた牛乳**（約1：1）。**フランス** 発祥。ボウルで飲むことも |
| **カフェ・コン・レチェ** | スペインのミルク入りコーヒー |
| **ウィンナーコーヒー** | 濃いコーヒーにホイップクリームをのせたもの。日本での呼び名で、オーストリアのウィーンでは、似た飲み物を「アインシュペナー」などと呼ぶ |

## 9-3 ミルクのスチーミング

| 手順 | 内容 |
|---|---|
| 準備 | **冷たい牛乳**（約3〜5℃）を、ミルクピッチャーの **注ぎ口の下あたりまで**（約1/3〜半分）入れる。スチームノズルを空ぶかしして、中の水を出す |
| ① ストレッチ（空気を入れる） | ノズルの先を **牛乳の表面すれすれ** に入れ、「チュッ、チュッ」と音を立てながら **空気を入れて泡を作る**。牛乳の量が増えていく |
| ② ロール（きめを整える） | ノズルを少し **沈め**、ピッチャーを傾けて **うずを作り**、大きな泡を細かくしながら **温める** |
| 仕上げ | 温度が **約60〜65℃** になったら止める。ノズルを湿った布でふき、空ぶかしする。ピッチャーを台に軽く打ちつけ、回して、泡と液体をなじませる |

- **約70℃を超えると、牛乳の甘みが減り、においが出やすく** なります（たんぱく質が変化する）。
- 理想は、つやがあり、液体のようになめらかに流れる **きめ細かい泡（マイクロフォーム）** です。
- 牛乳は **冷たい状態** から始めると、泡を作る時間を長くとれます。
- **乳脂肪分** や **たんぱく質** の量で、泡立ちや味わいが変わります。豆乳・オーツミルクなどの植物性ミルクも使われます。

## 9-4 ラテアート

**ラテアートとは**　エスプレッソにスチームミルクを注いで、表面に **模様や絵を描く** 技術です。

| 種類 | 方法 | 代表的な絵柄 |
|---|---|---|
| **フリーポア** | **ミルクピッチャーから注ぐミルクの動きだけ** で模様を描く | **ハート**、**リーフ（ロゼッタ）**、**チューリップ**、スワン |
| **エッチング** | **ピック**（竹串のような道具）で、泡の表面に線を描いたり、チョコレートソースなどで描いたりする | 動物、キャラクター、花、文字 |
| **デザインカプチーノ（3Dラテアート）** | **泡を盛り上げて立体的な形** を作る | 立体の動物、キャラクター |

**フリーポアの基本の流れ（ハート）**

1. カップを手前に傾け、**少し高い位置から細く** 注いで、エスプレッソとミルクをなじませる（**ベース** を作る）。クレマの下にミルクを潜り込ませるイメージ。
2. カップの **半分〜6分目** ほどになったら、ピッチャーの注ぎ口を **カップの液面に近づけ**、注ぐ量を **増やす** と、表面に **白い円** が浮かぶ。
3. カップを少しずつ水平に戻しながら、円を大きくする。
4. 円が広がったら、ピッチャーを **持ち上げて細く注ぎながら**、**円を切るように手前から奥へ** 抜く → ハートの形になる。

**リーフ（ロゼッタ）**　白い模様が浮かんだら、ピッチャーを **左右に小刻みに振りながら後ろに下がり**、最後に手前から奥へ切るように抜く。

**チューリップ**　**白い円を少しずつ重ねて押し出す** ように何段か注ぎ、最後に切るように抜く。

**きれいに描くためのポイント**

| ポイント | 理由 |
|---|---|
| **新鮮なエスプレッソ**、**クレマ** がしっかりあること | クレマがキャンバスになる。茶色と白のコントラスト |
| **きめ細かいミルクフォーム（マイクロフォーム）** | 大きな泡があると描けない |
| ミルクとエスプレッソを **すぐに** 合わせる | 時間がたつと、ミルクが泡と液体に分離し、クレマも消える |
| **注ぐ高さ・速さ・位置** を調整する | 高いとミルクは沈み、低く近いと表面に白く浮かぶ |
| **カップの形** | 口が広く、底が丸いカップが描きやすい |
| 練習 | 水と洗剤の泡で練習する方法もある |

> **ここを覚える**
> - エスプレッソ＝約9気圧・約25〜30秒・クレマ。タンピング（ムラがあるとチャネリング）
> - 1948年 ガジアのレバー式でクレマのあるエスプレッソが広まった
> - リストレット＝少なく濃い、ルンゴ＝多く、ドッピオ＝ダブル、アメリカーノ＝お湯で割る
> - カプチーノ＝泡が多い（1：1：1）、カフェラテ＝ミルクが多い、マキアート＝少量の泡（しみ）、フラットホワイト＝薄く平らな泡（豪・NZ）
> - カフェオレ＝ドリップ＋牛乳（フランス）、アフォガート＝アイス＋エスプレッソ
> - スチーミング：ストレッチ→ロール、約60〜65℃（70℃超で甘みが減る）、マイクロフォーム
> - フリーポア（ハート・リーフ・チューリップ）／エッチング（ピック）／3Dラテアート

# 第10章 コーヒーカップの種類

## 10-1 カップの種類

| 種類 | 容量（目安） | 特徴・用途 |
|---|---|---|
| **デミタスカップ** | 約60〜90ml | 「**デミ＝半分**」「**タス＝カップ**」（フランス語）。**エスプレッソ** 用。**厚手で、冷めにくい**（少量のエスプレッソの温度を保つ）。小さな受け皿とスプーン |
| **コーヒーカップ（レギュラーカップ）** | 約120〜150ml | 一般的なコーヒー用。**口が狭めで、高さがある（筒形）** ものが多く、**冷めにくい** |
| （比較）**ティーカップ** | 約150〜200ml | 紅茶用。**浅く、口が広い**。香りが広がり、**水色（紅茶の色）が見やすい** |
| **カプチーノカップ** | 約150〜200ml | **口が広く、丸みがある**（底も丸い）。**泡をのせやすく、ラテアートを描きやすい**。厚手で保温性がある |
| **ラテカップ・ラテボウル** | 約250〜350ml | カフェラテ用。大きめ |
| **カフェオレボウル** | 約250ml〜 | **取っ手のないボウル型**。フランスの朝食で、パンを浸して食べることも |
| **マグカップ** | 約250〜350ml | **取っ手つき、受け皿なし**。たっぷり飲むときに。カジュアル |
| **グラス** | ── | **アイスコーヒー**、**ラテ・マキアート**（層を見せる）。**耐熱ガラス** や、**二重構造（ダブルウォール）** のグラスも |
| **カッピングボウル** | 約150〜250ml | カッピング（評価）用。口が広い |

## 10-2 カップの形と味の感じ方

| 形 | 感じ方の傾向 |
|---|---|
| **口が広い** | **香りが広がりやすい**。冷めやすい |
| **口が狭い（すぼまっている）** | **香りがこもり、冷めにくい** |
| **飲み口が薄い** | すっきり、**繊細** に感じやすい。酸味や香りを感じやすい |
| **飲み口が厚い** | **まろやか**、やさしく感じやすい。口当たりがやわらかい |
| **背が高い** | 冷めにくい |
| **白いカップ（内側）** | コーヒーの **色（濃さ・透明感）が見やすい** |

※感じ方には個人差があります。

## 10-3 素材の種類

| 素材 | 特徴 |
|---|---|
| **磁器** | 白く、硬く、**薄くても丈夫**。**水を吸わない**。色やにおいがつきにくい。たたくと高く澄んだ音 |
| **ボーンチャイナ** | **牛の骨の灰** を混ぜた磁器。**白く透明感** があり、軽くて丈夫。**イギリス発祥** |
| **陶器** | 土の風合い。**厚手で温かみ** があり、**保温性が高い**。水を吸いやすい（使う前に水にくぐらせると、しみがつきにくい）。たたくと鈍い音 |
| **炻器（せっき）** | 陶器と磁器の中間の性質 |
| **ガラス** | コーヒーの **色が見える**。アイスコーヒーやラテ・マキアート向き。**耐熱ガラス** を使う |
| **ステンレス（真空断熱）** | **保温性・保冷性が高い**。割れにくく、持ち運び向き（タンブラー） |
| 紙・プラスチック | テイクアウト用 |

## 10-4 カップの扱い方・提供のしかた

| ポイント | 内容 |
|---|---|
| **カップを温める** | 温かいコーヒーは、**カップに湯を注いで温めてから** 注ぐと冷めにくい。エスプレッソマシンの上（カップウォーマー）で温めることも |
| **アイスはグラスを冷やす** | 冷やしたグラスに注ぐ |
| **取っ手の向き** | 取っ手を **右側** にそろえて出すことが多い（お客様が右手で持ちやすい）。左側にして出す習慣もあり、店や地域によって違う |
| **スプーン** | ソーサーに添える（取っ手と同じ側、またはカップの手前） |
| **注ぐ量** | カップの約8分目程度 |
| **シュガー・ミルク** | 別の器で添える |

> **ここを覚える**
> - デミタス＝「半分のカップ」（フランス語）、エスプレッソ用、厚手
> - コーヒーカップ＝口が狭め・高さがあり冷めにくい／ティーカップ＝浅く口が広い（香り・水色）
> - カプチーノカップ＝口が広く丸い（泡・ラテアート）、カフェオレボウル＝取っ手なし（フランス）
> - 口が広い＝香りが広がる・冷めやすい、飲み口が薄い＝繊細、厚い＝まろやか
> - 磁器＝水を吸わない、ボーンチャイナ＝牛の骨灰（イギリス）、陶器＝保温性
> - カップは温めてから注ぐ

# 第11章 香りと味わいの評価

## 11-1 コーヒーの味わいを表す言葉

| 言葉 | 意味 |
|---|---|
| **フレグランス** | **挽いた粉（乾いた状態）の香り** |
| **アロマ** | **湯を注いだ後（液体）の香り** |
| **フレーバー** | **口に含んだときの香りと味の総合的な印象**（鼻に抜ける香りを含む） |
| **アシディティ（酸味）** | **明るさ、さわやかさ、いきいきとした感じ**。良い酸味は「**フルーティー**」「**ジューシー**」「かんきつのよう」「ベリーのよう」などと表現する。悪い酸味（酸っぱい、刺激的）とは区別する |
| **ボディ（コク）** | **口の中で感じる重さ、とろみ、質感**（マウスフィール）。「軽い」「重い」「シルキー」「クリーミー」など |
| **アフターテイスト** | **飲み込んだ後に残る味と香り** の長さと質 |
| **スウィートネス（甘さ）** | 自然な甘みの感じ |
| **クリーンカップ** | **雑味やにごり、欠点の風味がない** こと |
| **バランス** | 味の要素どうしの **調和** |
| **ビターネス（苦み）** | 苦み。質の良い苦みと、えぐみのある苦みがある |

**香りを表す言葉の例**

| 系統 | 例 |
|---|---|
| フルーティー | ベリー、かんきつ（レモン・オレンジ）、りんご、ぶどう、トロピカルフルーツ |
| フローラル | ジャスミン、バラ、紅茶のような |
| 甘い香り | キャラメル、はちみつ、黒糖、バニラ |
| ナッツ・ココア | アーモンド、ヘーゼルナッツ、チョコレート、ココア |
| スパイス | シナモン、クローブ、こしょう |
| ロースト | 香ばしい、トースト、スモーキー |
| 好ましくない香り（欠点） | 土臭い、カビ臭い、発酵臭、ゴム臭、薬品臭、焦げ臭 |

## 11-2 フレーバーホイール

**フレーバーホイール** は、コーヒーの香りや味を表す言葉を **円形に整理した図** です。中心の大まかな分類（例：「フルーティー」）から、外側の細かい言葉（例：「ベリー」→「ブルーベリー」）へとたどって、感じた風味を言葉にするために使います。アメリカのスペシャルティコーヒー協会（現在のSCA）とワールド・コーヒー・リサーチが2016年に改訂したものがよく知られています。

## 11-3 カッピング

**カッピング** は、コーヒーの **品質や風味の特徴を評価するための、決まった手順のテイスティング方法** です。生豆の買い付け、焙煎の確認、ブレンドづくりなどで行われます。

**一般的な手順（SCAの方式をもとにした一例）**

| 順 | 手順 | 内容 |
|---|---|---|
| 準備 | 焙煎 | **浅煎り〜中煎り**（豆の個性や欠点が分かりやすい）。焙煎後8〜24時間程度おく |
| 準備 | 分量 | 湯150mlに対して粉 **約8.25g**（約1：18）。挽き目はペーパードリップよりやや粗め。同じ豆で数カップ用意する（均一性を見る） |
| ① | **フレグランス** | 挽いた直後の **粉の香り** を確かめる |
| ② | 注湯 | **約93℃** の湯を、粉全体が湿るように注ぐ |
| ③ | 待つ | 表面に粉の層（**クラスト**）ができる。**約3〜5分**（一般に約4分）待つ |
| ④ | **ブレイク** | スプーンで **クラストを崩し**、立ち上る **アロマ** を確かめる |
| ⑤ | すくい取る | 表面の泡や浮いた粉を **取り除く** |
| ⑥ | **すする** | 液温が約70℃前後に下がったら、スプーンですくい、「**ズズッ**」と **勢いよくすすって**、霧状にして口全体に広げて味わう（香りが鼻に抜け、風味を感じやすい） |
| ⑦ | 評価 | **温度が下がるにつれての変化** も確かめ、評価シートに記録する。スプーンはカップごとに洗う（湯ですすぐ） |

**評価項目の例**　フレグランス／アロマ、フレーバー、アフターテイスト、アシディティ（酸味）、ボディ、バランス、スウィートネス（甘さ）、クリーンカップ、ユニフォミティ（均一性）、総合評価

## 11-4 スペシャルティコーヒー

**スペシャルティコーヒー** とは、**生産地（種子）からカップ（飲む人）まで、すべての段階で品質がしっかり管理された、風味の個性がはっきりした高品質なコーヒー** のことです。**From Seed to Cup（種からカップまで）** という言葉で表されます。

| 項目 | 内容 |
|---|---|
| 代表的な団体 | **SCA（スペシャルティコーヒー協会）**：2017年に、アメリカのSCAAとヨーロッパのSCAEが統合してできた。日本には **SCAJ（日本スペシャルティコーヒー協会）** がある |
| 従来の評価 | SCA（旧SCAA）の **100点満点のカッピング評価** で、**80点以上** のものがスペシャルティコーヒーとされてきた |
| **最近の変化** | SCAは **2024年11月**、新しい評価方式「**コーヒー・バリュー・アセスメント（CVA）**」の規格を採用し、2004年からの100点方式の評価用紙と手順を置き換えた。CVAは、**生豆の物理的な評価、風味の記述的な評価（どんな風味か、強さ）、好ましさの評価（点数）、カップ以外の要素（トレーサビリティ・認証など）の評価** の4つに分けて、コーヒーの価値を多面的に表す |
| 品評会 | **カップ・オブ・エクセレンス（COE）**：生産国ごとに、その年の最高品質のコーヒーを選ぶ国際的な品評会。入賞したコーヒーはオークションで取引される（1999年にブラジルで始まった） |
| 鑑定士 | **Qグレーダー**：CQI（コーヒー品質協会）が認定する、コーヒーの品質を評価する国際的な資格 |

> **注意**　「80点以上＝スペシャルティ」という基準は長く使われてきましたが、評価方式の見直しが進んでいます。最新の基準は、SCAなどの公式情報で確認しましょう。

**コマーシャルコーヒー**　スペシャルティコーヒーに対して、一般に流通している、価格の安定や大量供給を重視したコーヒーのことです。

## 11-5 認証のあるコーヒー

| 認証 | 内容 |
|---|---|
| **フェアトレード** | 生産者に **適正な価格** を支払い、生活や労働環境の改善を目指す |
| **有機（オーガニック）** | 化学合成農薬や化学肥料を使わない方法で栽培。日本では **有機JAS** マーク |
| **レインフォレスト・アライアンス** | 森林や生態系の保護、労働者の権利などに配慮 |
| **バードフレンドリー** | 渡り鳥が休める森（シェードツリー）を守る農法 |

> **ここを覚える**
> - フレグランス＝粉の香り、アロマ＝液体の香り、フレーバー＝口に含んだときの総合印象
> - アシディティ＝明るい酸味、ボディ＝口の中の重さ・質感、クリーンカップ＝雑味がない
> - フレーバーホイール＝風味の言葉を円形に整理した図
> - カッピング：150mlに約8.25g、約93℃、約4分でブレイク、すすって評価
> - スペシャルティ＝From Seed to Cup。従来は80点以上。SCAは2024年11月に新方式CVAを採用
> - COE＝国ごとの品評会、Qグレーダー＝品質評価の資格
> - フェアトレード＝適正な価格

# 第12章 世界のコーヒー文化とコーヒーと健康

## 12-1 世界のコーヒー文化

| 国・地域 | 文化 |
|---|---|
| **エチオピア** | **コーヒーセレモニー** ── 生豆を洗ってその場で **煎り**、すりつぶし、「**ジェベナ**」という素焼きのポットで **煮出して**、何杯もふるまう、**おもてなしの儀式**。乳香をたいたり、ポップコーンを添えたりする。3杯飲むのが礼儀とされることも |
| **トルコ** | **ジェズベ（イブリック）** という小さな柄付きの鍋で、**とても細かい粉** を水（と砂糖）と一緒に煮出し、**粉が沈んでから上澄みを飲む**。飲み終わったカップをひっくり返し、残った粉の模様で **占い** をする習慣も。**トルココーヒーの文化と伝統** は、**2013年にユネスコの無形文化遺産** に登録された |
| **イタリア** | **バール** で、エスプレッソを **立ったまま素早く** 飲む。朝はカプチーノとパン（コルネット）。昼過ぎ以降はミルク入りを控える習慣があるといわれる |
| **フランス** | **カフェ** で長く過ごす文化。朝食に **カフェオレ** をボウルで |
| **オーストリア（ウィーン）** | 伝統的な **カフェハウス** 文化。新聞を読んだり、長居したりできる。ウィーンのカフェハウス文化は、**オーストリアの国内のユネスコ無形文化遺産リスト** に登録されている。ホイップクリームをのせたコーヒー（アインシュペナーなど） |
| **アメリカ** | マグカップでたっぷり飲む。**シアトル系** のコーヒーチェーン、**サードウェーブ** の発祥地の一つ |
| **ベトナム** | **フィン** という金属のフィルターで、深煎りのコーヒー（ロブスタが多い）を濃く淹れ、**練乳（コンデンスミルク）** を入れて飲む。卵を泡立てて加える「エッグコーヒー」も |
| **北欧** | 1人あたりのコーヒー消費量が多い国が多い。スウェーデンの「**フィーカ**」（コーヒーとお菓子で休む時間） |
| **ブラジル** | 生産国でありながら、消費量も多い。小さなカップで甘くした「**カフェジーニョ**」 |
| **スペイン** | カフェ・コン・レチェ、カフェ・コルタード |
| **ギリシャ** | 冷たい泡立てたコーヒー「フラッペ」 |
| **アイルランド** | **アイリッシュコーヒー**（アイリッシュウイスキー・砂糖・コーヒー・生クリーム） |
| **インド** | 南インドのフィルターコーヒー（ミルクと砂糖で甘く、高い位置から注いで泡立てる） |
| **日本** | **喫茶店文化**、**缶コーヒー** と **自動販売機**、**ハンドドリップ**（ペーパー・ネル）の技術、サイフォンの普及、コンビニコーヒー |

## 12-2 コーヒーの成分

| 成分 | 特徴 |
|---|---|
| **カフェイン** | **苦み** の一部。**覚醒作用**（眠気を覚ます）、**利尿作用** など |
| **クロロゲン酸**（ポリフェノールの一種） | 生豆に多い。**焙煎が進むと分解されて減る**。抗酸化作用などが研究されている |
| トリゴネリン | 焙煎でニコチン酸（ナイアシン）などに変わる |
| 香り成分 | 焙煎で生まれる。数百〜1,000種類以上ともいわれる |
| 脂質（コーヒーオイル） | 金属フィルターやフレンチプレスでは液に多く出る |

## 12-3 コーヒーと健康

**カフェインの量（目安）**

| 飲み物 | カフェイン（100mlあたり） |
|---|---|
| **コーヒー（ドリップ）** | **約60mg**（日本食品標準成分表（八訂）の浸出液の値） |
| インスタントコーヒー（粉2gを湯140mlで溶いた場合） | 約57mg（成分表の粉末の値 100gあたり約4.0gから計算した目安） |
| 玉露 | 約160mg |
| 紅茶 | 約30mg |
| 煎茶 | 約20mg |

- エスプレッソは **1杯の量は少ない** ですが、100mlあたりの濃度は高くなります。
- **デカフェ（カフェインレス）** ── カフェインを取り除いたコーヒー。欧州（EU）ではカフェインを **99.9％以上** 除いたものなどの基準があり、日本では「カフェインレス」は **90％以上** 除いたものとする業界の考え方があります（詳しい基準は表示を確認）。カフェインを取り除く方法には、**水を使う方法（スイスウォーター）**、**超臨界二酸化炭素** を使う方法、有機溶媒を使う方法があります。

**カフェインの摂取量の目安（海外機関の例）**

| 対象 | 1日の目安 |
|---|---|
| 健康な成人 | **約400mgまで**（欧州食品安全機関（EFSA）、カナダ保健省など）。コーヒーにすると、マグカップ（約240ml）で3杯程度 |
| 妊娠中・授乳中の女性 | **約200mgまで**（EFSAなど） |
| 子ども | 体重に応じて、より少なく |

※日本では、カフェインの摂取量について国としての基準は定められていません（2026年10月時点で確認できた範囲）。

**とりすぎに注意**　カフェインをとりすぎると、**眠れない、心拍数が上がる、胃の不快感、不安感** などが起こることがあります。エナジードリンクなどとあわせてとるときは、合計量に注意しましょう。

> **注意**　コーヒーの健康効果は、研究段階のものも多く、薬ではありません。お客様に説明するときは「〜と言われています」「〜が研究されています」のように、**言い切らない表現** を使いましょう。

## 12-4 コーヒーソムリエとしての接客

| 場面 | ポイント |
|---|---|
| 好みを聞く | 「**酸味** が好きか、**苦み** が好きか」「**軽い** のが好きか、**しっかり** が好きか」「ミルクを入れるか」 |
| 豆を提案する | 酸味派 → エチオピア・ケニアの浅〜中煎り。苦み派 → マンデリン・深煎り。バランス派 → ブラジル・コロンビアの中煎り |
| 挽き方を確認する | **お客様の抽出器具** を聞いて、合った挽き方にする |
| 保存方法を伝える | 豆のまま、密閉、冷暗所、早めに |
| 淹れ方を伝える | 湯温・粉の量・蒸らし |
| 健康のこと | 言い切らない |

> **ここを覚える**
> - エチオピア＝コーヒーセレモニー（ジェベナ）、トルコ＝ジェズベで煮出す・占い・2013年ユネスコ無形文化遺産
> - イタリア＝バールで立ち飲み、フランス＝カフェオレ、ウィーン＝カフェハウス、ベトナム＝フィン＋練乳、スウェーデン＝フィーカ
> - カフェイン：コーヒー100mlあたり約60mg（成分表）
> - 成人は1日約400mgまで、妊娠中は約200mgまで（EFSAなど）
> - クロロゲン酸＝ポリフェノール、焙煎で減る
> - デカフェ＝カフェインを取り除いたコーヒー

# 模擬試験 第1回

※以下はこの教科書で作成した **オリジナル問題** です。実際の試験問題ではありません。受験者の紹介に合わせて「記述10問＋○×10問・45分」の形にしています。14問以上の正解を目標にしましょう。

## 記述問題

1. コーヒーの木（アラビカ種）の原産地とされる国を答えなさい。
2. 1888年に東京に開かれた、日本初の本格的な喫茶店とされる店の名前を答えなさい。
3. コーヒーの木は何科の植物か答えなさい。
4. コーヒーの実の中で、種が1粒だけ丸く育った豆を何というか答えなさい。
5. 世界最大のコーヒー生産国を答えなさい。
6. 「ブルーマウンテン」が作られている国を答えなさい。
7. エチオピア（イエメン）のモカとインドネシアのジャワを合わせた、世界最古といわれるブレンドの名前を答えなさい。
8. 焙煎の8段階のうち、シティローストの次に深い焙煎度を答えなさい。
9. エスプレッソの表面にできる、きめ細かい泡の層を何というか答えなさい。
10. ピックなどで泡の表面に線を描いて模様を作るラテアートを何というか答えなさい。

## ○×問題

1. アラビカ種は、ロブスタ種より病気に強く、低地でもよく育つ。
2. ロブスタ種は、インスタントコーヒーや缶コーヒーによく使われる。
3. 浅煎りのコーヒーは酸味が強く、深煎りのコーヒーは苦みが強い傾向がある。
4. ペーパードリップには、粗挽きの粉が最も適している。
5. フレンチプレスは、粉を湯に浸して成分を出す「浸漬式」の器具である。
6. メリタのドリッパーは、穴が3つある。
7. 挽き方を細かくし、湯の温度を高くすると、成分が出やすく苦みが強くなる。
8. カフェラテのミルクは、80℃以上に温めると甘みが増しておいしくなる。
9. デミタスカップは、主にエスプレッソを飲むときに使う。
10. コーヒー豆は、粉にして保存するほうが、豆のまま保存するより長持ちする。

# 模擬試験 第2回

## 記述問題

1. ヤギが赤い実を食べて跳ね回るのを見て、コーヒーを発見したという伝説のヤギ飼いの名前を答えなさい。
2. 「コーヒー」という言葉の語源とされる、アラビア語の言葉を答えなさい。
3. 1804年、オランダ船でコーヒーを飲み、「焦げくさくて味わうに堪えない」という意味の感想を書き残した日本の文人を答えなさい。
4. 全日本コーヒー協会が制定した「コーヒーの日」は何月何日か答えなさい。
5. 果肉を取り除き、水槽で発酵させてから水で洗い流して乾燥させる精製方法を何というか答えなさい。
6. インドネシア・スマトラ島で作られる、苦みと重いコクが特徴の銘柄を答えなさい。
7. 「キリマンジャロ」が作られている国を答えなさい。
8. 生豆を焙煎する前に混ぜてから一緒に焙煎するブレンドの方法を何というか答えなさい。
9. 1908年にドイツで、ペーパードリップを考案した人物の名前を答えなさい。
10. エスプレッソに少量のミルクフォームをのせた飲み物を何というか答えなさい。

## ○×問題

1. コーヒーベルトとは、主に赤道をはさんで北緯25度〜南緯25度あたりの、コーヒー栽培に適した地域のことである。
2. ナチュラル（乾燥式）は、実をそのまま乾燥させる精製方法で、甘くフルーティーな味になりやすい。
3. ブラジルの生豆の等級「No.2」は、欠点豆が最も多い等級である。
4. 標高の高い所でとれた硬い豆は、熱が中まで伝わりにくく、幅広い焙煎に耐えられる。
5. 1ハゼは「ピチピチ」と細かい音、2ハゼは「パチッ」と大きな音がする。
6. ペーパードリップでは、最後の1滴まで落とし切るのが良い。
7. サイフォンは、浸漬式の抽出器具である。
8. アイスコーヒーを急冷式で作るときは、通常より粉を多くして濃く淹れる。
9. カプチーノは、カフェラテより泡（フォーム）が多い。
10. コーヒーには、一般に軟水が向いているといわれる。

# 模擬試験 第3回

## 記述問題

1. コーヒーのさび病の大流行で、コーヒーの栽培から紅茶の栽培に転換した国（現在の国名）を答えなさい。
2. ロンドンのコーヒーハウスが「1ペニーで知識が得られる場所」として呼ばれた名前を答えなさい。
3. 1727年ごろにコーヒーが伝わり、のちに世界最大の生産国となった国を答えなさい。
4. 焙煎すると「チャフ」としてはがれる、生豆に張りついた薄い皮を何というか答えなさい。
5. エチオピアのゲシャ地区の野生種が由来とされ、パナマで高い評価を受けた、花のような香りの品種を答えなさい。
6. 焙煎の前後に、手で欠点豆や異物を取り除く作業を何というか答えなさい。
7. ペーパードリップで、最初に少量の湯を注いでガスを抜き、粉と湯をなじませる工程を何というか答えなさい。
8. エスプレッソマシンで抽出するとき、粉を均一に押し固める作業を何というか答えなさい。
9. カッピングで、表面にできた粉の層をスプーンで崩して香りを確かめることを何というか答えなさい。
10. エチオピアで、生豆をその場で煎って煮出し、何杯もふるまうおもてなしの儀式を何というか答えなさい。

## ○×問題

1. ロブスタ（カネフォラ）種のカフェインは、アラビカ種の約2倍とされる。
2. ウォッシュト（水洗式）は、すっきりとしたきれいな酸味になりやすい。
3. 焙煎が深くなるほど、クロロゲン酸は増える。
4. 深煎りの豆は、浅煎りの豆よりカフェインが大幅に多い。
5. プロペラ式のミルは、粒の大きさがそろいやすい。
6. ネルドリップのネル（布）は、使った後に乾燥させて保管するのが良い。
7. 抽出収率が低すぎると、薄く、酸っぱく、物足りない味になりやすい。
8. フラットホワイトは、オーストラリア・ニュージーランド発祥とされる。
9. トルココーヒーの文化と伝統は、ユネスコの無形文化遺産に登録されている。
10. SCAは2024年に、新しい評価方式「コーヒー・バリュー・アセスメント（CVA）」を採用した。

# 付録3 精査メモと参考情報

## 第1版からの主な訂正・補足

| 項目 | 第1版 | 第2版（訂正後） |
|---|---|---|
| 試験日程 | 2か月に1回（偶数月）、試験期間5日間 | **随時受験**（試験期間・申込期間がなくなったと紹介されている） |
| スペシャルティの評価 | 「SCAの評価で80点以上（評価方式は見直しが進んでいる）」 | **SCAは2024年11月に新評価方式CVAを採用し、2004年からの100点方式を置き換えた** と明記 |
