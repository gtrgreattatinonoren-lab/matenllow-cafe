# 第1章 カップケーキの歴史と基礎知識

## 1-1 カップケーキとは

カップケーキは、**紙やアルミのカップ（ベーキングカップ）、または小さな型に生地を入れて焼く、1人分の小さなケーキ** です。焼いた後に **フロスティング（クリーム）やトッピング** でデコレーションするのが特徴です。

**カップケーキの魅力**

- **1人分ずつ** で、切り分ける必要がない
- **手で持って食べられる**
- 小さいので **焼き時間が短い**
- デコレーションで **見た目のバリエーション** が無限に広がる
- パーティー、イベント、ギフトに向く

## 1-2 カップケーキの歴史

| 年代 | 出来事 |
|---|---|
| **1796年** | アメリカで出版された料理本『**アメリカン・クッカリー（American Cookery）**』（**アメリア・シモンズ** 著）に、「**小さなカップで焼く軽いケーキ（a light cake to bake in small cups）**」というレシピがある。これが、現在のカップケーキにあたるものの **現存する最も古い記述** とされる |
| **1828年** | **イライザ・レスリー** の料理本『Seventy-five Receipts for Pastry, Cakes, and Sweetmeats』に、「**カップケーキ（cup cake）**」という **言葉** が記されている。これが、この言葉の現存する最も古い記録とされる |
| 19世紀 | アメリカで、カップ（器）で焼くケーキや、カップで量って作るケーキが広まる。オーブンの改良や、マフィン型の普及も後押しした |
| 19世紀後半〜 | ベーキングパウダーの普及で、手軽にふくらむケーキが作れるようになる |
| **1919年** | アメリカで、のちの「**ホステス・カップケーキ**」が発売される（発売したのは当時の製パン会社で、「ホステス」ブランドになったのはその後とされる）。市販のカップケーキとして広く知られる |
| 20世紀 | 紙のベーキングカップが普及し、家庭や学校のパーティーの定番になる |
| **2000年代** | ニューヨークの **マグノリア・ベーカリー** が、テレビドラマ『**セックス・アンド・ザ・シティ**』（2000年の回）に登場したことなどをきっかけに、**カップケーキの大ブーム** が起こったといわれる。カップケーキ専門店が次々と生まれた |
| 2000年代後半〜2010年代 | 日本でもカップケーキ専門店が増え、デコレーションカップケーキが人気に |

## 1-3 名前の由来（2つの説）

| 説 | 内容 |
|---|---|
| **焼く容器の説** | 陶器の **カップ（器）** やマグに生地を入れて焼いたから |
| **計量の説** | 材料を **カップで量って** 作ったから。当時は、材料を重さで量る方法が主流だったが、カップで量ることで手軽に作れるようになった |

**ナンバーケーキ（1-2-3-4ケーキ）**　「バター1カップ・砂糖2カップ・小麦粉3カップ・卵4個」のように、**材料の量を数字の順番で覚えられる** ケーキがあり、「ナンバーケーキ」「1-2-3-4ケーキ」と呼ばれました。カップケーキの「カップ」は、このような **カップで量る** 作り方とも関係があるといわれます。

※どちらの説が正しいか、はっきりとは分かっていません。両方の意味があるとする見方もあります。

## 1-4 各国のカップケーキ

| 名前 | 国 | 特徴 |
|---|---|---|
| **カップケーキ** | アメリカ | たっぷりのフロスティングを高く絞り、華やかに飾る |
| **フェアリーケーキ** | イギリス | アメリカのものより **小さめ**。上に **アイシング** を塗り、スプリンクルなどで **シンプル** に飾る |
| **バタフライケーキ** | イギリス | ケーキの上部を丸く切り取り、それを半分に切って、クリームの上に **蝶の羽のように** のせる |
| パティ・ケーキ | オーストラリアなど | フェアリーケーキと同じようなもの |

## 1-5 カップケーキと似たお菓子とのちがい

| | カップケーキ | マフィン（アメリカ式） | マドレーヌ | フィナンシェ |
|---|---|---|---|---|
| 生地 | **バター生地**（ケーキに近い）。きめ細かく、ふんわり | 甘さ控えめ。ざっくりした食感 | 溶かしバターの生地 | 焦がしバター・アーモンドプードル・卵白 |
| 混ぜ方 | **シュガーバッター法** が多い | **マフィンメソッド**（粉類と液体を別々に混ぜて、さっくり合わせる） | 卵と砂糖に粉・溶かしバター | 同左 |
| 甘さ | 甘い（**デザート**） | 控えめ（朝食・軽食） | 甘い | 甘い |
| 仕上げ | **フロスティング・デコレーション** をする | ほとんどしない。具を **生地に混ぜ込む**。上にクランブルをのせることも | しない | しない |
| 型 | カップ（マフィン型＋紙カップ） | マフィン型 | 貝殻形 | 長方形（金塊形） |

※アメリカのマフィンはベーキングパウダーでふくらませる「**クイックブレッド**（発酵させずにすぐ焼けるパン・お菓子）」の一種です。イギリスの「イングリッシュマフィン」は **イーストで発酵** させるパンで、別のものです。

> **ここを覚える**
> - 発祥はアメリカ。1796年『アメリカン・クッカリー』（アメリア・シモンズ）に「小さなカップで焼く軽いケーキ」
> - 「cup cake」という言葉の最古の記録＝1828年 イライザ・レスリーの料理本
> - 1919年 ホステス・カップケーキ（市販品）、2000年代 マグノリア・ベーカリー（セックス・アンド・ザ・シティ）でブーム
> - 名前の由来＝「器のカップ」説と「計量カップ」説（ナンバーケーキ＝1-2-3-4ケーキ）
> - イギリス＝フェアリーケーキ（小さめ・アイシング）、バタフライケーキ（蝶の羽）
> - マフィンとの違い：カップケーキはバター生地＋フロスティング、マフィンはマフィンメソッド・甘さ控えめ

## 2-3 計量の基本

**重さ（g）で量るのが基本**

- 小麦粉は、ふるったものと詰めたものでは、同じ1カップでも重さが大きく違うため、**重さで量るほうが正確** です。

| 325℉ | 約163℃ |

# 第3章 基本のカップケーキのレシピ

## 3-1 基本のバニラカップケーキ（直径約7cmのカップ12個分・一例）

| 材料 | 分量 | 役割 |
|---|---|---|
| 無塩バター | 115g | コク・風味。空気を含んでふんわり |
| グラニュー糖 | 150g | 甘み・しっとり・焼き色・泡の安定 |
| 卵（Mサイズ） | 2個（殻なしで約100g） | ふくらみ、生地をつなぐ、乳化 |
| 薄力粉 | 180g | 生地の骨組み |
| ベーキングパウダー | 小さじ2（約6〜8g） | ふくらませる |
| 塩 | ひとつまみ | 甘みを引き立てる |
| 牛乳 | 120ml | しっとりさせる、生地をのばす |
| バニラオイル | 少々 | 香り（焼き菓子向き） |

**下準備**

1. **バター・卵・牛乳を常温に戻す**（バターは指で押すとすっと入る柔らかさ）。
2. **薄力粉・ベーキングパウダー・塩を合わせてふるう**。
3. マフィン型に **ベーキングカップ** を敷く。
4. オーブンを **170〜180℃に予熱** する。

**作り方（シュガーバッター法）**

1. ボウルにバターを入れ、泡立て器（ハンドミキサー）で **クリーム状** にする。
2. グラニュー糖を2〜3回に分けて加え、**白っぽくふんわりするまで** よく混ぜる（**クリーミング**：空気を含ませる）。
3. 溶いた卵を **少しずつ（5〜6回に分けて）** 加え、そのつどよく混ぜる（一度に入れると **分離** する）。バニラオイルを加える。
4. ふるった粉の **1/3** を加えてゴムベラでさっくり混ぜ、牛乳の **1/2** を加えて混ぜる。これを **「粉 → 牛乳 → 粉 → 牛乳 → 粉」** の順でくり返す（**粉で始まり粉で終わる**）。
5. 粉っぽさがなくなり、**つやが出たら混ぜ終わり**（**混ぜすぎない**）。
6. カップの **約6〜7分目（2/3程度）** まで生地を入れる。
7. 170〜180℃のオーブンで **約18〜22分** 焼く。
8. **竹串** を中心に刺して、**生地がついてこなければ** 焼き上がり。表面を指で軽く押して、弾力があれば良い。
9. すぐに型から出し、**ケーキクーラーの上で完全に冷ます**。
10. 冷めてからフロスティングを絞る。

> **ポイント（粉と牛乳を交互に入れる理由）**
> - 牛乳を一度に入れると、バターと水分が分かれて **分離** しやすい。
> - 粉を一度に入れると、混ぜるのに時間がかかり、**混ぜすぎ（グルテン）** の原因になる。
> - 交互に入れることで、**なめらかで均一な生地** になる。
> - 粉で始まり、粉で終わるのは、粉が水分を吸って分離を防ぐため。

## 3-2 ほかの生地の作り方

| 作り方 | やり方 | 仕上がり |
|---|---|---|
| **シュガーバッター法** | バター＋砂糖 → 卵 → 粉と牛乳を交互に | ふんわり、きめ細かい。最も一般的 |
| **フラワーバッター法** | バター＋粉を先に混ぜ、卵＋砂糖を加える | しっとり、きめが細かい。分離しにくい |
| **リバースクリーミング法（逆クリーミング）** | 粉・砂糖・膨張剤に柔らかいバターを混ぜて砂状にし、液体を加える | きめが細かく、しっとり柔らか。グルテンができにくい |
| **オイルベース（マフィンメソッド）** | 卵・砂糖・油・牛乳などの液体を混ぜ、粉類を加えてさっくり混ぜる | **しっとり、冷えても硬くなりにくい**。手軽 |
| **共立て法（スポンジ系）** | 全卵と砂糖を泡立て、粉と溶かしバターを加える | ふわふわで軽い |
| オールインワン法 | すべての材料を一度に混ぜる | 手軽 |

## 3-3 基本のオイルベースカップケーキ（12個分・一例）

| 材料 | 分量 |
|---|---|
| 卵 | 2個 |
| グラニュー糖 | 120g |
| 植物油（米油・サラダ油など） | 100ml |
| 牛乳（またはヨーグルト） | 120ml |
| 薄力粉 | 180g |
| ベーキングパウダー | 小さじ2 |
| 塩 | ひとつまみ |

1. 卵と砂糖を泡立て器でよく混ぜ、植物油を少しずつ加えて乳化させる。
2. 牛乳を加えて混ぜる。
3. ふるった粉類を加え、ゴムベラで **粉っぽさがなくなる程度にさっくり** 混ぜる。
4. カップに入れ、170〜180℃で約18〜22分焼く。

**バターとオイルのちがい**

| | バター | 植物油 |
|---|---|---|
| 風味 | **豊か** | 控えめ（素材の味が出る） |
| 食感 | ふんわり、きめ細かい | **しっとり、もっちり** |
| 冷えたとき | **固くなる**（バターが固まるため） | **固くなりにくい** |
| 向いているもの | 常温で食べる、風味を楽しむ | **冷蔵するカップケーキ**（クリームチーズ・生クリームのフロスティング）、キャロットケーキ |

## 3-4 焼き温度と時間の目安

| カップの大きさ | 温度 | 時間（目安） |
|---|---|---|
| ミニ（直径約4〜5cm） | 170〜180℃ | 約10〜13分 |
| **標準（直径約7cm）** | **170〜180℃** | **約18〜22分** |
| ジャンボ（直径約9cm以上） | 160〜170℃ | 約25〜30分 |

※オーブンや生地によって変わります。焼き時間の **最後の数分は、竹串で確認** しましょう。

> **ここを覚える**
> - 基本の流れ：常温に戻す → バター＋砂糖を白っぽく → 卵を少しずつ → 粉と牛乳を交互に（粉で始まり粉で終わる）→ 混ぜすぎない
> - カップの6〜7分目、170〜180℃で約18〜22分、竹串で確認、網の上で完全に冷ます
> - オイルベース＝しっとり、冷えても硬くなりにくい（冷蔵向き）
> - リバースクリーミング法＝粉と柔らかいバターを先に混ぜる

# 第4章 生地のバリエーション

## 4-1 代表的なカップケーキ（一例）

| 種類 | 基本の生地からの変え方（一例） | 合うフロスティング |
|---|---|---|
| **チョコレート** | 薄力粉の一部（約20〜30g）を **ココアパウダー（無糖）** に置き換える。溶かしたチョコレートを加えることも | チョコレートバタークリーム、ガナッシュ |
| **抹茶** | 薄力粉の一部を **抹茶（約5〜10g）** に置き換える（粉と一緒にふるう） | ホワイトチョコクリーム、あんこ、生クリーム |
| **レモン** | **レモンの皮のすりおろし**（表皮の黄色い部分だけ）と果汁を加える | レモンアイシング、クリームチーズ |
| **バナナ** | よく熟したバナナ（皮に黒い斑点＝**シュガースポット** が出たもの）をつぶして加え、牛乳を減らす | クリームチーズ、チョコレート |
| **キャロット** | すりおろしたにんじん・シナモンなどのスパイス・くるみ・レーズン。**植物油** を使う生地が多い | **クリームチーズフロスティング**（定番） |
| **レッドベルベット** | 少量のココア・**バターミルク**・**酢**・**赤い色素** で、赤い生地にする。アメリカ南部で人気 | **クリームチーズフロスティング**（定番） |
| **ストロベリー** | いちごのピュレやフリーズドライのいちごパウダーを加える | いちごのバタークリーム |
| **コーヒー（モカ）** | インスタントコーヒーを少量の湯で溶いて加える | コーヒーバタークリーム |
| **紅茶（アールグレイ）** | 細かい茶葉や、牛乳で煮出した紅茶を使う | ミルクティークリーム |
| **パンプキン** | かぼちゃのピュレ・シナモン・ナツメグ | クリームチーズ |
| **ココナッツ** | ココナッツミルク・ココナッツファイン | ココナッツクリーム |
| **米粉（グルテンフリー）** | 薄力粉を **米粉** に置き換える（米粉は吸水が違うので配合を調整） | 各種 |

## 4-2 中にフィリングを入れる方法

1. 焼いて冷ましたカップケーキの **中央を、丸口金の裏側やりんごの芯抜きなどで丸くくりぬく**。
2. くりぬいた穴に、**ジャム、カスタード、ガナッシュ、キャラメルソース、レモンカードなど** を詰める。
3. 上からフロスティングを絞ってふたをする。

※焼く前に生地の中にジャムを入れる方法もありますが、沈んだり焦げたりしやすいので注意します。

## 4-3 甘くない（おかず系）カップケーキ

チーズ、ハム、ベーコン、野菜などを生地に混ぜ込んだ、**塩味のカップケーキ**（ケークサレ風）もあります。砂糖を減らし、フロスティングの代わりにクリームチーズやマッシュポテトをのせることもあります。

> **ここを覚える**
> - チョコ＝薄力粉の一部をココア（無糖）に、抹茶＝粉と一緒にふるう
> - キャロット・レッドベルベット＝クリームチーズフロスティングが定番
> - レッドベルベット＝ココア少量・バターミルク・酢・赤い色素
> - バナナはシュガースポットが出たものを。レモンの皮は表皮だけ
> - フィリングは焼いた後にくりぬいて詰める

# 第5章 フロスティングとクリーム

## 5-1 フロスティングとは

**フロスティング（frosting）** は、ケーキの表面に塗ったり絞ったりする、クリーム状の甘い飾りのことです。「霜（frost）がおりたように覆う」ことが語源とされます。カップケーキの見た目と味を大きく左右します。

## 5-2 代表的なフロスティング（一例）

| 種類 | 材料（一例） | 特徴 | 保存 |
|---|---|---|---|
| **アメリカンバタークリーム** | バター100g＋**粉糖**200g＋牛乳または生クリーム少々＋バニラ | **甘くしっかり**。形が崩れにくく、**絞りやすい**。初心者向き | 涼しい場所、暑い時期は冷蔵 |
| **クリームチーズフロスティング** | クリームチーズ100g＋バター30g＋粉糖40〜60g | **ほどよい酸味**。柔らかめで、絞った形が崩れやすい | **要冷蔵** |
| **ホイップクリーム** | 生クリーム100ml＋砂糖8〜10g | **軽くあっさり**。時間がたつと **ダレやすい** | **要冷蔵** |
| **スイスメレンゲバタークリーム** | 卵白と砂糖を **湯せんで温めながら泡立て**、冷めてからバターを加える | **なめらかで甘さ控えめ**、つやがある。軽い口当たり | 冷蔵 |
| **イタリアンメレンゲバタークリーム** | 卵白に約117〜121℃のシロップを加えて泡立て、バターを加える | 安定性が高い。なめらか | 冷蔵 |
| **ガナッシュ** | チョコレート＋生クリーム | **濃厚**。比率で固さが変わる（チョコが多いほど固い）。冷まして泡立てると絞れる | 冷蔵 |
| **アイシング（グラスアイシング）** | 粉糖＋水・レモン汁・牛乳など | 表面に **塗って乾かす**。フェアリーケーキに | 常温 |
| **ロイヤルアイシング** | 粉糖＋卵白（またはメレンゲパウダー）＋レモン汁 | 乾くと **硬く固まる**。細かい模様や飾りに | 常温 |
| **ギリシャヨーグルトクリーム** | 水切りヨーグルト＋砂糖など | さっぱり。軽い | 要冷蔵 |
| **マシュマロフロスティング** | マシュマロや、メレンゲとシロップ | ふわふわ。バーナーで焦がすことも | ── |

**ガナッシュの比率の目安（チョコレート：生クリーム）**

| 比率 | 状態 | 用途 |
|---|---|---|
| 1：2 | ゆるい | ソース、泡立てて軽いクリームに |
| **1：1** | 中くらい | **コーティング（冷ますと塗れる）、泡立てて絞る** |
| 2：1 | 固い | トリュフ、絞り出し |

※チョコレートの種類（ダーク・ミルク・ホワイト）で固さが変わります。ホワイトやミルクはダークより柔らかくなりやすいので、チョコの割合を増やします。

## 5-3 フロスティング作りのポイント

| ポイント | 理由 |
|---|---|
| **バターは常温に戻す**（柔らかすぎないこと） | 冷たいとダマになり、溶けると形が保てない |
| **粉糖を使う**（ふるう） | グラニュー糖は溶けにくく、ジャリジャリする |
| **クリームチーズも常温に** | 冷たいとダマになる。ただし混ぜすぎると水っぽくゆるくなる |
| 生クリームは **冷やしながら** 泡立てる | 分離を防ぐ |
| 色をつけるときは **ジェルタイプの食用色素** | 水分が少なく、クリームがゆるくなりにくい |
| **固さを調整する** | 固すぎる → 牛乳や生クリームを少し足す。柔らかすぎる → 粉糖を足す、冷蔵庫で冷やす |

## 5-4 フロスティングとカップケーキの組み合わせ

| カップケーキ | 合うフロスティング |
|---|---|
| バニラ | バタークリーム（バニラ・チョコ）、いちごクリーム |
| チョコレート | チョコバタークリーム、ガナッシュ、ピーナッツバタークリーム |
| レッドベルベット | クリームチーズ |
| キャロット | クリームチーズ |
| レモン | レモンアイシング、クリームチーズ、メレンゲ |
| 抹茶 | ホワイトチョコ、生クリーム、あんこ |
| バナナ | クリームチーズ、チョコ、キャラメル |

> **ここを覚える**
> - アメリカンバタークリーム＝バター＋粉糖。甘くしっかり、絞りやすい
> - クリームチーズフロスティング＝酸味、柔らかめ、要冷蔵
> - スイスメレンゲバタークリーム＝卵白と砂糖を湯せんで泡立て、バター。甘さ控えめ・なめらか
> - ガナッシュ＝チョコ＋生クリーム（比率で固さが変わる）
> - アイシング＝粉糖＋水分（塗って乾かす）、ロイヤルアイシング＝卵白入りで硬く固まる
> - 色づけはジェル状の色素

# 第6章 カップケーキに使える食材

## 6-1 粉類

| 食材 | 特徴・使い方 |
|---|---|
| **薄力粉** | 基本の粉。グルテンが少なく、**ふんわり** |
| 強力粉 | 一部を混ぜると、しっかりした食感に |
| **米粉** | **グルテンを含まない**。しっとり・もっちり。**グルテンフリー**（小麦不使用）の生地に使える。製菓用の米粉を使う（米粉の種類で吸水量が違う）。**工場や台所での小麦の混入** に注意 |
| **アーモンドプードル** | 一部を置き換えると、**コクとしっとり感** |
| 全粒粉 | 素朴で香ばしい |
| **ココアパウダー** | チョコレート生地に。**無糖（ピュアココア）** を使う（調整ココアは砂糖や乳製品入り） |
| コーンスターチ | 一部を置き換えると、**軽い食感** に |
| おからパウダー | 糖質を控えたいときなど。吸水が多い |
| オートミール | ざっくりした食感 |

## 6-2 甘味料

| 食材 | 特徴 |
|---|---|
| **グラニュー糖** | すっきりした甘さ。基本の砂糖 |
| 上白糖 | しっとり、焼き色が濃くなる |
| きび砂糖・**ブラウンシュガー** | コクがある。キャロットケーキ、バナナケーキなど |
| **粉糖** | **フロスティング、アイシング** に |
| **はちみつ** | 風味としっとり感。焼き色が濃くなりやすい。**1歳未満の乳児にははちみつを与えない**（乳児ボツリヌス症の予防） |
| メープルシロップ | 独特の風味 |
| 黒糖 | 強いコクと風味 |

## 6-3 油脂

| 食材 | 特徴 |
|---|---|
| **無塩バター** | 風味が良い。基本の油脂 |
| **植物油（サラダ油・米油・太白ごま油など）** | **冷えても固まりにくく、しっとり**。冷蔵するカップケーキに向く。くせのない油を選ぶ |
| 発酵バター | 香りが豊か |
| **ココナッツオイル** | 独特の香り。**約24〜25℃以下で固まる** |
| オリーブオイル | 香りが強いので、レモンやハーブの生地などに |
| マーガリン | バターの代用 |

## 6-4 卵・乳製品

| 食材 | 特徴 |
|---|---|
| **卵** | ふくらみ・つなぎ・色・乳化。**常温に戻して** 使う |
| **牛乳** | しっとり、のびの良い生地に |
| **バターミルク** | 本来はバターを作ったときに残る乳液。酸味があり、**重曹と反応してふくらむ**。生地を柔らかくする。レッドベルベットに。日本では手に入りにくいので、**牛乳にレモン汁や酢を少量加えて（牛乳200mlに大さじ1程度）、数分置いて代用** することが多い |
| **ヨーグルト・サワークリーム** | しっとり、ほどよい酸味 |
| **クリームチーズ** | フロスティング、生地に混ぜることも |
| **生クリーム** | ホイップクリーム、ガナッシュ |
| 豆乳 | 牛乳の代用（乳を使わないとき） |

## 6-5 膨張剤

| 食材 | 特徴 |
|---|---|
| **ベーキングパウダー** | 基本の膨張剤。**重曹＋酸性剤＋分散剤**。くせが少なく、均一にふくらむ |
| **重曹（ベーキングソーダ）** | **アルカリ性**。**酸性の材料**（バターミルク、ヨーグルト、ココア、はちみつ、ブラウンシュガーなど）と合わせて使う。入れすぎると **苦く、色が黄色（ココア生地では赤茶色）っぽく** なる |

## 6-6 香り・風味づけ

| 食材 | 特徴 |
|---|---|
| **バニラエッセンス** | アルコールに香りを溶かしたもの。**加熱で香りが飛びやすい** → **冷たいお菓子・クリーム向き** |
| **バニラオイル** | 油に香りを溶かしたもの。**加熱しても香りが残りやすい** → **焼き菓子向き** |
| **バニラビーンズ** | さやを縦に裂いて、中の **種をしごき出して** 使う。最も香りが豊か。高価 |
| バニラエクストラクト | バニラビーンズをアルコールに漬けた天然の香料（アメリカのレシピに多い） |
| シナモン・ナツメグ・ジンジャーなどのスパイス | キャロット、パンプキン、アップル |
| 洋酒（ラム酒・キルシュなど） | 香り。**子ども向け・お酒が苦手な人には控える** |
| **柑橘の皮** | すりおろして香りを加える。**表皮の黄色・オレンジ色の部分だけ**（白い部分は苦い）。ワックスのかかっていない国産のものが安心 |
| インスタントコーヒー・抹茶・紅茶 | 風味づけ |

## 6-7 具材（混ぜ込み・トッピング）

| 食材 | 使うときのポイント |
|---|---|
| **生のフルーツ**（いちご・りんご・ブルーベリーなど） | **水分が多い** ので、生地がべちゃっとしないよう量を調整。りんごは加熱してから使うと扱いやすい |
| **冷凍フルーツ** | **解凍せずに** 使うと、色が生地に流れにくい |
| **ドライフルーツ** | **湯通し** や **洋酒漬け** で柔らかくする（生地の水分を吸いすぎない） |
| **チョコチップ・ナッツ・ドライフルーツ** | **薄力粉を少量まぶしてから** 混ぜると、**底に沈みにくい** |
| ナッツ | **ローストする** と香りが良くなる |
| 野菜（かぼちゃ・さつまいも・にんじん・ほうれん草） | 加熱してピュレにする、すりおろすなど。**自然な色と甘み** |
| ジャム | 焼いた後にくりぬいて詰めると、中からとろり |
| あんこ | 和風カップケーキに |

## 6-8 色づけ

| 食材 | 特徴 |
|---|---|
| **食用色素（ジェルタイプ）** | 少量で **鮮やか** に色がつく。**水分が少なく、クリームが水っぽくなりにくい** |
| 食用色素（液体） | 手に入りやすい。入れすぎるとクリームがゆるくなる |
| 食用色素（粉末） | 少量の水で溶いて使う |
| **天然の素材** | **抹茶**（緑）、**ココア**（茶）、**いちごパウダー**（ピンク）、**紫いもパウダー**（紫）、**かぼちゃパウダー**（黄）、**ブルーベリー**（紫）、**ビーツ**（赤）、**ほうれん草パウダー**（緑）、**竹炭パウダー**（黒） |

**天然素材の色の注意**　天然の色素は、**熱や光で色があせたり、変色したり** することがあります。紫いもやブルーベリーの色素（アントシアニン）は、**アルカリ性（重曹）で青緑っぽく、酸性で赤っぽく** 変わる性質があります。

> **ここを覚える**
> - 米粉＝グルテンを含まない（小麦の混入に注意）
> - ココアは無糖（ピュアココア）を使う
> - 植物油＝冷えても固まりにくくしっとり
> - バターミルク＝牛乳＋レモン汁（酢）で代用、重曹と反応してふくらむ
> - 重曹は酸性の材料と組み合わせる
> - バニラエッセンス＝冷菓向き、バニラオイル＝焼き菓子向き、バニラビーンズ＝種をしごき出す
> - チョコチップ・ナッツは粉をまぶすと沈みにくい、冷凍フルーツは解凍せずに
> - アントシアニン（紫いも・ブルーベリー）はアルカリで青緑、酸で赤に変わる

# 第7章 カップケーキ作りの注意点

## 7-1 材料の準備

| 注意点 | 理由 |
|---|---|
| **正確に量る** | 特に **ベーキングパウダー** は、多すぎても少なすぎても失敗する |
| **材料の温度をそろえる**（バター・卵・牛乳を常温に） | 冷たい卵や牛乳を加えると、バターが固まって **分離** しやすい |
| **粉類はふるう** | ダマを防ぎ、ベーキングパウダーを均一に混ぜる |
| **材料の鮮度を確認** | 古いベーキングパウダーはふくらむ力が弱い。バターの酸化臭、卵の鮮度 |
| **オーブンの予熱を始めておく** | 生地ができたらすぐ焼けるように（ベーキングパウダーは水分と反応し始めるため、生地を長く置かない） |

## 7-2 混ぜ方

| 注意点 | 理由・対策 |
|---|---|
| バターと砂糖は **しっかり空気を含ませる**（白っぽくなるまで） | ふんわりした食感のもと |
| 卵は **少しずつ** 加える | 一度に入れると **分離** する |
| 分離したら | **ふるった粉を少量（大さじ1〜2）加える** とまとまりやすい。ボウルの底を少し温めるのも効果的 |
| 粉を加えたら **混ぜすぎない** | 混ぜすぎるとグルテンができて、**硬く、ふくらみの悪い、トンネル状の穴のある** 生地になる |
| ボウルの底や側面をこまめにはらう | 混ざっていないバターが残ると、焼きムラになる |

## 7-3 型に入れる量と方法

- カップの **約6〜7分目（2/3程度）** が目安です。

| 量 | 仕上がり |
|---|---|
| 少なすぎる | 小さく、カップから生地が出ず、見た目がさびしい |
| **6〜7分目** | **ちょうど良くカップのふちまでふくらむ** |
| 多すぎる | あふれる、ドーム状に大きく盛り上がりすぎてデコレーションしにくい、生焼けになりやすい |

- 生地を **同じ量ずつ** 入れると、焼き上がりの大きさと焼け具合がそろいます（**アイスクリームディッシャー**、スプーン2本、絞り袋を使うと便利）。
- 入れた後、型を軽く台に打ちつけて、**大きな気泡を抜く** と表面がきれいになります。

## 7-4 焼き方

| 注意点 | 理由 |
|---|---|
| **オーブンは必ず予熱** する | 予熱が足りないとふくらまない、生焼け |
| **途中で何度も扉を開けない** | 温度が下がって、**しぼむ** 原因になる（特に焼き始めの前半） |
| 焼き時間は目安 | **竹串を刺して、生地がついてこないか** で確認する |
| 焼きムラがあれば | 焼き時間の **後半** に、手早く天板の前後を入れ替える |
| 焼けたら **すぐに型から出す** | 型の中に置いたままだと、**蒸気で底が湿り、カップがはがれる** 原因になる |
| **網の上で完全に冷ます** | ── |

## 7-5 デコレーション前の注意

- **カップケーキが完全に冷めてから** フロスティングを絞る（温かいと **クリームが溶ける**）。
- 表面がドーム状に盛り上がりすぎた場合は、**包丁で平らに切る** と、デコレーションしやすくなります。
- 乾燥しないよう、デコレーションまで時間があるときはラップをかけておきます。

## 7-6 フロスティングを扱うときの注意

- バタークリームは、**硬すぎると絞りにくく、柔らかすぎると形が崩れます**。室温や手の温度に注意します。
- 絞り袋を **長時間手で握っていると、体温でクリームが柔らかく** なるので、袋に入れる量は半分程度にします。
- ホイップクリームやクリームチーズフロスティングは、**冷蔵保存が必要** です。

> **ここを覚える**
> - 材料は常温、粉はふるう、ベーキングパウダーは正確に・新しいものを
> - 卵は少しずつ。分離したら粉を少量
> - 粉を入れたら混ぜすぎない（硬い・トンネル状の穴）
> - カップの6〜7分目、同じ量ずつ（ディッシャー）
> - 予熱、扉を開けない、竹串、すぐ型から出して網で完全に冷ます
> - 完全に冷めてからデコレーション

# 第8章 よくある失敗と原因

| 失敗 | 主な原因 | 対策 |
|---|---|---|
| **中央がへこむ・しぼむ** | **焼き不足**、焼いている途中で扉を開けた、**ベーキングパウダーが多すぎる**、生地を混ぜすぎた、砂糖や水分が多すぎる | 竹串で確認、扉を開けない、計量を正確に |
| **中央が大きく割れる・とがる（火山のように）** | **オーブンの温度が高すぎる**（表面が先に固まり、中の生地が突き破る）、生地が多い、粉が多い | 温度を下げる、生地の量を減らす |
| **ふくらまない** | ベーキングパウダーが少ない・**古い**、クリーミング不足、**予熱不足**、生地を作ってから焼くまで時間をおいた | 新しい膨張剤、しっかりクリーミング、予熱 |
| **硬い・パサパサ** | **混ぜすぎ**、**焼きすぎ**、粉が多い、砂糖や油脂が少ない | さっくり混ぜる、焼き時間を短く |
| **生焼け（中がべちゃっとしている）** | 温度が低い、時間が短い、生地が多い | 竹串で確認 |
| **表面がべたつく** | 冷めきる前に密閉した、湿気、砂糖が多い | 完全に冷ましてから保存 |
| **カップが生地からはがれる** | **型の中で冷ました**（蒸気がこもる）、湿気、生地の油分が多い、焼き不足 | 焼けたらすぐ型から出し、網の上で冷ます |
| **具が底に沈む** | 生地がゆるい、具が重い・大きい・濡れている | 具に **粉をまぶす**、小さく切る |
| **大きな穴・トンネル** | **混ぜすぎ**（グルテン）、ベーキングパウダーのダマ | さっくり混ぜる、粉をふるう |
| **生地が分離した** | 卵・牛乳が冷たい、卵を一度に入れた | 常温に戻す、少しずつ加える、粉を少量足す |
| **焼き色が濃すぎる・焦げる** | 温度が高い、上段で焼いた、砂糖やはちみつが多い | 温度を下げる、アルミホイルをかぶせる |
| **焼き色が薄い** | 温度が低い、砂糖が少ない | 温度を上げる |
| **苦い・えぐい** | **重曹が多い**、ベーキングパウダーのダマ | 計量を正確に、よくふるう |
| **フロスティングが溶ける・ダレる** | カップケーキが **温かいうち** に絞った、室温が高い、クリームが柔らかい | 完全に冷ます、クリームを冷やす |
| **フロスティングがざらざらする** | **グラニュー糖** を使った、粉糖をふるっていない | 粉糖をふるって使う |
| **クリームチーズフロスティングがゆるい** | 混ぜすぎ、クリームチーズが柔らかすぎる | 冷やす、粉糖を足す |

> **ポイント**　失敗の原因は、**「材料（量・温度・鮮度）」「混ぜ方（足りない・混ぜすぎ）」「焼き方（温度・時間・予熱・扉）」** の3つの面から考えましょう。

## 9-1 絞り袋と口金

| **クローズスター** | 先が閉じ気味の星形 | 細かいひだ、ドロップフラワー |

**絞り袋の使い方**

1. 口金を絞り袋の先に入れ、袋の先を口金の大きさに合わせて切る。
2. コップなどに絞り袋を立てて、袋の口を外側に折り返し、クリームを **半分〜2/3程度** 入れる（入れすぎると絞りにくく、体温でクリームが溶ける）。
3. 袋の口をねじって、クリームを先に寄せる。
4. 利き手で袋のねじった部分を持って **押し出し**、反対の手は口金の近くを **支えるだけ**。

# 第10章 保存・包装・衛生・販売

## 10-1 保存

| 状態 | 保存方法・目安 |
|---|---|
| **デコレーションなし** | 完全に冷ましてから、乾燥しないようラップや密閉容器で **常温**（1〜2日）。それ以上は **冷凍**（ラップで1個ずつ包み、冷凍用の袋へ。約2週間〜1か月が目安） |
| **バタークリーム** | 涼しい場所で当日中。暑い時期や翌日以降は **冷蔵**（食べる前に常温に戻すと口どけが良い） |
| **ホイップクリーム・クリームチーズフロスティング** | **冷蔵** し、**当日〜翌日中** に食べる |
| 生のフルーツをのせたもの | **冷蔵** し、当日中に |
| 冷蔵したもの | 食べる少し前に出して、バターを柔らかくすると口どけが良い（クリームチーズ・生クリームは出しすぎない） |

**冷凍のポイント**

- デコレーション前の **生地だけ** を冷凍するのがおすすめです。
- バタークリームを絞ったものは、表面を冷凍して固めてから包むと、形が崩れにくくなります。
- 解凍は **冷蔵庫でゆっくり** 行います（急に常温に出すと結露する）。
