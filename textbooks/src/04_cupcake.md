# 第1章 カップケーキの基礎知識

## 1-1 カップケーキとは

カップケーキは、**紙やアルミのカップ（ベーキングカップ）、または小さな型に生地を入れて焼く、1人分の小さなケーキ** です。焼いた後に **フロスティング（クリーム）やトッピング** でデコレーションするのが特徴です。

## 1-2 カップケーキの歴史

- カップケーキは **アメリカ** で生まれたお菓子とされています。
- 1796年にアメリカで出版された料理本『アメリカン・クッカリー（American Cookery）』（アメリア・シモンズ著）に、「**小さなカップで焼くケーキ**」についての記述があり、これが古い記録の一つとして紹介されることが多いです。
- 「カップケーキ（cupcake）」という言葉は、19世紀前半の料理本（1828年のイライザ・レスリーの本など）に見られるとされます。
- 1919年には、アメリカのホステス社が市販のカップケーキを発売しました。
- 2000年代には、ニューヨークの **マグノリア・ベーカリー** がテレビドラマ『セックス・アンド・ザ・シティ』に登場したことなどをきっかけに、カップケーキの大ブームが起こったといわれます。日本でも2000年代後半〜2010年代に専門店が増えました。

## 1-3 名前の由来（2つの説）

| 説 | 内容 |
|---|---|
| 焼く容器の説 | 陶器の **カップ（器）** に生地を入れて焼いたから |
| 計量の説 | 材料を **カップで量って** 作ったから（材料の量を「1・2・3・4」の数で覚える「**ナンバーケーキ（1-2-3-4ケーキ）**」と呼ばれるケーキとの関係が紹介されることもある） |

※どちらが正しいか、はっきりとは分かっていません。

## 1-4 各国のカップケーキ

| 名前 | 国 | 特徴 |
|---|---|---|
| カップケーキ | アメリカ | たっぷりのフロスティングで華やか |
| フェアリーケーキ | イギリス | アメリカより小さめで、アイシングなどでシンプルに飾る |
| バタフライケーキ | イギリス | 上部を切り取って半分にし、蝶の羽のようにのせる |

## 1-5 カップケーキとマフィンの違い

| | カップケーキ | マフィン |
|---|---|---|
| 生地 | **バター生地**（ケーキに近い）。きめ細かくふんわり | 甘さ控えめ。パンに近いものもある |
| 混ぜ方 | バターと砂糖をすり混ぜる（シュガーバッター法）ことが多い | 粉類と液体を **さっくり混ぜる**（マフィンメソッド） |
| 甘さ | 甘い（デザート） | 控えめ（朝食・軽食） |
| 仕上げ | **フロスティングやデコレーション** をする | ほとんどしない（生地に具を混ぜ込む） |

※アメリカのマフィンはベーキングパウダーでふくらませる「クイックブレッド」の一種、イギリスのマフィン（イングリッシュマフィン）はイーストで発酵させるパンです。

> **ここを覚える**
> - 発祥はアメリカ。1796年『アメリカン・クッカリー』に「小さなカップで焼くケーキ」
> - 名前の由来は「器のカップ」説と「計量カップ」説
> - マフィンとの違い：カップケーキはバター生地＋フロスティング

# 第2章 カップケーキのレシピ

## 2-1 基本のバニラカップケーキ（直径約7cmのカップ12個分・一例）

| 材料 | 分量 | 役割 |
|---|---|---|
| 無塩バター | 115g | コク・風味、空気を含んでふんわり |
| グラニュー糖 | 150g | 甘み・しっとり・焼き色 |
| 卵（Mサイズ） | 2個（約100g） | ふくらみ、生地をつなぐ |
| 薄力粉 | 180g | 生地の骨組み |
| ベーキングパウダー | 小さじ2（約6〜8g） | ふくらませる |
| 塩 | ひとつまみ | 甘みを引き立てる |
| 牛乳 | 120ml | しっとりさせる |
| バニラオイル | 少々 | 香り |

**下準備**

- バター・卵・牛乳を **常温に戻す**
- 薄力粉・ベーキングパウダー・塩を **合わせてふるう**
- マフィン型に **グラシンカップ（紙カップ）** を敷く
- オーブンを **170〜180℃に予熱** する

**作り方（シュガーバッター法）**

1. ボウルにバターを入れ、泡立て器（ハンドミキサー）でクリーム状にする。
2. グラニュー糖を2〜3回に分けて加え、**白っぽくふんわりするまで** よく混ぜる（空気を含ませる）。
3. 溶いた卵を **少しずつ** 加え、そのつどよく混ぜる（一度に入れると分離する）。バニラオイルを加える。
4. ふるった粉の **1/3** を加えてゴムベラでさっくり混ぜ、牛乳の **1/2** を加えて混ぜる。これを **「粉 → 牛乳 → 粉 → 牛乳 → 粉」** の順でくり返す。
5. 粉っぽさがなくなり、つやが出たら混ぜ終わり（**混ぜすぎない**）。
6. カップの **約6〜7分目（2/3程度）** まで生地を入れる。
7. 170〜180℃のオーブンで **約18〜22分** 焼く。
8. **竹串** を中心に刺して、生地がついてこなければ焼き上がり。
9. 型から出し、ケーキクーラーの上で **完全に冷ます**。
10. 冷めてからフロスティングを絞る。

> **ポイント**　粉と牛乳を交互に入れるのは、**分離を防ぎ、なめらかな生地にするため** です。牛乳を一度に入れると、バターと水分が分かれやすくなります。

## 2-2 生地のバリエーション

| 種類 | 基本からの変え方（一例） |
|---|---|
| チョコレート | 薄力粉の一部（約20〜30g）をココアパウダーに置き換える |
| 抹茶 | 薄力粉の一部を抹茶（約5〜10g）に置き換える |
| レモン | レモンの皮のすりおろし・果汁を加える。レモンアイシングと合う |
| バナナ | よく熟したバナナをつぶして加える。牛乳を減らす |
| キャロット | すりおろしたにんじん・シナモン・くるみ。植物油を使う生地が多い。クリームチーズフロスティングが定番 |
| レッドベルベット | ココア少量・バターミルク・酢・赤い色素で、赤い生地にする。クリームチーズフロスティングが定番 |
| オイルベース | バターの代わりに植物油。**冷めても硬くなりにくく、しっとり** |

## 2-3 基本のフロスティング

| 種類 | 材料（一例） | 特徴 |
|---|---|---|
| **アメリカンバタークリーム** | バター100g＋粉糖200g＋牛乳少々 | 甘くしっかり。形が崩れにくく、絞りやすい |
| **クリームチーズフロスティング** | クリームチーズ100g＋バター30g＋粉糖40〜60g | ほどよい酸味。柔らかめ。**要冷蔵** |
| **ホイップクリーム** | 生クリーム100ml＋砂糖8〜10g | 軽くあっさり。時間がたつとダレやすい。**要冷蔵** |
| **スイスメレンゲバタークリーム** | 卵白と砂糖を湯せんで温めて泡立て、バターを加える | なめらかで甘さ控えめ。つやがある |
| **ガナッシュ** | チョコレート＋生クリーム（同量など） | 濃厚。比率で固さが変わる |
| **アイシング** | 粉糖＋水（または卵白・レモン汁） | 表面に塗って乾かす。フェアリーケーキに |

> **ここを覚える**
> - 基本の工程：バター＋砂糖を白っぽく → 卵を少しずつ → 粉と牛乳を交互に → 混ぜすぎない
> - カップには6〜7分目、170〜180℃で約18〜22分、竹串で確認
> - **完全に冷ましてから** デコレーション

# 第3章 カップケーキに使える食材

## 3-1 粉類

| 食材 | 特徴・使い方 |
|---|---|
| 薄力粉 | 基本の粉。グルテンが少なく、ふんわり |
| 強力粉 | 一部を混ぜると、しっかりした食感に |
| 米粉 | **グルテンを含まない**。しっとり・もっちり。小麦アレルギー対応（グルテンフリー）の生地に使える（ただし工場での混入に注意） |
| アーモンドプードル | 一部を置き換えると、コクとしっとり感が出る |
| 全粒粉 | 素朴で香ばしい |
| ココアパウダー | チョコレート生地に。**無糖のもの** を使う |
| コーンスターチ | 一部を置き換えると、軽い食感に |

## 3-2 甘味料

| 食材 | 特徴 |
|---|---|
| グラニュー糖 | すっきりした甘さ。基本の砂糖 |
| 上白糖 | しっとり、焼き色が濃くなる |
| きび砂糖・ブラウンシュガー | コクがある。キャロットケーキなどに |
| 粉糖 | フロスティング、アイシングに |
| はちみつ・メープルシロップ | 風味としっとり感。焼き色が濃くなりやすい。**1歳未満の乳児にははちみつを与えない**（乳児ボツリヌス症の予防） |

## 3-3 油脂

| 食材 | 特徴 |
|---|---|
| 無塩バター | 風味が良い。基本の油脂 |
| 植物油（サラダ油・米油など） | 冷えても固まりにくく、**しっとり**。冷蔵するカップケーキに向く |
| 発酵バター | 香りが豊か |
| ココナッツオイル | 独特の香り。低い温度で固まる |

## 3-4 卵・乳製品

| 食材 | 特徴 |
|---|---|
| 卵 | ふくらみ・つなぎ・色。**常温に戻して** 使う |
| 牛乳 | しっとり、のびの良い生地に |
| バターミルク | 酸味があり、重曹と反応してふくらむ。レッドベルベットに。**牛乳にレモン汁や酢を少量加えて代用** することもある |
| ヨーグルト・サワークリーム | しっとり、ほどよい酸味 |
| クリームチーズ | フロスティング、生地に混ぜることも |
| 生クリーム | ホイップクリーム、ガナッシュ |

## 3-5 膨張剤

| 食材 | 特徴 |
|---|---|
| ベーキングパウダー | 基本の膨張剤。くせが少なく、均一にふくらむ |
| 重曹 | 酸性の材料（バターミルク、ヨーグルト、ココアなど）と合わせて使う。入れすぎると苦く、色が黄色っぽくなる |

## 3-6 香り・風味づけ

| 食材 | 特徴 |
|---|---|
| バニラエッセンス | 加熱で香りが飛びやすい。**冷たいお菓子・クリーム向き** |
| バニラオイル | 加熱しても香りが残りやすい。**焼き菓子向き** |
| バニラビーンズ | さやから種を取り出して使う。最も香りが豊か |
| シナモン・ナツメグなどのスパイス | キャロットケーキ、アップルケーキ |
| 洋酒（ラム酒など） | 香り。子ども向けには控える |
| 柑橘の皮 | すりおろして香りを加える。**表皮のみ**（白い部分は苦い） |

## 3-7 具材（混ぜ込み・トッピング）

| 食材 | 使うときのポイント |
|---|---|
| 生のフルーツ（いちご、りんご、ブルーベリー） | 水分が多いので、生地がべちゃっとしないよう量を調整。りんごは加熱してから使うと扱いやすい |
| 冷凍フルーツ | 解凍せずに使うと色が生地に流れにくい |
| ドライフルーツ | 湯通しや洋酒漬けで柔らかくする |
| チョコチップ・ナッツ | **薄力粉を少量まぶしてから** 混ぜると、底に沈みにくい |
| 野菜（かぼちゃ、さつまいも、にんじん、ほうれん草） | 加熱してペーストにする、すりおろすなど。自然な色と甘み |
| ジャム | 焼いた後にくりぬいて詰めると、中からとろり |

## 3-8 色づけ

| 食材 | 特徴 |
|---|---|
| 食用色素（ジェルタイプ） | 少量で鮮やかに色がつき、クリームが水っぽくなりにくい |
| 食用色素（液体・粉末） | 手に入りやすい。入れすぎに注意 |
| 天然の素材 | 抹茶（緑）、ココア（茶）、いちごパウダー（ピンク）、紫いもパウダー（紫）、かぼちゃパウダー（黄）、ブルーベリー（紫） |

> **ここを覚える**
> - 米粉＝グルテンを含まない
> - 植物油＝冷えても固まりにくくしっとり
> - バターミルク＝牛乳＋レモン汁（酢）で代用可
> - バニラエッセンス＝冷菓向き、バニラオイル＝焼き菓子向き
> - チョコチップ・ナッツは粉をまぶすと沈みにくい

# 第4章 カップケーキ作りの注意点

## 4-1 材料の準備

- **正確に量る** ── 特にベーキングパウダーは、多すぎても少なすぎても失敗します。
- **材料の温度をそろえる** ── バター・卵・牛乳は常温に戻します。冷たい卵を加えると、バターが固まって **分離** しやすくなります。
- **粉類はふるう** ── ダマを防ぎ、ベーキングパウダーを均一に混ぜるためです。

## 4-2 混ぜ方

- バターと砂糖は **しっかり空気を含ませる**（白っぽくなるまで）。
- 卵は **少しずつ** 加える。
  - 分離してしまったら、**ふるった粉を少量加える** とまとまりやすくなります。
- 粉を加えたら **混ぜすぎない**。混ぜすぎるとグルテンができて、**硬く、ふくらみの悪い** 生地になります。

## 4-3 型に入れる量

- カップの **約6〜7分目（2/3程度）** が目安です。
  - 少なすぎる → 小さく、カップから生地が出ない
  - 多すぎる → あふれる、ドーム状に大きく盛り上がりすぎてデコレーションしにくい
- 生地を同じ量ずつ入れると、焼き上がりがそろいます（アイスクリームディッシャーやスプーン2本を使うと便利）。

## 4-4 焼き方

- **オーブンは必ず予熱** する。
- 焼き時間は目安。**竹串を刺して、生地がついてこないか** で確認する。
- 途中で何度も扉を開けない（温度が下がって、しぼむ原因に）。
- 焼きムラがあれば、焼き時間の後半に天板の前後を入れ替える。

## 4-5 よくある失敗と原因

| 失敗 | 主な原因 | 対策 |
|---|---|---|
| 中央がへこむ・しぼむ | 焼き不足、扉を開けた、ベーキングパウダーが多すぎる、生地を混ぜすぎた | 竹串で確認、扉を開けない、計量を正確に |
| 中央が大きく割れる・とがる | オーブンの温度が高すぎる、生地が多い | 温度を下げる、生地の量を減らす |
| ふくらまない | ベーキングパウダーが少ない・古い、泡立て不足、予熱不足 | 新しい膨張剤、しっかりクリーミング |
| 硬い・パサパサ | 混ぜすぎ、焼きすぎ、粉が多い | さっくり混ぜる、焼き時間を短く |
| 生焼け | 温度が低い、時間が短い、生地が多い | 竹串で確認 |
| カップが生地からはがれる | 湿気（冷める間の蒸気）、生地の油分 | 焼けたらすぐ型から出し、網の上で冷ます |
| 具が底に沈む | 生地がゆるい、具が重い | 具に粉をまぶす |

## 4-6 デコレーションの注意点

- **カップケーキが完全に冷めてから** フロスティングを絞る（温かいとクリームが溶ける）。
- バタークリームは、硬すぎると絞りにくく、柔らかすぎると形が崩れます。**室温や手の温度** に注意します。
- ホイップクリームやクリームチーズフロスティングは、**冷蔵保存が必要** です。

> **ここを覚える**
> - 材料は常温、卵は少しずつ、分離したら粉を少量
> - 粉を入れたら混ぜすぎない
> - カップの6〜7分目、予熱、竹串で確認
> - 中央がへこむ＝焼き不足など、中央が割れる＝温度が高すぎるなど

# 第5章 デコレーションの技術

## 5-1 絞り袋と口金

| 口金 | 仕上がり |
|---|---|
| 丸口金 | なめらかなドーム状、水玉 |
| 星口金（6〜8切） | ギザギザの模様、ロゼット |
| 大きめの星口金（オープンスター、例：1Mなど） | バラのような「ローズ絞り」 |
| 閉じた星口金（クローズスター） | 細かいひだ |
| 葉口金（リーフ） | 葉っぱ |
| バラ口金（花びら） | 花びら |

**代表的な絞り方**

- **ローズ絞り** ── 中心から外側へ、うずまき状に絞る
- **ソフトクリーム絞り** ── 外側から中心へ、重ねるように高く絞る
- **ドーム絞り** ── 丸口金で中心にこんもり絞る

## 5-2 トッピング

| トッピング | 説明 |
|---|---|
| スプリンクル（カラースプレー） | カラフルな砂糖菓子。チョコスプレー、ノンパレル（小粒）など |
| アラザン | 砂糖とでんぷんの粒に銀色や金色をつけたもの |
| シュガーペースト（フォンダン） | 粘土のように形を作れる砂糖の生地。キャラクターや花 |
| アイシングクッキー | クッキーを飾りとしてのせる |
| フルーツ | いちご、ブルーベリーなど。生のものは水分に注意 |
| チョコレート飾り | 削ったチョコ、型抜きしたチョコ |
| エディブルフラワー | 食用の花（食用として栽培されたものに限る） |

## 5-3 色の組み合わせとテーマ

- **季節** ── 春（ピンク・桜）、夏（青・白・柑橘）、秋（茶・オレンジ・栗）、冬（赤・緑・白）
- **イベント** ── 誕生日、ハロウィン、クリスマス、バレンタイン、ウェディング
- 色数を **2〜3色** にしぼると、まとまりやすくなります。

# 第6章 保存・衛生・販売

## 6-1 保存

| 状態 | 保存方法・目安 |
|---|---|
| デコレーションなし | 乾燥しないようラップや密閉容器で常温（1〜2日）、または冷凍 |
| バタークリーム | 涼しい場所、暑い時期は冷蔵 |
| ホイップクリーム・クリームチーズ | **冷蔵** し、当日〜翌日中に食べる |
| 冷蔵したもの | 食べる少し前に出して、バターを柔らかくすると口どけが良い |

## 6-2 衛生管理

- 手洗い、道具の消毒を徹底する。
- 生クリーム・卵を使うクリームは、細菌が増えやすいので **温度管理** を徹底する。
- 生卵を使うクリーム（スイスメレンゲは湯せんで温めるが、十分な加熱とはいえないことがある）を扱うときは、新鮮な卵を使い、早めに食べる。

## 6-3 アレルギーへの配慮

カップケーキに多く使われる **小麦・卵・乳** は、表示が義務の「特定原材料」です（ほかに、えび・かに・くるみ・そば・落花生の計8品目）。ナッツ類（くるみは義務、アーモンド・カシューナッツなどは推奨）にも注意が必要です。

- グルテンフリーにするなら **米粉**、卵なし・乳なしにするなら **植物油・豆乳** などで代用する方法があります。
- ただし、同じキッチンで作ると **混入（コンタミネーション）** の可能性があります。

## 6-4 販売するとき

- 手作りのカップケーキを販売するには、**菓子製造業の営業許可**（保健所）や、**食品衛生責任者** の設置などが必要です。
- 包装して販売する場合は、**食品表示**（名称、原材料、アレルゲン、消費期限、保存方法、製造者など）が必要です。
- 詳しい条件は地域によって違うことがあるため、**管轄の保健所** に相談してください。

# 解答と解説

## 記述問題

| 番号 | 解答 | ひとこと解説 |
|---|---|---|
| 1 | アメリカ | 2000年代にニューヨークでブーム |
| 2 | アメリカン・クッカリー（American Cookery） | アメリア・シモンズ著 |
| 3 | フェアリーケーキ | バタフライケーキという飾り方もある |
| 4 | シュガーバッター法 | 白っぽくなるまで混ぜる |
| 5 | 約6〜7分目（2/3程度） | 多すぎるとあふれる |
| 6 | 竹串 | 生地がついてこなければ焼き上がり |
| 7 | クリームチーズフロスティング | 要冷蔵 |
| 8 | レモン汁（または酢） | 酸で牛乳が少し固まる |
| 9 | 米粉 | 工場での小麦混入には注意 |
| 10 | バニラオイル | エッセンスは加熱で飛びやすい |

## ○×問題

| 番号 | 解答 | 解説 |
|---|---|---|
| 1 | ○ | マフィンは具を混ぜ込むことが多い |
| 2 | × | **常温に戻して** 使う。冷たいと分離しやすい |
| 3 | × | **少しずつ** 加えないと分離する |
| 4 | ○ | グルテンができすぎるため |
| 5 | × | **6〜7分目** が目安 |
| 6 | × | **完全に冷ましてから**。温かいとクリームが溶ける |
| 7 | ○ | 粉が生地とのすべりを抑える |
| 8 | ○ | 植物油は低温でも固まりにくい |
| 9 | × | ホイップクリームは **冷蔵** し、早めに食べる |

| 用語 | 意味 |
|---|---|
| フロスティング | カップケーキの上に絞ったり塗ったりするクリーム |

| 口金 | 絞り袋の先につけて模様を作る金具 |

| シュガーペースト | 粘土のように成形できる砂糖の生地 |
