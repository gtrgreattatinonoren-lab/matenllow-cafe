# 第1章 お菓子作りの基本

## 1-1 お菓子作りは「科学」

料理は味を見ながら調整できますが、お菓子は **焼く前に配合と手順が決まっていないと失敗しやすい** のが特徴です。材料の量・温度・混ぜ方が、ふくらみや食感を左右します。

**お菓子作りの基本の3原則**

1. **正確に量る** ── 目分量にしない
2. **温度を守る** ── 材料の温度、オーブンの温度
3. **手順を守る** ── 混ぜる順番、混ぜ方

## 1-2 作り始める前の準備（下準備）

- レシピを最後まで読む
- 材料をすべて量っておく
- バターや卵を **常温に戻す**（レシピの指示に従う）
- 粉類を **ふるう**
- 型に紙を敷く、またはバターを塗って粉をはたく
- **オーブンを予熱する**

# 第2章 材料の種類と働き

## 2-1 小麦粉とグルテン

| 種類 | たんぱく質（目安） | グルテン | お菓子での用途 |
|---|---|---|---|
| 薄力粉 | 約6.5〜9％ | 少なく弱い | スポンジ、クッキー、マフィンなど **ほとんどの洋菓子** |
| 中力粉 | 約8〜10.5％ | 中くらい | 一部の焼き菓子 |
| 強力粉 | 約11.5〜13.5％ | 多く強い | パイ生地の一部、打ち粉（さらさらで散りやすい）、シュー生地に混ぜることもある |

**グルテンとお菓子の関係**

- グルテンは、小麦粉の **グルテニン（弾力）** と **グリアジン（粘り）** が、水と一緒に混ぜられることでできます。
- パンにはグルテンが必要ですが、ケーキやクッキーでは **グルテンができすぎると、硬く、ふくらみの悪い仕上がり** になります。
- そのため、お菓子では主に **薄力粉** を使い、粉を加えた後は **ゴムベラでさっくり（切るように）混ぜる** のが基本です。

**粉をふるう理由**

- ダマ（かたまり）をなくす
- 空気を含ませて、ほかの材料と混ざりやすくする
- ゴミや異物を取り除く
- ベーキングパウダーやココアなどを均一に混ぜる

**そのほかの粉**

- **アーモンドプードル** ── アーモンドの粉。コクとしっとり感（マカロン、フィナンシェ）
- **コーンスターチ** ── とうもろこしのでんぷん。軽い食感、とろみづけ
- **米粉** ── グルテンを含まない。もっちり・しっとり

## 2-2 砂糖

| 種類 | 特徴 | 向いているお菓子 |
|---|---|---|
| グラニュー糖 | くせのない甘さ、さらさら | 洋菓子全般 |
| 上白糖 | 転化糖を含み、しっとり。焼き色がつきやすい | カステラ、和菓子 |
| 粉糖（粉砂糖） | グラニュー糖を細かくしたもの。溶けやすい | アイシング、クッキー、仕上げの飾り |
| 三温糖・きび砂糖 | コクがある、やや茶色 | 素朴な焼き菓子 |
| 和三盆 | 香川・徳島の伝統的な砂糖。口どけが良い | 干菓子 |
| はちみつ・メープルシロップ | 風味、しっとり、焼き色が濃くなる | 焼き菓子 |

**砂糖の働き**

- 甘みをつける
- **水分を抱える（保水性）** ── しっとりさせ、硬くなりにくくする
- **焼き色をつける**（メイラード反応・カラメル化）
- **泡を安定させる** ── メレンゲの泡が消えにくくなる
- **日持ちを良くする**（微生物が使える水分を減らす）
- 卵の凝固を遅らせ、なめらかにする（プリンなど）

> **ポイント**　砂糖を減らしすぎると、甘さだけでなく **しっとり感・焼き色・泡の安定** まで失われます。

## 2-3 卵

| 性質 | 内容 | 利用するお菓子 |
|---|---|---|
| **起泡性** | 泡立てると空気を含む。卵白は特に泡立ちやすい | スポンジ、メレンゲ、シフォン |
| **乳化性** | 卵黄の **レシチン** が、水と油を混ぜ合わせる | マヨネーズ、バター生地、カスタード |
| **熱凝固性** | 加熱すると固まる。卵白は約60℃前後から固まり始め約80℃で固まる。卵黄は約65℃前後から固まり始め約70℃前後で固まる | プリン、カスタード |

- **全卵** は、湯せんで人肌程度（約35〜40℃）に温めると泡立ちやすくなります。
- **卵白** は、冷やしたほうが泡はきめ細かく安定しますが、泡立てに時間がかかります。油分や卵黄が少しでも混ざると泡立ちにくくなります。
- 卵の大きさで重さが違うため、レシピの「卵1個」は **約50g（殻を除く）** として、グラムで量るのが確実です。

## 2-4 油脂

**油脂の3つの性質**

| 性質 | 内容 | 例 |
|---|---|---|
| **クリーミング性** | 泡立てると空気を抱き込む | パウンドケーキ（バターと砂糖をすり混ぜる） |
| **ショートニング性** | グルテンのつながりを切り、**サクサク・ほろほろ** にする | クッキー、タルト生地 |
| **可塑性（かそせい）** | 力を加えると形が変わり、そのまま保つ（粘土のような性質） | パイ生地（バターを薄くのばして折り込む） |

| 種類 | 特徴 |
|---|---|
| 無塩バター | お菓子作りの基本。塩分で味が変わらない |
| 発酵バター | 乳酸菌で発酵させたバター。香りが豊か |
| 有塩バター | 塩分を含む。お菓子に使うと塩味がつく |
| ショートニング | 植物油などから作る固形油脂。サクサク感が出る。風味はほぼない |
| マーガリン | バターの代わりに使われる。風味はバターに劣る |
| 植物油（サラダ油など） | 液体。冷えても固まりにくく、しっとり（シフォンケーキ、マフィン） |

- バターを「常温に戻す」とは、**指で押すとすっと入る柔らかさ**（一般に約20℃前後）が目安です。溶かしてしまうとクリーミング性がなくなります。
- バターは温度で状態が変わるので、**レシピの指示（冷たいまま／柔らかく／溶かす）を守る** ことが大切です。

## 2-5 乳製品

| 種類 | 特徴 |
|---|---|
| 牛乳 | 生地をのばす、風味、焼き色 |
| 生クリーム（動物性） | 乳脂肪分 **約35〜47％**。脂肪分が高いほど濃厚で泡立てやすいが、分離しやすい |
| ホイップ用植物性クリーム | 植物性油脂が原料。安定しやすく、あっさり |
| クリームチーズ | チーズケーキ、フロスティング |
| ヨーグルト・サワークリーム | 酸味としっとり感 |

**生クリームの泡立て**

- ボウルの底を **氷水で冷やしながら** 泡立てる（約10℃以下が目安）。
- 泡立ての目安：**6〜7分立て**（とろりと流れる：ムース用）、**8分立て**（ツノがおじぎする：ナッペ用）、**9分立て**（ツノがしっかり立つ：絞り用）。
- 泡立てすぎるとボソボソになり、さらに進むと分離します。

## 2-6 塩

- 少量の塩は **甘みを引き立て、味を引き締める** 効果があります（味の対比効果）。
- パイ生地やタルト生地、キャラメルなどでは、塩が風味を良くします。
- 有塩バターを使うときは、塩を減らします。

## 2-7 膨張剤

| 種類 | しくみ | 特徴 |
|---|---|---|
| **ベーキングパウダー** | 重曹（炭酸水素ナトリウム）＋酸性剤＋分散剤（でんぷん）。水分と熱で炭酸ガスが出る | 均一にふくらむ。くせが少ない |
| **重曹（ベーキングソーダ）** | 加熱で炭酸ガスが出る | 横に広がるようにふくらむ。入れすぎると **苦み** が出て、**黄色っぽく** なる。どら焼き、かりんとう |
| イースト | 発酵で炭酸ガスが出る | 一部の発酵菓子（サバランなど） |
| 卵の泡・空気 | 泡や空気が熱でふくらむ | スポンジ、メレンゲ |
| 水蒸気 | 生地の水分が蒸気になってふくらむ | シュー生地、パイ生地 |

- ベーキングパウダーは、粉と一緒に **ふるって均一に** します。
- 湿気で効果が落ちるので、開封後は早めに使います。

## 2-8 ゼラチン・寒天・アガー（凝固剤）

| | ゼラチン | 寒天 | アガー |
|---|---|---|---|
| 原料 | 動物（牛・豚）のコラーゲン | 海藻（テングサなど） | 海藻（カラギーナン）、豆（ローカストビーンガム）など |
| 溶かす温度 | **約50〜60℃**（沸騰させると固まる力が弱まる） | **沸騰させて** 煮溶かす（約90℃以上） | 約90℃以上 |
| 固まる温度 | 冷蔵庫（約20℃以下）で固まる | **常温（約40℃前後）** で固まる | 常温（約30〜40℃）で固まる |
| 食感 | ぷるぷる、口の中で溶ける | しっかり、歯切れが良い | ぷるぷる、透明感 |
| 主なお菓子 | ゼリー、ムース、ババロア | 羊羹、ところてん、あんみつ | 透明なゼリー |

> **注意**　**パイナップル・キウイ・パパイヤ・マンゴーなどの生の果物** には、たんぱく質を分解する酵素（プロテアーゼ）が含まれ、**ゼラチンが固まらなくなる** ことがあります。加熱した果物や缶詰を使うか、寒天・アガーを使いましょう。

## 2-9 チョコレート

- **テンパリング（温度調整）** ── 一度溶かし、冷まし、少し温め直すことで、カカオバターの結晶をそろえ、**つや・パリッとした口どけ** を出す作業です。
- 温度の目安（一例・ダークチョコレート）：**約50〜55℃で溶かす → 約27〜28℃まで下げる → 約31〜32℃に上げる**。ミルクやホワイトはこれより低め。メーカーの表示温度を優先します。
- 失敗すると、表面が白くなる **ブルーム現象** が起こります（脂肪が浮き出るファットブルーム、湿気で砂糖が浮き出るシュガーブルーム）。

## 2-10 水の温度

- 材料の水分の温度は、**生地の温度** を左右します。
- **タルト・パイ生地** ── 冷水を使い、バターを溶かさないようにする（サクサクにするため）。
- **ゼラチンをふやかす** ── 冷水を使う（ぬるま湯だと溶けてダマになる）。
- **シュー生地** ── 水・バターを **しっかり沸騰** させてから粉を入れ、でんぷんを糊化させる。
- **ドライイースト** ── 40℃前後のぬるま湯で予備発酵。

> **ここを覚える**
> - お菓子は薄力粉、粉を入れたらさっくり混ぜる（グルテンを作りすぎない）
> - 砂糖＝甘み・保水・焼き色・泡の安定・日持ち
> - 卵＝起泡性・乳化性（レシチン）・熱凝固性
> - 油脂＝クリーミング性・ショートニング性・可塑性
> - 重曹は入れすぎると苦く黄色に。BP＝重曹＋酸性剤＋分散剤
> - ゼラチンは沸騰させない、生のパイナップル・キウイで固まらない／寒天は沸騰させる

# 第3章 道具の種類と選び方

## 3-1 はかる道具

| 道具 | 選び方・使い方のポイント |
|---|---|
| **デジタルスケール** | **最小1g単位、できれば0.1g単位** で量れるもの。最大2kg程度量れると便利。容器をのせて表示を0にする「風袋（ふうたい）引き」機能があるものが使いやすい |
| **計量カップ** | 目盛りが見やすく、耐熱性のあるもの。**平らな場所に置いて、真横から目盛りを読む** |
| **計量スプーン** | **大さじ＝15ml、小さじ＝5ml**（小さじ1/2もあると便利）。粉は山盛りにすくって、すりきりで量る |
| **温度計** | 生地・シロップ・チョコレートの温度を測る。**デジタル温度計**（すぐ測れる）や、高温まで測れる棒状の温度計 |
| **タイマー** | 焼き時間・冷やし時間を正確に |

> **ポイント**　お菓子作りでは、カップやスプーンより **重さ（g）で量る** ほうが正確です。粉は詰め方で体積あたりの重さが大きく変わるからです。

## 3-2 混ぜる道具

| 道具 | 選び方・使い方のポイント |
|---|---|
| **ボウル** | ステンレス製は **冷やしたり温めたり（湯せん）しやすい**。耐熱ガラスは電子レンジが使える。大・中・小とそろえると便利 |
| **泡立て器（ホイッパー）** | ワイヤーの本数が多いものは泡立てやすい。**ボウルの大きさに合った長さ** のものを選ぶ |
| **ハンドミキサー** | メレンゲ・全卵の泡立て、バターのクリーム状にするのが楽。速度調整ができるもの |
| **スタンドミキサー** | 大量の生地や長時間の泡立てに。両手が空く |
| **ゴムベラ（シリコンベラ）** | 生地をさっくり混ぜる、ボウルの生地を残さず集める。**耐熱性のシリコン製** は加熱調理にも使える。一体型は衛生的 |
| **木べら** | 加熱しながら混ぜる（カスタード、シュー生地）。こしがあり力を入れやすい |
| **カード（スケッパー）** | 生地を切る・集める・平らにする。タルト生地やパイ生地に |
| **粉ふるい・こし器** | 粉をふるう、液体をこしてなめらかにする（プリン液など） |

## 3-3 そのほかの道具

| 道具 | 用途 |
|---|---|
| 型（丸型、パウンド型、タルト型、マフィン型、シフォン型） | 生地を焼く。底が抜けるタイプは取り出しやすい |
| めん棒・ルーラー | 生地を均一な厚さにのばす |
| 絞り袋・口金 | クリームや生地を絞る（丸口金・星口金など） |
| パレットナイフ | クリームを塗る（ナッペ） |
| 回転台 | ケーキにクリームを塗るときに回す |
| オーブンシート・クッキングシート | 型や天板に敷く |
| ケーキクーラー | 焼き菓子を冷ます |
| 刷毛（はけ） | シロップや卵液を塗る |

# 第4章 オーブンを使ったお菓子作り

## 4-1 オーブンの基本

- **予熱は必ず行う** ── 予熱が足りないと、ふくらまない・焼きムラ・生焼けの原因になります。予熱中に生地を作り終えるように段取りします。
- **オーブンにはくせがある** ── 同じ温度設定でも、機種によって焼け方が違います。レシピの温度と時間は目安と考え、焼き色や竹串で確認します。
- **扉を何度も開けない** ── 庫内の温度が下がります。特にスポンジやシュー生地は、ふくらんでいる途中で開けるとしぼむことがあります。
- **焼きムラ対策** ── 焼き色に差が出てきたら、途中で天板の前後を入れ替えます（焼き時間の後半に、手早く）。

## 4-2 ガスオーブンと電気オーブン

| | ガスオーブン | 電気オーブン |
|---|---|---|
| しくみ | ガスの炎で熱した空気を、ファンで庫内に循環させる | 電熱ヒーターで加熱する（ファン付きのものもある） |
| 火力 | **強い**。立ち上がり（予熱）が速い | ガスより **弱め**。予熱に時間がかかる |
| 庫内の状態 | **乾燥しやすい**（焼き菓子がカリッと焼ける） | **水分が残りやすい**（しっとりしやすい） |
| 注意点 | 焼き色がつきやすく、表面が早く焼ける。ファンの風で焼きムラが出ることも | 扉を開けたときの温度低下が大きい。ヒーターに近い部分が焦げやすい |
| 温度設定の目安 | レシピどおり、または **少し低め** | レシピ（ガス基準）より **約10〜20℃高め** にすることが多い |

※温度差は機種によって違います。自分のオーブンで何度か試して、くせをつかみましょう。

## 4-3 天板の位置と焼き方

- **上段** ── 上火が強く当たり、表面に焼き色がつきやすい
- **中段** ── 最も標準的
- **下段** ── 底がしっかり焼ける（タルトの底など）
- 2段で焼くときは、途中で上下を入れ替えます。
- 焼き色がつきすぎたら、**アルミホイルをかぶせる** と表面の焦げを防げます。

## 4-4 蒸し焼き（湯せん焼き）

**蒸し焼き（湯せん焼き）とは**　天板に **湯を張り**、その中に型を置いて焼く方法です。

| 目的 | 説明 |
|---|---|
| 温度がゆっくり上がる | 湯があるため、生地の温度が100℃以上に急に上がらず、**低温でじっくり** 火が通る |
| なめらかに仕上がる | 卵の **急な凝固を防ぎ**、口当たりがなめらかになる |
| 「す」が立つのを防ぐ | 「す」＝生地の中の水分が沸騰してできる小さな穴。プリンでよく起こる |
| 乾燥・割れを防ぐ | 蒸気で表面が乾きにくく、ひび割れしにくい |

**蒸し焼きにする主なお菓子**　プリン（カスタードプディング）、ベイクドチーズケーキ、スフレチーズケーキ、ガトーショコラの一部

**ポイント**

- **底が抜ける型** を使うときは、湯が入らないように型の外側をアルミホイルで包みます。
- 湯は **お湯（約50〜60℃以上）** を使います。水だと温度が上がるまでに時間がかかります。
- 途中で湯がなくなったら足します。

## 4-5 焼き上がりの確認

- **竹串を刺す** ── 何もついてこなければ焼き上がり（スポンジ、パウンドケーキ）。
- **指で軽く押す** ── 弾力があって跳ね返れば焼き上がり（スポンジ）。
- **焼き色** ── 全体にきれいな焼き色がついているか。
- **揺らす** ── プリンやチーズケーキは、中心が少しふるふるする程度（冷めると固まる）。

> **ここを覚える**
> - 予熱は必ず。扉はむやみに開けない
> - ガス＝火力が強く乾燥しやすい、電気＝火力弱めで水分が残りやすく、約10〜20℃高めに設定することが多い
> - 蒸し焼き＝湯を張って低温でじっくり → なめらか、「す」防止（プリン、チーズケーキ）

# 第5章 生地とクリームの基本

## 5-1 スポンジ生地

| 方法 | やり方 | 仕上がり |
|---|---|---|
| **共立て（ともだて）** | **全卵** をそのまま泡立てる | きめ細かく、しっとり |
| **別立て** | 卵黄と卵白を **分けて** 泡立て、後で合わせる | 軽くふんわり。泡立てやすく初心者向き |

## 5-2 バター生地（パウンドケーキなど）

| 方法 | やり方 | 特徴 |
|---|---|---|
| **シュガーバッター法** | バターと砂糖をすり混ぜて空気を含ませ、卵、粉の順に加える | 最も一般的。ふんわり |
| **フラワーバッター法** | バターと粉を先に混ぜ、卵と砂糖を泡立てたものと合わせる | きめが細かく、しっとり |
| **オールインワン法** | すべての材料を一度に混ぜる | 手軽 |

**分離に注意**　バターに卵を一度に入れたり、卵が冷たかったりすると、水分と油分が分かれて **分離** します。卵は常温に戻し、**少しずつ** 加えます。分離したら、粉を少量加えるとまとまりやすくなります。

## 5-3 タルト生地・パイ生地

| 生地 | 特徴 |
|---|---|
| **パート・シュクレ** | 砂糖が多く、甘くサクサク。タルト台 |
| **パート・サブレ** | さらに砂糖・バターが多く、ほろほろ |
| **パート・ブリゼ** | 砂糖が少ない（または入れない）。キッシュなど |
| **折り込みパイ生地** | 生地でバターを包み、のばして折る作業をくり返して、**何層にも重ねる**。焼くとバターの水分が蒸気になり、層がふくらむ |
| **練り込みパイ生地** | 粉とバターをざっくり混ぜる。手軽 |

タルト・パイ生地は、**冷やして休ませる** ことで、グルテンが落ち着いて縮みにくく、バターも溶けにくくなります。

## 5-4 シュー生地

- 水（牛乳）・バターを **沸騰** させ、粉を加えて加熱しながら混ぜ、でんぷんを **糊化** させます。
- 卵を少しずつ加え、木べらで持ち上げると **三角形に垂れ下がる** 固さに調整します。
- 焼くと生地の水分が **水蒸気** になり、糊化した生地が風船のようにのびて、中が空洞になります。
- **焼いている途中で扉を開けるとしぼむ** ので注意します。

## 5-5 メレンゲ

| 種類 | 作り方 | 用途 |
|---|---|---|
| **フレンチメレンゲ** | 卵白に砂糖を加えながら泡立てる | 焼き菓子、スポンジ、シフォン |
| **イタリアンメレンゲ** | 卵白に **約117〜120℃** に煮詰めた熱いシロップを加えて泡立てる | 安定性が高い。ムース、バタークリーム |
| **スイスメレンゲ** | 卵白と砂糖を **湯せん** で温めながら泡立てる | 硬めでつやがある。飾り |

## 5-6 クリーム

| クリーム | 材料 | 用途 |
|---|---|---|
| カスタードクリーム（クレーム・パティシエール） | 牛乳・卵黄・砂糖・粉（薄力粉やコーンスターチ） | シュークリーム、タルト |
| ホイップクリーム（クレーム・シャンティ） | 生クリーム・砂糖 | ショートケーキ |
| バタークリーム | バター・砂糖（メレンゲや卵黄を使うことも） | デコレーションケーキ |
| アーモンドクリーム（クレーム・ダマンド） | バター・砂糖・卵・アーモンドプードル | タルトの中身（焼いて使う） |
| ガナッシュ | チョコレート・生クリーム | トリュフ、ケーキ |

# 第7章 よくある失敗・衛生・保存

## 7-1 よくある失敗と原因

| 失敗 | 主な原因 |
|---|---|
| スポンジがふくらまない | 卵の泡立て不足、粉を混ぜすぎて泡が消えた、オーブンの予熱不足 |
| スポンジがしぼむ | 焼き不足、扉の開けすぎ、焼き上がり後に衝撃を与えていない（蒸気が抜けず縮む） |
| ケーキが硬い | 粉を混ぜすぎてグルテンができた、焼きすぎ |
| クッキーが広がる | バターが溶けた、生地を冷やしていない、砂糖が多い |
| プリンに「す」が立つ | 温度が高すぎる、加熱しすぎ（蒸し焼きで防ぐ） |
| ゼリーが固まらない | ゼラチンを沸騰させた、量が少ない、生のパイナップル・キウイなどを入れた |
| チョコレートが白くなる | テンパリングの失敗、保存温度・湿度（ブルーム） |
| 生クリームが分離する | 泡立てすぎ、温度が高い |

## 7-2 衛生管理

- 作業前・卵を触った後は、**石けんで手を洗う**。
- 卵は **新鮮なもの** を使い、ひび割れた卵は加熱用にする（サルモネラ菌による食中毒予防）。
- 生クリームやカスタードは **細菌が増えやすい** ので、作ったらすぐ冷やし、早めに食べる。
- まな板・ふきんは清潔にし、よく乾かす。

## 7-3 保存の目安

| お菓子 | 保存方法 |
|---|---|
| クッキー・焼き菓子 | 乾燥剤と一緒に密閉容器で常温 |
| 生クリーム・カスタードを使ったケーキ | **冷蔵** し、当日〜翌日中に食べる |
| パウンドケーキ | ラップで包んで常温または冷蔵。冷凍も可能 |
| チョコレート | 約15〜18℃前後の涼しい場所（冷蔵庫に入れるときは密閉して結露に注意） |

## 7-4 アレルギー表示

食品表示法では、アレルギーを起こしやすい食品が定められています。

- **表示が義務の「特定原材料」** ── えび、かに、くるみ、小麦、そば、卵、乳、落花生（ピーナッツ）の **8品目**（くるみは2023年に追加され、2025年4月から完全義務化）
- **表示が推奨される品目** ── アーモンド、カシューナッツ、大豆、ごま、ゼラチンなど約20品目

> **注意**　アレルギー表示の品目は見直されることがあります（カシューナッツの義務化などが検討されています）。お菓子を販売・提供するときは、**消費者庁の最新情報** を必ず確認してください。また、お菓子を販売するには、**菓子製造業の営業許可** などが必要です（保健所に相談）。
