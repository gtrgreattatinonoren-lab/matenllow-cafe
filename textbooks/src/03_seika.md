# 第1章 お菓子作りの基本

## 1-1 お菓子作りは「科学」

料理は味を見ながら調整できますが、お菓子は **焼く前に配合と手順が決まっていないと失敗しやすい** のが特徴です。材料の量・温度・混ぜ方が、ふくらみや食感を大きく左右します。

**お菓子作りの基本の3原則**

1. **正確に量る** ── 目分量にしない。グラムで量る
2. **温度を守る** ── 材料の温度、生地の温度、オーブンの温度
3. **手順を守る** ── 混ぜる順番、混ぜ方、混ぜる時間

## 1-2 作り始める前の準備（下準備）

| 下準備 | 理由 |
|---|---|
| レシピを最後まで読む | 途中で手が止まると、泡が消えたり生地が冷えたりする |
| 材料をすべて量っておく | 作業中に量ると時間がかかり、生地の状態が変わる |
| バター・卵を **常温に戻す**（レシピの指示に従う） | 冷たいと混ざりにくく、分離の原因になる |
| 粉類を **ふるう** | ダマをなくし、空気を含ませる |
| 型に紙を敷く、またはバターを塗って粉をはたく | 焼いた後に型から外しやすくする |
| **オーブンを予熱する** | 生地ができたらすぐ焼けるようにする |
| 湯せん用のお湯、氷水などを用意する | 温度管理のため |

## 1-3 洋菓子の分類

| 分類 | 説明 | 例 |
|---|---|---|
| **生菓子（なまがし）** | 水分が多く、日持ちしないお菓子 | ショートケーキ、シュークリーム、ムース、プリン |
| **半生菓子** | 水分がやや多い焼き菓子 | マドレーヌ、フィナンシェ、パウンドケーキ |
| **焼き菓子・干菓子** | 水分が少なく、日持ちするお菓子 | クッキー、ビスケット、メレンゲ菓子 |
| **冷菓** | 冷やして固める・凍らせるお菓子 | ゼリー、ババロア、アイスクリーム |
| **砂糖菓子・チョコレート菓子** | 砂糖やチョコレートが主体 | キャンディ、トリュフ、ボンボン・ショコラ |

## 1-4 フランス語の製菓用語（よく使うもの）

| 用語 | 意味 |
|---|---|
| パティスリー（pâtisserie） | お菓子、お菓子屋 |
| パティシエ（pâtissier） | お菓子職人 |
| ガトー（gâteau） | ケーキ、お菓子 |
| パート（pâte） | 生地 |
| クレーム（crème） | クリーム |
| アパレイユ（appareil） | 混ぜ合わせた液状の生地（流し込む生地） |
| ナッペ（napper） | クリームなどを塗ること |
| ムラング（meringue） | メレンゲ |
| グラサージュ（glaçage） | 表面をつやのある衣で覆うこと |
| アンビベ（imbiber） | 生地にシロップをしみこませること |

> **ここを覚える**
> - 3原則：正確に量る・温度を守る・手順を守る
> - 下準備：材料を量る、常温に戻す、粉をふるう、型の準備、予熱
> - 生菓子・半生菓子・焼き菓子（干菓子）・冷菓

# 第2章 小麦粉とグルテン

## 2-1 小麦粉の種類

| 種類 | たんぱく質（目安） | 原料 | グルテン | お菓子での用途 |
|---|---|---|---|---|
| **薄力粉** | 約6.5〜9％ | **軟質小麦** | **少なく弱い** | スポンジ、クッキー、マフィン、タルトなど **ほとんどの洋菓子** |
| 中力粉 | 約8〜10.5％ | 中間質小麦 | 中くらい | 一部の焼き菓子、和菓子 |
| **強力粉** | 約11.5〜13.5％ | **硬質小麦** | **多く強い** | パイ生地の一部、シュー生地の一部、**打ち粉** |

※数値は一般的な目安で、製品によって違います。

**打ち粉に強力粉が使われる理由**　強力粉は粒子が粗く **さらさらしていて散りやすい** ため、台や生地に薄く均一にまぶせ、生地に吸収されにくいからです。

## 2-2 グルテンのしくみ

- 小麦粉に含まれる2つのたんぱく質 **グルテニン（弾力）** と **グリアジン（粘り・伸び）** が、**水と一緒に混ぜたりこねたりする** と結びついて、網目状の **グルテン** ができます。
- グルテンは、**混ぜる・こねるほど強くなります**。

**パンとお菓子のちがい**

| | パン | 多くのお菓子 |
|---|---|---|
| グルテン | **しっかり作る**（ガスを閉じ込めてふくらませる） | **作りすぎない** |
| 粉 | 強力粉 | 薄力粉 |
| 混ぜ方 | よくこねる | **さっくり混ぜる** |
| 目指す食感 | もっちり、弾力 | ふんわり、さっくり、ほろほろ |

**グルテンができすぎると…**

- 生地が **硬く、弾力が強く** なる
- **ふくらみが悪く、目が詰まる**
- クッキーやタルトが **縮む・硬くなる**

**グルテンを作りすぎないコツ**

1. **薄力粉** を使う
2. 粉を加えた後は、ゴムベラで **切るように「さっくり」混ぜる**（練らない）
3. 粉っぽさがなくなったら **混ぜすぎない**
4. タルト・パイ生地は **冷やして休ませる**（グルテンが落ち着き、縮みにくくなる）
5. 油脂を先に粉にまぶす（**サブラージュ**：グルテンができにくくなる）

## 2-3 粉をふるう理由

| 理由 | 説明 |
|---|---|
| ダマをなくす | 小麦粉は湿気でかたまりやすい |
| **空気を含ませる** | 生地に混ざりやすくなり、軽く仕上がる |
| 異物を取り除く | ゴミなどを除く |
| **ほかの粉と均一に混ぜる** | ベーキングパウダー、ココア、アーモンドプードルなどを均一に |

※ふるった粉は、時間がたつと再び湿気を吸うので、使う直前にふるうのが理想です。

## 2-4 小麦粉以外の粉

| 粉 | 特徴 | 主な用途 |
|---|---|---|
| **アーモンドプードル（パウダー）** | アーモンドを粉にしたもの。油分が多く、**コクとしっとり感** | マカロン、フィナンシェ、ダックワーズ、クレーム・ダマンド |
| **コーンスターチ** | とうもろこしの **でんぷん**。グルテンを作らない | 一部を置き換えて **軽くほろほろ** に（ショートブレッドなど）、カスタードのとろみ |
| **米粉** | **グルテンを含まない**。もっちり・しっとり。吸水しやすい | グルテンフリーのお菓子 |
| ココアパウダー | カカオの固形分を粉にしたもの。**無糖** のものを使う | チョコレート生地 |
| 全粒粉 | 小麦を丸ごと挽いた粉。香ばしい | 素朴なクッキー |
| きな粉・抹茶など | 風味・色づけ | |

> **ここを覚える**
> - お菓子は薄力粉（軟質小麦・たんぱく質約6.5〜9％）
> - 打ち粉は強力粉（さらさらで散りやすい）
> - グルテン＝グルテニン（弾力）＋グリアジン（粘り）。混ぜるほど強くなる
> - 粉を入れたらさっくり混ぜる。混ぜすぎ＝硬い・ふくらまない
> - ふるう理由：ダマ・空気・異物・均一に混ぜる
> - アーモンドプードル＝コク・しっとり、コーンスターチ＝軽さ・とろみ

# 第3章 砂糖

## 3-1 砂糖の種類

| 種類 | 特徴 | 向いているお菓子 |
|---|---|---|
| **グラニュー糖** | 結晶が細かくさらさら。**くせのない、すっきりした甘さ**。純度が高い | 洋菓子全般 |
| **上白糖** | しっとりしている。**転化糖** を少し含むため、**焼き色がつきやすく**、しっとり仕上がる | カステラ、和菓子、家庭の料理 |
| **粉糖（粉砂糖）** | グラニュー糖を細かく砕いたもの。**溶けやすい**。固まり防止にコーンスターチを加えたものもある | アイシング、クッキー（サクサクに）、仕上げの飾り、マカロン |
| **泣かない粉糖（デコレーション用）** | 油脂などでコーティングし、水分で溶けにくい | ケーキの仕上げ |
| 三温糖 | 加熱を重ねて作るため茶色く、**コク** がある | 煮物、素朴な焼き菓子 |
| きび砂糖・てんさい糖 | ミネラルを含み、やさしい甘さとコク | 焼き菓子 |
| **カソナード・ブラウンシュガー** | サトウキビ由来の茶色い砂糖。独特の風味 | クレーム・ブリュレ、焼き菓子 |
| **和三盆** | 香川・徳島の伝統的な砂糖。口どけが良く、上品な甘さ | 干菓子 |
| **転化糖・水あめ** | 結晶になりにくく、しっとりさせる | 焼き菓子、キャンディ、生チョコ |
| はちみつ | 果糖・ブドウ糖が主成分。風味としっとり感。**焼き色が濃くなりやすい** | カステラ、マドレーヌ |
| メープルシロップ | カエデの樹液を煮詰めたもの。独特の風味 | 焼き菓子 |

## 3-2 砂糖の働き

| 働き | 説明 | お菓子での例 |
|---|---|---|
| **甘みをつける** | ── | ── |
| **保水性（水分を抱える）** | 水分を抱え込んで逃がさない → **しっとり、硬くなりにくい** | スポンジ、パウンドケーキ |
| **焼き色をつける** | **メイラード反応**（糖とアミノ酸）や **カラメル化**（糖そのものが焦げる）で、焼き色と香ばしい香り | 焼き菓子全般 |
| **泡を安定させる** | 卵白の泡のまわりの水分に溶けて、**泡が消えにくくなる** | メレンゲ |
| **防腐性（日持ちを良くする）** | 微生物が使える水分を減らす | ジャム、砂糖漬け |
| **卵の凝固をゆるやかにする** | 卵が固まる温度を上げ、**なめらか** にする | プリン、カスタード |
| **でんぷんの老化を遅らせる** | 硬くなるのを防ぐ | 焼き菓子 |
| ゼリーを作る | 果物のペクチンと酸と一緒に固まる | ジャム |
| 結晶化させる | 煮詰めて冷やすと結晶になる | フォンダン、糖衣 |
| イーストの栄養 | 発酵を助ける | 発酵菓子 |

> **ポイント**　砂糖を減らすと、甘さが減るだけでなく、**しっとり感・焼き色・泡の安定・日持ち** まで失われます。レシピの砂糖を大幅に減らすと失敗しやすいので注意しましょう。

## 3-3 砂糖を煮詰めたときの変化（シロップの温度）

砂糖と水を煮詰めると、温度によって状態が変わります（温度は目安で、資料によって少し違います）。

| 温度（目安） | 状態 | 用途 |
|---|---|---|
| 約103〜105℃ | 薄いシロップ | ボーメ30°のシロップ（生地に塗る）など |
| 約107〜110℃ | 糸を引く | ── |
| **約117〜121℃** | 冷水に落とすと、柔らかい〜やや硬い玉になる | **イタリアンメレンゲ**、パータ・ボンブ |
| 約115〜118℃ | 柔らかい玉 | フォンダン、ファッジ |
| 約130〜140℃ | 硬い玉〜割れる手前 | ヌガー |
| 約145〜155℃ | パリッと割れる | 飴細工、べっこう飴 |
| **約160℃〜** | 茶色く色づく（**カラメル化**） | カラメルソース、プリンのカラメル |

**カラメルソースを作るときの注意**

- 色づき始めたら、焦げるのはあっという間です。
- 火を止めてから水や生クリームを加えると、**激しくはねる** ので、やけどに注意します（お湯を使う、少しずつ加える、手を離す）。

> **ここを覚える**
> - グラニュー糖＝すっきり（洋菓子の基本）、上白糖＝転化糖を含みしっとり・焼き色が濃い、粉糖＝溶けやすい
> - 砂糖の働き：甘み・保水（しっとり）・焼き色・泡の安定・日持ち・卵の凝固をゆるやかに・老化を遅らせる
> - イタリアンメレンゲのシロップ＝約117〜121℃、カラメル化＝約160℃〜

# 第4章 卵

## 4-1 卵の構造

| 部分 | 割合（目安） | 主な成分 |
|---|---|---|
| 殻 | 約10％ | 炭酸カルシウム |
| **卵白** | 約60％ | 約9割が **水分**、残りはほとんどが **たんぱく質** |
| **卵黄** | 約30％ | 約半分が水分。**脂質** とたんぱく質が多い。**レシチン** を含む |

**卵のサイズ（日本の規格）**

| サイズ | 重さ（殻付き） |
|---|---|
| L | 64g以上〜70g未満 |
| **M** | **58g以上〜64g未満** |
| MS | 52g以上〜58g未満 |
| S | 46g以上〜52g未満 |

- レシピの「卵1個」は、**殻を除いて約50g** と考えることが多いです。
- 卵は大きさで重さが違うので、**グラムで量る** のが確実です。
- 卵のサイズによって変わるのは、主に **卵白の量** です（卵黄の大きさはあまり変わらない）。

## 4-2 卵の3つの性質

| 性質 | 内容 | 利用するお菓子 |
|---|---|---|
| **起泡性（きほうせい）** | **泡立てると空気を含む**。卵白は特に泡立ちやすい | スポンジ、メレンゲ、シフォン、スフレ |
| **乳化性（にゅうかせい）** | 卵黄の **レシチン** が、水と油を混ぜ合わせる | マヨネーズ、バター生地（パウンドケーキ）、カスタード、アングレーズソース |
| **熱凝固性（ねつぎょうこせい）** | **加熱すると固まる** | プリン、カスタード、焼き菓子の骨組み |

**卵の固まる温度（目安）**

| | 固まり始め | しっかり固まる |
|---|---|---|
| **卵白** | 約60℃前後 | 約80℃前後 |
| **卵黄** | 約65℃前後 | 約70℃前後 |

※この温度差を利用したのが **温泉卵**（卵黄が固まり、卵白が固まりきらない、約65〜70℃でゆっくり加熱）です。
※砂糖や牛乳を加えると、固まる温度は高くなり、**なめらか** に仕上がります。

## 4-3 泡立て（起泡性）のポイント

**全卵の泡立て（共立て）**

- 湯せんで **人肌程度（約35〜40℃）** に温めると、卵の表面張力が下がって **泡立ちやすく** なります。
- 泡立てすぎた後に温めたままにすると、泡が粗くなるので、温めたら湯せんから外して泡立て続けます。
- 泡立て器ですくって落としたとき、**リボン状に重なり、跡がしばらく残る** くらいが目安です。

**卵白の泡立て（メレンゲ）**

| ポイント | 理由 |
|---|---|
| **ボウルや泡立て器に、油分や水分をつけない** | 油分があると泡立たない |
| **卵黄を少しでも混ぜない** | 卵黄の脂質で泡立たなくなる |
| **冷やした卵白** を使う | 泡立てに時間はかかるが、**きめが細かく安定した泡** になる |
| 常温の卵白 | 泡立ちやすいが、泡が粗く消えやすい |
| **砂糖は何回かに分けて加える** | 最初から全部入れると泡立ちにくい。後から入れると泡が安定する |
| 少量のレモン汁・クリームタータ（酒石酸） | 泡を安定させる |
| 泡立てすぎない | **泡立てすぎるとボソボソになり**、生地に混ぜにくい |

**メレンゲの泡立ての段階**

| 段階 | 状態 |
|---|---|
| 5〜6分立て | 白く泡立つが、すくうとすぐ落ちる |
| 7〜8分立て | ツノが立つが、先がおじぎする |
| **9分立て（しっかり）** | **ツノがピンと立ち、つやがある** |
| 泡立てすぎ | つやがなく、ボソボソと分離する |

## 4-4 卵の鮮度と扱い

- **新しい卵** は、割ったとき **卵黄が盛り上がり、濃厚卵白（卵黄のまわりの濃い卵白）がしっかり** している。
- 古くなると、卵白が水っぽくなり（水様卵白が増える）、卵黄が平たくなる。
- **新しい卵白はコシが強く泡立ちにくいが安定した泡**、**古い卵白は泡立ちやすいが泡が消えやすい** といわれます。
- 卵は **冷蔵保存** し、ひびが入ったものは **加熱用** に使います（サルモネラ菌などの食中毒予防）。
- 生食用の卵の賞味期限は、**生で食べられる期限** です。期限を過ぎたら、しっかり加熱して早めに使います。

> **ここを覚える**
> - 卵＝殻約10％・卵白約60％・卵黄約30％。M玉は58〜64g。1個約50g（殻なし）
> - 起泡性・乳化性（卵黄のレシチン）・熱凝固性
> - 卵白は約60℃で固まり始め約80℃で固まる、卵黄は約65℃で固まり始め約70℃で固まる
> - 全卵は約35〜40℃に温めると泡立ちやすい
> - メレンゲは油分・卵黄厳禁、砂糖は分けて加える

# 第5章 油脂と乳製品

## 5-1 油脂の3つの性質

| 性質 | 内容 | 例 |
|---|---|---|
| **クリーミング性** | 泡立てると **空気を抱き込む** | パウンドケーキ（バターと砂糖を白っぽくなるまですり混ぜる）、バタークリーム |
| **ショートニング性** | グルテンのつながりを切り、**サクサク・ほろほろ（もろい食感）** にする | クッキー、タルト生地、パイ生地 |
| **可塑性（かそせい）** | 力を加えると形が変わり、**そのまま形を保つ**（粘土のような性質） | **折り込みパイ生地**（バターを薄くのばして生地に折り込む） |

※ショートニング性の「ショート（short）」は、英語で「もろい、さくい」という意味です。

## 5-2 油脂の種類

| 種類 | 特徴 |
|---|---|
| **無塩バター（食塩不使用バター）** | **お菓子作りの基本**。塩分で味が変わらない |
| 有塩バター | 塩分（約1〜2％）を含む。お菓子に使うと塩味がつく |
| **発酵バター** | 原料のクリームを **乳酸菌で発酵** させてから作るバター。**香りが豊か** |
| **澄ましバター** | バターを溶かして、上の透明な脂肪分だけを取り出したもの。焦げにくい |
| **焦がしバター（ブール・ノワゼット）** | バターを加熱して、**ヘーゼルナッツ（ノワゼット）色** に焦がしたもの。香ばしい。**フィナンシェ** に使う |
| **ショートニング** | 植物油などから作る固形の油脂。**風味はほとんどない**。サクサク感が強い |
| マーガリン | バターの代わりとして作られた。風味はバターに劣る |
| **植物油（サラダ油・米油など）** | 液体。**冷えても固まりにくく、しっとり** → シフォンケーキ、マフィン、冷やして食べるケーキ |
| ラード | 豚の脂。中華菓子など |

**バターの規格**　乳等省令では、バターは **乳脂肪分80.0％以上、水分17.0％以下** と決められています。

## 5-3 バターの温度と状態

| 状態 | 目安 | 使い方 |
|---|---|---|
| **冷たいまま** | 冷蔵庫から出してすぐ | パイ生地、スコーン、タルト生地（すり合わせる方法） ── バターを溶かさず、粒を残す |
| **常温に戻す（ポマード状）** | **指で押すとすっと入る柔らかさ**（約20℃前後） | パウンドケーキ、クッキー、バタークリーム ── 空気を含ませる |
| **溶かす** | 湯せんや電子レンジで液体に | マドレーヌ、フィナンシェ、ジェノワーズ（最後に加える） |

> **注意**　一度溶けたバターを冷やして固め直しても、**クリーミング性は元に戻りません**。常温に戻すときは、溶かしすぎないようにしましょう。

## 5-4 乳製品

| 種類 | 特徴 |
|---|---|
| **牛乳** | 生地をのばす、風味、焼き色（乳糖）。約9割が水分 |
| **生クリーム（クリーム）** | 乳等省令では「クリーム」は **乳脂肪分18.0％以上**。お菓子用のホイップには **乳脂肪分約35〜47％** のものがよく使われる |
| ホイップ用植物性クリーム | 植物性脂肪が原料。泡立てても安定しやすく、あっさり |
| クリームチーズ | チーズケーキ、フロスティング |
| マスカルポーネ | イタリアのクリームチーズ。ティラミス |
| ヨーグルト・サワークリーム | 酸味としっとり感 |
| スキムミルク（脱脂粉乳） | 牛乳の代わりに |
| 練乳（加糖練乳） | 甘みとコク |

## 5-5 生クリームの泡立て

| ポイント | 理由 |
|---|---|
| ボウルの底を **氷水で冷やしながら** 泡立てる | 温度が高い（約10℃以上）と、**脂肪が溶けて分離しやすい** |
| 乳脂肪分が高いほど | 早く泡立ち、濃厚だが、**分離しやすい** |
| 砂糖は最初から入れてよい（一般に生クリームの約6〜10％） | ── |

**泡立ての段階**

| 段階 | 状態 | 用途 |
|---|---|---|
| 6分立て | とろりと流れ、跡がすぐ消える | ソース、ムース |
| 7分立て | とろりと流れ、跡が少し残る | ムース、ケーキの下塗り |
| **8分立て** | **ツノが立つが、先がおじぎする** | **ナッペ（塗る）**、ケーキのサンド |
| 9分立て | ツノがしっかり立つ | 絞り出し |
| 泡立てすぎ | ボソボソになり、さらに進むと **分離（バターと水分に分かれる）** | ── |

> **ここを覚える**
> - クリーミング性（空気を抱く）・ショートニング性（サクサク）・可塑性（折り込み）
> - バター＝乳脂肪分80.0％以上。無塩バターが基本。発酵バター＝香り
> - 焦がしバター＝フィナンシェ／植物油＝冷えても固まらずしっとり（シフォン）
> - バターの常温＝指がすっと入る（約20℃前後）。溶かすとクリーミング性は戻らない
> - 生クリームは氷水で冷やして泡立てる。8分立て＝ナッペ

# 第6章 膨張剤・凝固剤・チョコレート・塩・水

## 6-1 膨張剤とふくらむしくみ

| ふくらませるもの | しくみ | お菓子の例 |
|---|---|---|
| **卵の泡（空気）** | 泡立てた空気が熱でふくらむ | スポンジ、シフォン、メレンゲ |
| **バターに含ませた空気** | クリーミングで抱き込んだ空気 | パウンドケーキ |
| **水蒸気** | 生地の水分が蒸気になってふくらむ | **シュー生地**、**パイ生地** |
| **化学膨張剤** | 加熱や水分で炭酸ガスが出る | マフィン、クッキー、どら焼き |
| **イースト** | 発酵で炭酸ガスが出る | サバラン、クグロフ、シュトーレン |

## 6-2 化学膨張剤

| 種類 | 成分・しくみ | 特徴 |
|---|---|---|
| **ベーキングパウダー（BP）** | **重曹（炭酸水素ナトリウム）＋酸性剤＋分散剤（コーンスターチなど）**。水分と熱で炭酸ガスが出る | **均一に縦にふくらむ**。くせが少ない。酸性剤で中和されるので、苦み・色の変化が少ない |
| **重曹（ベーキングソーダ）** | 炭酸水素ナトリウム。加熱で炭酸ガスが出る | **横に広がるようにふくらむ**。アルカリ性のため、**入れすぎると苦み・えぐみが出て、生地が黄色っぽく** なる。焼き色が濃くなる。どら焼き、かりんとう、黒糖まんじゅう |
| イスパタ（イーストパウダー） | 重曹を主成分にした膨張剤 | 中華まん、蒸し菓子（白く仕上がる） |

**ベーキングパウダーの注意点**

- **粉と一緒にふるって、均一に** 混ぜる（ムラがあると、穴や苦みの原因）。
- **湿気** で反応して効果が落ちるので、開封後は密閉して、早めに使い切る。
- 入れすぎると、ふくらみすぎて **しぼんだり、パサついたり、苦み** が出たりする。
- 最近は **アルミニウム（ミョウバン）を含まない** ベーキングパウダーも多く売られている。

**重曹を使うお菓子のポイント**　ココア、はちみつ、黒糖、ヨーグルト、バターミルクなど **酸性の材料と組み合わせる** と、中和されて苦みが出にくく、よくふくらみます。

## 6-3 凝固剤（ゼラチン・寒天・アガー・ペクチン）

| | ゼラチン | 寒天 | アガー | ペクチン |
|---|---|---|---|---|
| 原料 | **動物**（牛・豚）の皮や骨の **コラーゲン** | **海藻**（テングサ・オゴノリなど） | **海藻**（カラギーナン）、豆（ローカストビーンガム）など | **果物**（りんご・柑橘の皮など） |
| 主成分 | たんぱく質 | 食物繊維（多糖類） | 食物繊維（多糖類） | 食物繊維（多糖類） |
| 溶かす温度 | **約50〜60℃**（**沸騰させると固まる力が弱まる**） | **沸騰させて煮溶かす**（約90℃以上で1〜2分） | 約90℃以上 | ── |
| 固まる温度 | **冷蔵庫（約20℃以下、一般に10℃以下で数時間）** | **常温（約40℃前後）** | 常温（約30〜40℃） | 種類によって条件が違う（砂糖と酸、カルシウムなど） |
| 溶ける温度 | 約25℃前後（**口の中で溶ける**、夏は常温で溶けやすい） | 約80〜90℃以上（常温では溶けない） | 約60℃以上 | ── |
| 食感 | **ぷるぷる、なめらか、口どけが良い** | **しっかり、歯切れが良い** | ぷるぷる、**透明感** | とろりとした固まり |
| 主なお菓子 | ゼリー、ムース、ババロア、マシュマロ、パンナコッタ | 羊羹、ところてん、あんみつ、水羊羹 | 透明なゼリー | ジャム、パート・ド・フリュイ（果物のグミ） |

**ゼラチンの使い方**

- **板ゼラチン** ── たっぷりの **冷水** に浸してふやかし、水気を絞って使う。
- **粉ゼラチン** ── **冷水**（ゼラチンの約5〜6倍量）に振り入れてふやかす（水にゼラチンを入れる。逆にするとダマになる）。
- ふやかしたゼラチンを、温めた液体（約50〜60℃）に入れて溶かす。

> **注意（重要）**　**パイナップル・キウイフルーツ・パパイヤ・マンゴー・いちじく・メロンなどの生の果物** には、**たんぱく質を分解する酵素（プロテアーゼ）** が含まれ、たんぱく質であるゼラチンが分解されて **固まらなくなる** ことがあります。
> 対策：**果物を加熱する**（酵素の働きがなくなる）、**缶詰の果物** を使う、**寒天やアガー**（たんぱく質ではない）を使う。

**酸と凝固剤**　レモン汁などの **酸の強いものを加えて加熱すると、ゼラチンや寒天は固まりにくくなる** ことがあります。酸は火を止めて少し冷ましてから加えます。

## 6-4 チョコレート

**チョコレートの種類（主な成分のちがい）**

| 種類 | 主な原料 |
|---|---|
| **ダーク（スイート・ビター）** | カカオマス、カカオバター、砂糖 |
| **ミルク** | カカオマス、カカオバター、砂糖、**乳製品** |
| **ホワイト** | **カカオバター**、砂糖、乳製品（カカオマスを含まない） |
| **クーベルチュール** | **カカオバターの割合が多い** 製菓用チョコレート。流れが良く、コーティングに向く |
| パータ・グラッセ（コーティング用） | カカオバターの一部をほかの油脂に置き換えたもの。**テンパリング不要** |

**テンパリング（温度調整）**

- チョコレートを一度溶かし、冷まし、少し温め直して、**カカオバターの結晶の形をそろえる** 作業です。
- 成功すると、**つやがあり、パリッと割れ、口どけが良く、型から外しやすい** チョコレートになります。

| 種類 | 溶かす | 下げる | 上げる（作業温度） |
|---|---|---|---|
| ダーク（一例） | 約50〜55℃ | 約27〜28℃ | 約31〜32℃ |
| ミルク（一例） | 約45〜50℃ | 約26〜27℃ | 約29〜30℃ |
| ホワイト（一例） | 約40〜45℃ | 約25〜26℃ | 約28〜29℃ |

※温度はメーカーや製品で違います。**パッケージに書かれた温度を優先** してください。

**ブルーム現象**　チョコレートの表面が白くなる現象です。

| 種類 | 原因 |
|---|---|
| **ファットブルーム** | テンパリングの失敗や温度変化で、**カカオバター（脂肪）が表面に浮き出て** 固まる |
| **シュガーブルーム** | 冷蔵庫から出したときなどの **結露（湿気）** で砂糖が溶け、乾いて表面に結晶が出る |

**チョコレートを扱うときの注意**

- **水が少しでも入ると、ボソボソに固まる**（「シーズ」する）。湯せんのときに湯気や水が入らないよう注意します。
- 高温にしすぎると焦げたり、分離したりします（直火にかけない）。
- 保存は **約15〜18℃前後** の涼しく乾燥した場所で。

**ガナッシュ**　チョコレートと生クリームを混ぜて **乳化** させたもの。比率で固さが変わります（チョコレートが多いほど固い）。

## 6-5 塩

| 働き | 説明 |
|---|---|
| **甘みを引き立てる** | 少量の塩は、甘みを強く感じさせる（**味の対比効果**） |
| **味を引き締める** | 全体の味にメリハリが出る |
| 風味を良くする | キャラメル（塩キャラメル）、パイ生地、タルト生地、クッキー |
| グルテンを引き締める | 生地にコシが出る（パイ生地など） |

- 使う量はごく少量（ひとつまみ程度）です。
- **有塩バターを使うときは、塩を減らす** か入れない。

## 6-6 水と温度

お菓子作りでは、**水や材料の温度** が仕上がりを大きく左右します。

| 場面 | 水・材料の温度 | 理由 |
|---|---|---|
| **タルト・パイ生地** | **冷水**、冷たいバター | バターを溶かさず、**サクサク・層** を作る。グルテンをできにくくする |
| **ゼラチンをふやかす** | **冷水** | ぬるま湯だと表面だけ溶けて、ダマになる |
| **シュー生地** | 水（牛乳）とバターを **しっかり沸騰** させてから粉を入れる | でんぷんを **糊化** させ、ふくらむ生地を作る |
| **全卵の泡立て** | 湯せんで約35〜40℃ | 泡立ちやすくなる |
| **生クリームの泡立て** | 約10℃以下（氷水で冷やす） | 分離を防ぐ |
| **バター生地（パウンド）** | 材料をすべて常温（約20℃前後）に | 分離を防ぎ、乳化させる |
| **ドライイースト** | 約40℃前後のぬるま湯 | 予備発酵 |
| **チョコレートを溶かす湯せん** | 約50〜60℃の湯 | 焦がさない・水を入れない |

**湯せん**　ボウルを、湯をはった鍋やボウルに重ねて、**間接的に温める方法** です。直火より温度がゆっくり上がるので、焦げたり固まったりしにくくなります。

> **ここを覚える**
> - BP＝重曹＋酸性剤＋分散剤（均一に縦にふくらむ）／重曹＝横に広がる、入れすぎると苦く黄色に
> - シュー・パイ＝水蒸気でふくらむ
> - ゼラチン＝動物・約50〜60℃で溶かす・沸騰させない・冷蔵で固まる・口で溶ける
> - 寒天＝海藻・沸騰させて溶かす・常温（約40℃）で固まる
> - 生のパイナップル・キウイ・パパイヤなどはゼラチンを固まらなくする（プロテアーゼ）
> - テンパリング（ダーク例：50〜55℃→27〜28℃→31〜32℃）。失敗するとファットブルーム
> - チョコに水は厳禁。塩は甘みを引き立てる（対比効果）
> - タルト・パイ＝冷水、ゼラチン＝冷水でふやかす、シュー＝沸騰

# 第7章 道具の種類と選び方

## 7-1 はかる道具

| 道具 | 選び方・使い方のポイント |
|---|---|
| **デジタルスケール** | **最小1g単位、できれば0.1g単位** で量れるもの（ベーキングパウダーやゼラチンなど少量の材料を正確に量るため）。**最大2kg程度** まで量れると便利。容器をのせて表示を0にする **風袋（ふうたい）引き機能** があるものが使いやすい。平らな場所に置いて使う |
| **計量カップ** | **1カップ＝200ml**（日本の場合）。目盛りが見やすく、耐熱性のあるもの（耐熱ガラス・プラスチック）。**平らな場所に置いて、目線を目盛りの高さに合わせて真横から読む** |
| **計量スプーン** | **大さじ＝15ml、小さじ＝5ml**。小さじ1/2（2.5ml）もあると便利。粉は山盛りにすくって、**へらなどで平らにすりきる** |
| **温度計** | 生地・シロップ・チョコレートの温度を測る。**デジタル温度計**（すぐ測れる）、高温（200℃程度）まで測れる **棒状温度計**（シロップ用）、表面を測れる **非接触型（赤外線）温度計** など |
| **タイマー** | 焼き時間・冷やし時間・泡立て時間を正確に |
| **オーブン用温度計** | オーブンの庫内の実際の温度を確かめる（設定温度と差があることが多い） |

> **ポイント（重さで量る理由）**　お菓子作りでは、カップやスプーンより **重さ（g）で量るほうが正確** です。小麦粉は、ふるったものと詰めたものでは、同じ1カップでも重さが大きく違うからです。
> **参考（目安）**：小麦粉 大さじ1 ≒ 9g、砂糖（上白糖）大さじ1 ≒ 9g、グラニュー糖 大さじ1 ≒ 12g、水 大さじ1 ＝ 15g、バター 大さじ1 ≒ 12g、塩 小さじ1 ≒ 5〜6g（目安であり、量り方で変わる）

## 7-2 混ぜる道具

| 道具 | 選び方・使い方のポイント |
|---|---|
| **ボウル** | **ステンレス製** は熱が伝わりやすく、**冷やしたり温めたり（湯せん）しやすい**。軽くて割れない。**耐熱ガラス製** は電子レンジが使え、中が見える。大・中・小とそろえると便利。**底が丸いもの** は泡立て器が隅まで届く |
| **泡立て器（ホイッパー）** | **ワイヤーの本数が多い** ものは、空気を含ませやすく泡立てやすい。**ボウルの直径と同じくらいの長さ** のものを選ぶ。持ち手がしっかりしているもの |
| **ハンドミキサー** | メレンゲ・全卵の泡立て、バターのクリーミングが楽で、時間も短い。**速度の切り替え** ができるもの。最後は低速できめを整える |
| **スタンドミキサー** | 大量の生地や長時間の泡立てに。両手が空く。アタッチメント（ホイッパー・ビーター・フック）を使い分ける |
| **ゴムベラ（シリコンベラ）** | 生地を **さっくり混ぜる**、**ボウルの生地を残さず集める**。**耐熱性のシリコン製** は加熱調理（カスタードなど）にも使える。**ヘラと柄が一体型** のものは、すき間に汚れがたまらず衛生的。適度なしなりがあるもの |
| **木べら** | **加熱しながら混ぜる**（カスタード、シュー生地、ジャム）。こしがあり、力を入れやすい。熱が伝わりにくい。においや色が移りやすく、よく乾かす必要がある |
| **カード（スケッパー・ドレッジ）** | 生地を切る・集める・平らにならす。タルト生地・パイ生地を作るとき、バターと粉を切り混ぜる |
| **粉ふるい・こし器（シノワ）** | 粉をふるう。液体をこしてなめらかにする（プリン液、カスタード、アングレーズソース） |

**泡立て器とゴムベラの使い分け**

| 作業 | 道具 |
|---|---|
| 卵・生クリームを泡立てる | 泡立て器・ハンドミキサー |
| バターと砂糖をすり混ぜる | 泡立て器・ハンドミキサー |
| **泡を消さないように粉を混ぜる** | **ゴムベラ**（底からすくい上げるように、さっくり） |
| メレンゲを生地に混ぜる | 最初の1/3は泡立て器でなじませ、残りはゴムベラで泡を消さないように |
| ボウルの生地を残さず集める | ゴムベラ |
| 加熱しながら混ぜる | 木べら・耐熱ゴムベラ |

# 第8章 オーブンを使ったお菓子作り

## 8-1 オーブンの基本

| ポイント | 説明 |
|---|---|
| **予熱は必ず行う** | 予熱が足りないと、ふくらまない・焼きムラ・生焼け・焼き色がつかないなどの原因になる。予熱完了の合図が出ても、庫内全体が温まるまで少し待つとより安定する |
| **段取り** | 予熱中に生地を作り終えるように段取りする。泡立てた生地は時間がたつと泡が消えるので、すぐに焼く |
| **オーブンにはくせがある** | 同じ温度設定でも、機種によって焼け方が違う。レシピの温度と時間は目安と考え、**焼き色や竹串で確認** する |
| **扉を何度も開けない** | 庫内の温度が下がる。特に **スポンジやシュー生地は、ふくらんでいる途中で開けるとしぼむ** ことがある |
| **焼きムラ対策** | 焼き色に差が出てきたら、**焼き時間の後半に、手早く天板の前後（左右）を入れ替える** |
| **焼き色がつきすぎたら** | 表面に **アルミホイルをかぶせる** |

## 8-2 熱の伝わり方

オーブンの中では、3つの方法で熱が伝わります。

| 熱の伝わり方 | 説明 | オーブンでの例 |
|---|---|---|
| **対流** | 温められた空気が動いて熱を運ぶ | ファン（コンベクション）で熱風を循環させる |
| **放射（輻射）** | ヒーターや庫内の壁から出る熱が直接届く | 上火・下火のヒーター |
| **伝導** | 触れているものから熱が伝わる | 天板や型から生地へ |

## 8-3 ガスオーブンと電気オーブン

| | ガスオーブン | 電気オーブン |
|---|---|---|
| しくみ | ガスの炎で熱した空気を、**ファンで庫内に循環** させる（コンベクション） | **電熱ヒーター** で加熱する（ファン付きのものもある） |
| **火力** | **強い**。立ち上がり（予熱）が **速い** | ガスより **弱め**。**予熱に時間がかかる** |
| **庫内の状態** | ガスが燃えるときに水蒸気は出るが、熱風が循環するため **乾燥しやすい**（焼き菓子がカリッと焼ける） | **水分が残りやすい**（しっとり焼けやすい） |
| 扉を開けたとき | 温度の回復が早い | **温度の低下が大きく、回復に時間がかかる** |
| 注意点 | 焼き色がつきやすく、**表面が先に焼けやすい**。ファンの風で焼きムラ・生地が乾燥することも | ヒーターに近い部分が焦げやすい。火力が足りずふくらみにくいことも |
| 温度設定の目安 | レシピどおり、または **少し低め** | ガスオーブン基準のレシピより **約10〜20℃高め** にすることが多い |
| 主な設置 | ビルトイン、業務用 | 家庭用（オーブンレンジ）に多い |

※温度差は機種によって違います。自分のオーブンで何度か試して、くせをつかみましょう。

**オーブンレンジ（電子レンジとオーブンの一体型）の注意**　庫内が小さいものは、ヒーターと生地の距離が近く、**表面が焦げやすい** ことがあります。

## 8-4 天板の位置と焼き方

| 位置 | 特徴 |
|---|---|
| **上段** | 上火が強く当たり、表面に焼き色がつきやすい |
| **中段** | 最も標準的。迷ったら中段 |
| **下段** | 底がしっかり焼ける（タルトの底、パイ） |

- 2段で焼くときは、途中で上下を入れ替えます。2段焼きは1段より時間が長くかかることが多いです。
- **天板は予熱のときに一緒に入れておく** と、生地を入れたときに下からも熱が伝わります（レシピによる。クッキーなどは天板を入れないことも）。
- 底が焦げやすいときは、**天板を2枚重ねる** と、下からの熱がやわらぎます。

## 8-5 焼き温度とお菓子の関係（目安）

| 温度帯（目安） | お菓子の例 | 目的 |
|---|---|---|
| 低温（約100〜130℃） | メレンゲ菓子 | 色をつけず、じっくり乾燥させる |
| 中低温（約150〜170℃） | クッキー、チーズケーキ（湯せん）、シフォン | じっくり火を通す |
| 中温（約170〜180℃） | スポンジ、パウンドケーキ、マフィン | 一般的な焼き菓子 |
| 高温（約190〜220℃） | シュー（最初）、パイ | 一気にふくらませる・層を立たせる |

## 8-6 蒸し焼き（湯せん焼き）

**蒸し焼き（湯せん焼き）とは**　天板やバットに **湯を張り**、その中に型を置いて焼く方法です。

| 目的・効果 | 説明 |
|---|---|
| **温度がゆっくり上がる** | 湯があるため、型のまわりが約100℃以上に上がりにくく、**低温でじっくり、均一に** 火が通る |
| **なめらかに仕上がる** | 卵の **急な凝固を防ぎ**、口当たりがなめらかでしっとりする |
| **「す」が立つのを防ぐ** | 「す」＝加熱しすぎで、生地の中の水分が沸騰（気化）してできる **小さな穴**。プリンや茶碗蒸しで起こりやすい |
| **乾燥・ひび割れを防ぐ** | 蒸気で表面が乾きにくく、ひび割れしにくい |
| 焦げを防ぐ | 底や側面が焦げにくい |

**蒸し焼きにする主なお菓子**

- **プリン（カスタードプディング）**
- **ベイクドチーズケーキ**
- **スフレチーズケーキ**
- ガトーショコラ（レシピによる）
- クレーム・ブリュレ、ポ・ド・クレーム

**蒸し焼きのポイント**

1. **底が抜ける型** を使うときは、湯が入らないように型の外側を **アルミホイルで二重に包む**。
2. 湯は **お湯（約50〜60℃以上、レシピによっては熱湯）** を使う。水だと温度が上がるまでに時間がかかる。
3. 湯の量は、**型の高さの1/3〜1/2程度** が目安。
4. 焼いている途中で湯がなくなったら足す。
5. 取り出すときは、**湯でやけどしない** よう注意する。

**蒸し焼きと「蒸す」のちがい**

| | 蒸し焼き（湯せん焼き） | 蒸す（蒸し器） |
|---|---|---|
| 器具 | オーブン | 蒸し器 |
| 加熱 | オーブンの熱＋湯 | **水蒸気** の熱 |
| 焼き色 | 表面に焼き色がつく | 焼き色はつかない |
| 例 | チーズケーキ、オーブンで焼くプリン | 蒸しパン、蒸しまんじゅう、蒸しプリン |

## 8-7 焼き上がりの確認

| 方法 | 対象 | 焼き上がりの目安 |
|---|---|---|
| **竹串を刺す** | スポンジ、パウンドケーキ、マフィン | **生地がついてこなければ** 焼き上がり |
| **指で軽く押す** | スポンジ | **弾力があって跳ね返れば** 焼き上がり |
| 焼き色 | 焼き菓子全般 | 全体にきれいな焼き色がついている |
| **揺らす** | プリン、チーズケーキ | 中心が少し **ふるふる** する程度（冷めると固まる） |
| 割れ目の色 | パウンドケーキ | 割れ目にも焼き色がついている |
| 側面 | スポンジ | 型から少し離れている |

## 8-8 焼き上がった後

| お菓子 | 焼き上がった後の扱い |
|---|---|
| **スポンジ** | 焼けたら **型ごと10〜20cmの高さから台に落として、ショックを与える**（中の熱い空気を抜き、焼き縮みを防ぐ）。型から出して冷ます |
| **シフォン** | 型ごと **逆さにして** 完全に冷ます（重みでつぶれないように） |
| パウンドケーキ | 型から出し、熱いうちに洋酒シロップを塗ることも。冷めたらラップで包むとしっとり |
| チーズケーキ・プリン | 粗熱を取ってから冷蔵庫で冷やす（型のまま） |
| クッキー | 天板の上で少し冷ましてから網へ（熱いうちは柔らかく割れやすい） |

> **ここを覚える**
> - 予熱は必ず。扉はむやみに開けない（スポンジ・シューはしぼむ）。焼きムラは後半に前後を入れ替える
> - ガス＝火力が強い・予熱が速い・乾燥しやすい／電気＝火力弱め・予熱に時間・水分が残りやすい、約10〜20℃高めに設定することが多い
> - 蒸し焼き＝湯を張って低温でじっくり → なめらか、「す」防止、乾燥・ひび割れ防止（プリン、チーズケーキ）
> - 底抜け型はアルミホイルで包む、湯は型の1/3〜1/2
> - 竹串・指で押す・揺らすで確認／スポンジは落としてショック、シフォンは逆さに

# 第9章 生地とクリームの基本

## 9-1 スポンジ生地（ジェノワーズ）

| 方法 | やり方 | 仕上がり |
|---|---|---|
| **共立て（ともだて）** | **全卵** をそのまま湯せんで温めながら泡立てる | **きめ細かく、しっとり**。ショートケーキの土台（ジェノワーズ） |
| **別立て（べつだて）** | **卵黄と卵白を分けて** 泡立て、後で合わせる | **軽くふんわり**、弾力がある。泡立てやすい。ロールケーキ、ビスキュイ |

**共立てスポンジの手順（一例：直径18cm丸型）**

| 材料 | 分量（一例） |
|---|---|
| 卵（全卵） | 3個（約150g） |
| グラニュー糖 | 90g |
| 薄力粉 | 90g |
| 無塩バター | 20g |
| 牛乳 | 20g |

1. 型に紙を敷き、オーブンを170〜180℃に予熱。薄力粉をふるう。バターと牛乳を合わせて湯せんで温めておく。
2. ボウルに卵をほぐし、グラニュー糖を加え、**湯せんにかけながら約35〜40℃まで温めて** 泡立てる。
3. 湯せんから外し、**リボン状に落ちて跡が残る** まで泡立てる。最後は低速できめを整える。
4. 薄力粉を加え、ゴムベラで **底からすくい上げるように、さっくり** 混ぜる。
5. 温めたバターと牛乳に生地を少量加えてなじませてから、全体に戻して混ぜる（油分で泡が消えるのを防ぐ）。
6. 型に流し、170〜180℃で約25〜30分焼く。
7. 焼き上がったら型ごと落としてショックを与え、型から出して冷ます。

## 9-2 バター生地（パウンドケーキなど）

**パウンドケーキの由来**　バター・砂糖・卵・小麦粉を **1ポンドずつ** 使ったことが名前の由来とされます。フランスでは「4分の4」という意味の **カトルカール（quatre-quarts）** と呼ばれ、4つの材料を同量で作ります。

| 方法 | やり方 | 特徴 |
|---|---|---|
| **シュガーバッター法** | **バターと砂糖** をすり混ぜて空気を含ませ、卵、粉の順に加える | 最も一般的。**ふんわり** |
| **フラワーバッター法** | **バターと粉** を先に混ぜ、卵と砂糖を泡立てたものと合わせる | 分離しにくい。**きめが細かく、しっとり** |
| オールインワン法 | すべての材料を一度に混ぜる | 手軽。ベーキングパウダーを使うことが多い |
| 別立て法 | 卵白をメレンゲにして加える | 軽い |

**分離に注意**

- バターに **卵を一度に入れたり、卵が冷たかったりする** と、水分と油分が分かれて **分離** します（もろもろとした状態）。
- 分離すると、ふくらみが悪く、きめが粗く、重い仕上がりになります。
- **対策**：卵を **常温に戻し、少しずつ** 加える。分離しかけたら、**ふるった粉を少量加える** とまとまりやすくなる。少し温めるのも効果的。

## 9-3 クッキー生地

| 種類 | 作り方 | 特徴 |
|---|---|---|
| 型抜きクッキー | 生地をのばして型で抜く | 冷やして休ませると縮みにくい |
| アイスボックスクッキー | 生地を棒状にして冷やし固め、切って焼く | 模様を作りやすい |
| 絞り出しクッキー | 柔らかい生地を口金で絞る | |
| ドロップクッキー | スプーンで落として焼く | |

- **粉糖** を使うと **サクサク・ほろほろ**、**グラニュー糖** を使うと **ザクザク・カリッ** とした食感になりやすいといわれます。

## 9-4 タルト生地・パイ生地

**タルト生地**

| 生地 | 特徴 | 用途 |
|---|---|---|
| **パート・シュクレ** | 「砂糖の生地」。砂糖が多く、**甘くサクサク** | 甘いタルト |
| **パート・サブレ** | さらに砂糖・バターが多く、**ほろほろ** | サブレ、タルト |
| **パート・ブリゼ** | 「砕けた生地」。砂糖が少ない（または入れない） | **キッシュ** などの塩味のタルト |

**タルト生地の作り方の2つの方法**

| 方法 | やり方 |
|---|---|
| **クレメ（クリーム状にする）** | 常温のバターに砂糖・卵・粉を順に加える |
| **サブラージュ（砂状にする）** | 冷たいバターと粉を指先ですり合わせて **砂状** にし、水分を加える。グルテンができにくく、サクサクに |

**パイ生地**

| 生地 | 作り方 | 特徴 |
|---|---|---|
| **折り込みパイ生地（フイユタージュ）** | 小麦粉と水の生地（**デトランプ**）で **バターを包み**、のばして **折りたたむ（3つ折り・4つ折り）作業をくり返し**、生地とバターの **層を何百層** にも重ねる | 焼くと、バターの水分が **水蒸気** になり、溶けたバターが層を分けて、**層が浮き上がる**。サクサクで、層がくっきり。ミルフィーユ、パイ |
| **練り込みパイ生地（速成）** | 粉と冷たいバターをざっくり混ぜ、水を加えてまとめ、のばして折る | 手軽。層は粗い。アップルパイなど |

**タルト・パイ生地のポイント**

- **冷たい材料** を使い、バターを溶かさない。
- 作業の合間に **冷蔵庫で休ませる**（グルテンを落ち着かせ、焼き縮みを防ぐ。バターを冷やし固める）。
- **ピケ**（フォークやピケローラーで穴をあける）で、焼いたときに底がふくれるのを防ぐ（タルト生地など）。
- **空焼き（から焼き）**：中身を入れる前に、生地だけを焼くこと。**重石（タルトストーン）** をのせて、生地が浮くのを防ぐ。

## 9-5 シュー生地（パータ・シュー）

**作り方の流れ**

1. 水（または牛乳）・バター・塩・（砂糖）を鍋に入れ、**しっかり沸騰** させる。
2. 火を止めて、ふるった粉を **一気に** 加えて混ぜる。
3. 再び火にかけ、**木べらで混ぜながら加熱** する（鍋底に薄い膜ができるくらいまで）。→ でんぷんが **糊化** し、余分な水分がとぶ。
4. ボウルに移し、溶き卵を **少しずつ** 加えて混ぜる。
5. 木べらで持ち上げたとき、**生地がゆっくり落ちて、へらに残った生地が逆三角形（三角形）に垂れ下がる** 固さに調整する。
6. 絞り出して、霧吹きをして焼く。

**シューがふくらむしくみ**

- 焼くと、生地の中の水分が **水蒸気** になってふくらみます。
- 糊化したでんぷんと卵のたんぱく質が **風船のゴムのように伸びて**、中が **空洞** になります。
- 卵のたんぱく質が熱で固まり、形が保たれます。

**シュー生地の失敗**

| 失敗 | 原因 |
|---|---|
| ふくらまない | 沸騰が不十分（糊化が足りない）、加熱不足、生地が硬すぎる・柔らかすぎる、オーブンの温度が低い |
| 焼いた後にしぼむ | **焼き不足**、**焼いている途中で扉を開けた** |
| 形が平たい | 生地が柔らかすぎる（卵が多い） |

## 9-6 メレンゲ

| 種類 | 作り方 | 特徴・用途 |
|---|---|---|
| **フレンチメレンゲ** | 卵白に **砂糖を加えながら** 泡立てる（加熱しない） | 最も基本的。焼き菓子、スポンジ（別立て）、シフォン、ダックワーズ |
| **イタリアンメレンゲ** | 卵白を泡立てながら、**約117〜121℃に煮詰めた熱いシロップ** を細く加えて泡立てる | **安定性が高く、泡が消えにくい**。熱いシロップで卵白に熱が入る。ムース、バタークリーム、マカロン、タルトの飾り |
| **スイスメレンゲ** | 卵白と砂糖を **湯せんで温めながら（約50〜60℃）** 泡立てる | **硬めで、つやがある**。焼き菓子、飾り |

## 9-7 基本のクリーム

| クリーム | フランス語名 | 主な材料 | 特徴・用途 |
|---|---|---|---|
| **カスタードクリーム** | **クレーム・パティシエール** | 牛乳・卵黄・砂糖・粉（薄力粉やコーンスターチ）・バニラ | 加熱してとろみをつける。**しっかり沸騰させて粉に火を通す**（粉っぽさとコシ）。シュークリーム、タルト、ミルフィーユ |
| **ホイップクリーム** | **クレーム・シャンティ** | 生クリーム・砂糖 | ショートケーキ、デコレーション |
| **バタークリーム** | クレーム・オ・ブール | バター・砂糖（＋メレンゲ、卵黄、シロップなど） | 日持ちし、形が崩れにくい。デコレーションケーキ、マカロン |
| **アーモンドクリーム** | **クレーム・ダマンド** | バター・砂糖・卵・**アーモンドプードル** を同量 | **焼いて使う**。タルトの中身（フルーツタルト、ガレット・デ・ロワ） |
| **アングレーズソース** | クレーム・アングレーズ | 牛乳・卵黄・砂糖 | 粉を入れず、**約80〜85℃** でとろみをつける（**沸騰させない**：卵が固まる）。ソース、ババロアのベース |
| **ガナッシュ** | ── | チョコレート・生クリーム | トリュフ、ケーキの中身・コーティング |
| **ディプロマットクリーム** | ── | カスタード＋ホイップクリーム | 軽いカスタード |

**カスタードとアングレーズのちがい**

| | カスタードクリーム | アングレーズソース |
|---|---|---|
| 粉 | **入れる** | 入れない |
| 加熱 | **沸騰させる**（粉に火を通す） | **沸騰させない**（約80〜85℃） |
| 仕上がり | 固めのクリーム | とろりとしたソース |

## 9-8 そのほかの基本のお菓子

| お菓子 | ポイント |
|---|---|
| **シフォンケーキ** | 卵黄生地に植物油と水を加え、しっかりしたメレンゲを合わせる。**型に油を塗らない**、焼いたら **逆さにして冷ます** |
| **プリン** | 卵・牛乳・砂糖を合わせてこし、**蒸し焼き** に。カラメルを型の底に |
| **ベイクドチーズケーキ** | クリームチーズ・砂糖・卵・生クリームなど。蒸し焼きにすることも |
| **レアチーズケーキ** | 焼かずに **ゼラチン** で冷やし固める |
| **スフレチーズケーキ** | メレンゲを加え、**低温で蒸し焼き** に。ふわふわ |
| **マドレーヌ** | 溶かしバターの生地。貝殻形。生地を休ませると、中央がぷっくりふくらむ（「おへそ」） |
| **フィナンシェ** | **焦がしバター**・アーモンドプードル・**卵白** を使う。金塊の形 |
| **マカロン** | アーモンドプードル・粉糖・メレンゲ。生地の泡を適度につぶす「**マカロナージュ**」で、表面がなめらかに、裾に「**ピエ**（フリル状の足）」ができる |
| **ムース** | 泡立てた生クリームやメレンゲに、ゼラチンを加えて冷やし固める。軽い口どけ |
| **ババロア** | アングレーズソースに、ゼラチンと泡立てた生クリームを加えて冷やし固める |

> **ここを覚える**
> - 共立て＝全卵（きめ細かくしっとり）、別立て＝卵黄と卵白を分ける（軽い）
> - パウンド（カトルカール）＝4つの材料が同量。シュガーバッター法＝バター＋砂糖を先に
> - 分離したら粉を少量。卵は常温で少しずつ
> - パート・シュクレ＝甘いタルト、パート・ブリゼ＝キッシュ。サブラージュ＝冷たいバターと粉を砂状に
> - 折り込みパイ＝バターを包んで折る。水蒸気で層が浮く
> - シュー＝しっかり沸騰・糊化、逆三角形の固さ、途中で扉を開けない
> - イタリアンメレンゲ＝約117〜121℃のシロップ（安定）、スイス＝湯せん
> - カスタード＝粉を入れて沸騰、アングレーズ＝粉なし・沸騰させない（約80〜85℃）
> - クレーム・ダマンド＝焼いて使う

# 第10章 洋菓子の歴史と名前の由来

## 10-1 洋菓子の歴史（ヨーロッパ）

| 時代 | 出来事 |
|---|---|
| 古代 | 古代エジプトやギリシャ・ローマで、はちみつ・果物・木の実などを使った甘いお菓子が作られていた |
| 中世 | 十字軍などを通じて、中東から **砂糖** やスパイスがヨーロッパに伝わる。砂糖は高価で、薬や富の象徴だった。**修道院** でお菓子づくりが発達した（クッキーやワッフルの原型など） |
| 16世紀 | イタリアからフランスへ製菓技術が伝わったとされる（イタリアのメディチ家の **カトリーヌ・ド・メディシス** がフランス王家に嫁いだ（1533年）際に、菓子職人を連れてきた、という話がよく知られるが、**伝説的な面もある**）。新大陸から **カカオ** がヨーロッパに伝わる |
| 17〜18世紀 | 砂糖の生産が増え（植民地での生産）、お菓子が上流階級に広まる。チョコレートは飲み物として流行 |
| 19世紀 | フランスの菓子職人 **アントナン・カレーム** が、豪華な飾り菓子（ピエス・モンテ）などで活躍し、近代製菓の基礎を築いたとされる。てんさい糖の生産、ベーキングパウダーの普及、チョコレートの固形化など、技術が発達し、お菓子が庶民にも広まる |

## 10-2 日本の洋菓子の歴史

| 時代 | 出来事 |
|---|---|
| 16世紀（室町〜安土桃山時代） | ポルトガルやスペインとの「南蛮貿易」で、**南蛮菓子** が伝わる。**カステラ、ボーロ、金平糖（コンペイトウ）、有平糖（あるへいとう）** など。「金平糖」はポルトガル語の **confeito（コンフェイト）** が語源とされる |

| 現在 | フランス菓子をはじめ世界中のお菓子が楽しまれる。日本のパティシエが国際的に活躍 |

# 第11章 よくある失敗と原因

| お菓子 | 失敗 | 主な原因 |
|---|---|---|
| スポンジ | **ふくらまない** | 卵の泡立て不足、粉を混ぜすぎて泡が消えた、バターを加えるときに泡が消えた、予熱不足 |
| スポンジ | **焼いた後にしぼむ（焼き縮み）** | 焼き不足、扉の開けすぎ、焼き上がり後にショックを与えていない |
| スポンジ | きめが粗い・大きな穴 | 泡立てた後にきめを整えていない、混ぜ不足 |
| スポンジ | 底に硬い層ができる | 粉やバターが沈んで混ざっていない、泡が消えた |
| バター生地 | **分離した** | 卵が冷たい、卵を一度に加えた |
| バター生地 | 硬い・ふくらまない | 粉を混ぜすぎてグルテンができた、クリーミング不足 |
| クッキー | **広がる・だれる** | バターが溶けた、生地を冷やしていない、砂糖が多い、天板が熱い |
| クッキー | 硬い | 混ぜすぎ（グルテン）、焼きすぎ |
| タルト | **焼き縮む** | 生地を休ませていない、こねすぎ、生地を引っぱって敷いた |
| タルト | 底がふくれる | ピケしていない、重石をのせていない |
| パイ | 層ができない | バターが溶けた（温度が高い）、生地を休ませていない |
| シュー | **ふくらまない・しぼむ** | 糊化不足、生地の固さ、焼き不足、途中で扉を開けた |
| プリン | **「す」が立つ** | 温度が高すぎる、加熱しすぎ（蒸し焼きで防ぐ） |
| ゼリー | **固まらない** | ゼラチンを沸騰させた、量が少ない、生のパイナップル・キウイなどを入れた、酸を加えて加熱した |
| 寒天 | 固まらない・ムラがある | 十分に沸騰させていない |
| チョコレート | **白くなる（ブルーム）** | テンパリングの失敗、温度変化、湿気 |
| チョコレート | **ボソボソに固まる** | **水が入った**、温度が高すぎた |
| 生クリーム | **分離する（ボソボソ）** | 泡立てすぎ、温度が高い |
| メレンゲ | 泡立たない | ボウルに油分、卵黄が混ざった |
| カスタード | 粉っぽい | 加熱不足（沸騰させていない） |
| カスタード・アングレーズ | ダマになる・ボソボソ | 加熱しすぎで卵が固まった、混ぜ不足 |
| カラメル | 結晶化して白く固まる | かき混ぜすぎ、鍋肌の砂糖の結晶 |

> **ポイント**　失敗の原因は、**「材料（量・温度・鮮度）」「混ぜ方（足りない・混ぜすぎ）」「加熱（温度・時間・予熱）」** の3つの面から考えると見つけやすくなります。

# 第12章 衛生・保存・アレルギー表示

## 12-1 衛生管理

**食中毒予防の三原則**　**つけない（清潔）・増やさない（温度管理・迅速）・やっつける（加熱・殺菌）**

| ポイント | 内容 |
|---|---|
| 手洗い | 作業前、トイレの後、**卵や生肉を触った後** は、石けんで手を洗う |
| 身じたく | 爪を短く、髪をまとめる、清潔な服装、アクセサリーを外す |
| 体調 | 下痢や発熱があるときは調理しない。**手に傷があるときは手袋** を使う |
| 卵 | 新鮮なものを使い、冷蔵保存。**ひび割れた卵は加熱用** に |

| 原因 | 特徴 | 予防 |
|---|---|---|
| **サルモネラ菌** | **卵**・鶏肉などが原因になりやすい | 新鮮な卵、冷蔵保存、十分な加熱、ひび割れた卵は生で使わない |
