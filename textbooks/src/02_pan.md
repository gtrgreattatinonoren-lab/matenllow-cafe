# 第1章 パンの歴史

## 1-1 世界のパンの歴史

| 時代・地域 | 出来事 |
|---|---|
| 古代メソポタミア | 小麦や大麦の粉を水でこねて焼いた、平たい **無発酵パン** が作られていたとされる |
| 古代エジプト | こねた生地を置いておいたら、空気中の酵母などで自然に発酵してふくらんだことから、**発酵パン** が生まれたといわれる。壁画にもパン作りの様子が描かれている |
| 古代ギリシャ | パン作りの技術が発達し、さまざまな種類のパンが作られた |
| 古代ローマ | 大きな石臼による製粉や、公共のパン焼き窯が発達。**パン職人が専門の職業** となり、組合も作られた。ポンペイの遺跡からはパン屋の窯や、炭化したパンが見つかっている |
| 中世ヨーロッパ | パン職人の **ギルド（同業組合）** ができ、品質や価格が管理された。地域ごとに特色あるパンが発展。白い小麦のパンは上流階級、ライ麦などの黒いパンは庶民の食べ物とされることが多かった |
| 19世紀 | **ルイ・パスツール** が、発酵は微生物（酵母）の働きによることを明らかにした。酵母を純粋に培養する技術が進み、**工業的なイーストの生産** が始まった。ローラー製粉機の普及で白い小麦粉が広まった |
| 20世紀 | パン製造の機械化・大量生産。ドライイースト・インスタントドライイーストの開発 |

## 1-2 日本のパンの歴史

| 年代 | 出来事 |
|---|---|
| **1543年ごろ** | ポルトガル人が種子島に来航。キリスト教の宣教師とともにパンが伝わる。**「パン」はポルトガル語の pão（パン）** が語源 |
| 江戸時代 | 鎖国とキリスト教の禁止で、パンはほとんど広まらなかった。長崎の出島のオランダ人などは食べていた |
| **1842年** | 伊豆韮山（にらやま）の代官 **江川太郎左衛門英龍（えがわたろうざえもんひでたつ）** が、兵糧（軍隊の携帯食）としてパン（乾パンのようなもの）を自宅で焼いた。「**パン祖**」と呼ばれる |
| 幕末〜明治初期 | 横浜などの外国人居留地に、外国人向けのパン屋ができる |
| **1869年** | 木村安兵衛・英三郎親子が東京で「**文英堂**」（のちの **木村屋**、現在の木村屋總本店）を開業 |
| **1874年** | 木村屋が、日本酒の酒種（さかだね）で発酵させた生地にあんこを包んだ **あんパン** を発売 |
| **1875年** | 木村屋が、明治天皇に **桜の花の塩漬けをのせたあんパン** を献上したと伝えられる（4月4日） |
| **1904年** | 新宿中村屋がクリームパンを発売したとされる |
| 大正時代 | 第一次世界大戦のドイツ人捕虜などから、ドイツのパン作りの技術が伝わったともいわれる。**コッペパン** が作られ始めた（1919年、丸十パン店の田辺玄平が考案したという説がよく知られるが、諸説ある） |
| 昭和初期 | **カレーパン** が生まれたとされる（1927年に東京の名花堂（現・カトレア）が「洋食パン」として売り出したという説が知られるが、諸説ある） |
| 戦後 | アメリカからの小麦の援助などを背景に、**学校給食** でパンが広まり、パン食が家庭に定着した |
| 1960年代以降 | 大手製パン会社の成長、食パンの普及。フランスパンやデニッシュなど、本格的な外国のパンが広まる |
| 現在 | ベーカリーの多様化。高級食パンブーム、国産小麦や自家製酵母へのこだわり |

**パンにまつわる記念日**

| 記念日 | 由来 |
|---|---|
| **4月12日　パンの記念日** | 1842年4月12日に江川太郎左衛門がパンを焼いたことにちなみ、パン食普及協議会が1983年に制定 |
| **毎月12日　パンの日** | 上と同じ由来で、パン食普及協議会が定めた |
| **4月4日　あんパンの日** | 1875年4月4日に、木村屋があんパンを明治天皇に献上したことにちなむ |

> **ここを覚える**
> - パスツール＝発酵は酵母の働きと明らかにした（19世紀）
> - パンの語源＝ポルトガル語の pão（1543年ごろ伝来）
> - パン祖＝江川太郎左衛門（1842年）→ 4月12日はパンの記念日、毎月12日はパンの日
> - あんパン＝木村屋（1874年）、酒種を使用 → 4月4日はあんパンの日

# 第2章 小麦と小麦粉

## 2-1 小麦の粒の構造

小麦の粒は、大きく3つの部分からできています。

| 部分 | 割合（目安） | 特徴 |
|---|---|---|
| **胚乳（はいにゅう）** | 約83〜85％ | 粒の中心。**でんぷんとたんぱく質** が多い。**小麦粉になるのは主にこの部分** |
| **外皮（ふすま）** | 約13〜15％ | 外側の皮。食物繊維やミネラルが多い |
| **胚芽（はいが）** | 約2〜3％ | 芽になる部分。脂質・ビタミンが多い |

- 小麦粉は、粒を砕いて、ふすまと胚芽を取り除き、胚乳を細かい粉にしたものです。
- 粒を丸ごと挽いたものが **全粒粉（ぜんりゅうふん）** です。

## 2-2 小麦粉の種類（たんぱく質の量による分類）

| 種類 | たんぱく質の量（目安） | 粒の硬さ | 主な用途 |
|---|---|---|---|
| **強力粉** | 約11.5〜13.5％ | **硬質小麦** | 食パン、菓子パン、ロールパン |
| **準強力粉** | 約10.5〜12.5％ | 硬質小麦など | **フランスパン**（バゲット）、ハード系のパン、中華麺 |
| **中力粉** | 約8〜10.5％ | 中間質小麦 | うどん、一部の和菓子・パン |
| **薄力粉** | 約6.5〜9％ | **軟質小麦** | お菓子、天ぷら |

※数値は一般的な目安で、メーカーや製品によって違います。

**見分け方**　強力粉は粒子が粗く、手で握っても固まりにくい（さらさらしている）。薄力粉は粒子が細かく、握ると固まりやすい。

## 2-3 小麦粉の等級と灰分

- **灰分（かいぶん）** とは、小麦粉を燃やしたときに残る **ミネラルの量** です。外皮に近い部分ほど灰分が多くなります。
- 灰分が少ないほど **色が白く**、多いほど **色がくすみ、風味が強く** なります。
- 日本では、灰分の量などで等級が分けられています。

| 等級 | 灰分（目安） | 特徴 |
|---|---|---|
| 特等粉・1等粉 | 約0.3〜0.4％ | 白く、上質。パン・お菓子用 |
| 2等粉 | 約0.5％ | |
| 3等粉 | 約1％ | |
| 末粉 | 約2〜3％ | 主に工業用・飼料用 |

※灰分の数値は目安です。

## 2-4 グルテンのしくみ

小麦粉に水を加えてこねると、小麦の2つのたんぱく質が結びついて **グルテン** ができます。

| たんぱく質 | 性質 | たとえ |
|---|---|---|
| **グルテニン** | **弾力**（引っぱると元に戻ろうとする力） | ゴム |
| **グリアジン** | **粘り・伸び**（よく伸びる力） | 水あめ |

- こねるほどグルテンは **網目状** に広がり、強い膜になります。
- この膜が、イーストの出す **炭酸ガスを風船のように閉じ込め**、パンがふくらみます。
- 焼くとグルテンが熱で固まり、パンの **骨組み** になります。
- たんぱく質が多い強力粉ほど、グルテンがたくさんできます。
- **小麦以外の穀物（米・とうもろこしなど）は、グルテンをほとんど作りません**。ライ麦や大麦はグルテンのもとになるたんぱく質を含みますが、しっかりした膜は作りにくいです。

**グルテンに影響するもの**

| 要因 | 影響 |
|---|---|
| **塩** | グルテンを **引き締めて強くする** |
| **砂糖** | 水を奪うため、多いとグルテンができにくい |
| **油脂** | グルテンの間に入り、**伸びを良くする**（多いとグルテンができにくい） |
| **こねる時間** | 長いほどグルテンが発達する（こねすぎると切れる） |
| **水の量・硬度** | 少ないと硬い生地、多いとベタつく生地。硬水はグルテンを引き締める |

## 2-5 小麦の産地と品種

### 輸入小麦（日本のパン用小麦の多くは輸入）

| 産地 | 銘柄（例） | 特徴 |
|---|---|---|
| カナダ | **1CW**（カナダ・ウェスタン・レッド・スプリング） | たんぱく質が多い硬質小麦。日本の **強力粉の代表的な原料** |
| アメリカ | **DNS**（ダーク・ノーザン・スプリング）、HRW（ハード・レッド・ウィンター）など | DNSは強力粉の原料 |
| オーストラリア | ASW（オーストラリア・スタンダード・ホワイト）など | うどん用（中力粉）に多い |
| フランス | フランス産小麦 | フランスパン用の粉の原料。フランスでは灰分で「タイプ55」「タイプ65」などと分類する |

### 国産小麦

日本の小麦は、もともと **うどん向きの中力粉用** が多かったのですが、近年は **パン用の品種** の開発が進んでいます。

| 品種 | 産地 | 特徴 |
|---|---|---|
| 春よ恋（はるよこい） | 北海道 | パン用。もちもちした食感 |
| ゆめちから | 北海道 | 超強力の品種。ほかの小麦とブレンドして使われることが多い |
| キタノカオリ | 北海道 | パン用。黄色みのある生地 |
| はるゆたか | 北海道 | パン用。生産量は少ない |
| きたほなみ | 北海道 | 日本で最も多く作られている小麦の一つ。主にうどん用 |
| ミナミノカオリ | 九州 | パン用 |

## 2-6 そのほかの粉

| 粉 | 特徴 |
|---|---|
| **全粒粉** | 小麦を丸ごと挽いた粉。香ばしく、食物繊維やミネラルが多い。ふすまがグルテンの膜を切るため、**ふくらみにくい** |
| **ライ麦粉** | ライ麦の粉。**グルテンの膜をほとんど作らない** ため、ふくらみにくい。サワー種と組み合わせて使う。酸味と独特の風味 |
| **米粉** | **グルテンを含まない**。パン用米粉には、グルテンを加えたものと、加えないもの（グルテンフリー）がある |
| **スペルト小麦** | 古代小麦の一種 |
| **デュラム小麦（セモリナ）** | パスタの原料。一部のパンにも使われる |

## 2-7 小麦粉の扱い方

- **湿気とにおいを吸いやすい** ので、密閉して涼しい場所に保存します。
- 開封後は早めに使い切ります（夏は虫がわくことも）。
- 使う前に **ふるう** と、ダマがなくなり、空気を含んで混ざりやすくなります（パンではふるわないこともあります）。

> **ここを覚える**
> - 小麦粉になるのは主に胚乳。丸ごと挽くと全粒粉
> - 強力粉（硬質小麦・約11.5〜13.5％）、準強力粉（フランスパン）、薄力粉（軟質小麦）
> - 灰分＝ミネラル。少ないほど白い
> - グルテン＝グルテニン（弾力）＋グリアジン（粘り・伸び）
> - 塩はグルテンを引き締める。砂糖・油脂が多いとグルテンができにくい
> - 1CW（カナダ）＝強力粉の代表的な原料／ライ麦はグルテンの膜をほとんど作らない

# 第3章 イーストと天然酵母

## 3-1 酵母（イースト）とは

- **酵母** は、カビやきのこの仲間（菌類）の **単細胞の微生物** です。
- パンに使われる酵母の多くは、**サッカロマイセス・セレビシエ（Saccharomyces cerevisiae）** という種類です。ビールやワインなどのお酒にも使われる酵母の仲間です。
- **イースト（パン酵母）** は、パン作りに向いた酵母を選び出して、**純粋に大量に培養したもの** です。

## 3-2 酵母の働き ── アルコール発酵

酵母は、生地の中の **糖** を分解して、**炭酸ガス（二酸化炭素）とアルコール** を作ります。これを **アルコール発酵** といいます。

> 糖（ブドウ糖） → 炭酸ガス（二酸化炭素） ＋ アルコール（エタノール）

| 作られるもの | パンへの役割 |
|---|---|
| **炭酸ガス** | グルテンの膜に閉じ込められ、**生地をふくらませる** |
| **アルコール** | パンの **香り** のもと。焼くとほとんどが蒸発する |
| 有機酸など | 香りと **風味**、生地をやわらかくのびやすくする |

### 糖を分解する酵素

酵母は、いろいろな **酵素** を使って、糖を少しずつ分解していきます。

| 酵素 | 働き |
|---|---|
| **アミラーゼ**（主に小麦粉に含まれる） | **でんぷん** を分解して **麦芽糖** にする |
| **マルターゼ**（酵母） | **麦芽糖** を分解して **ブドウ糖** にする |
| **インベルターゼ**（酵母） | **ショ糖（砂糖）** を分解して **ブドウ糖と果糖** にする |
| **チマーゼ**（酵母が持つ酵素群） | **ブドウ糖・果糖** を分解して、**炭酸ガスとアルコール** にする |

> **ポイント**　砂糖を入れないフランスパンでもふくらむのは、**小麦粉のでんぷんがアミラーゼで分解されて糖になり**、それを酵母が使うためです。

## 3-3 酵母が働く条件

| 条件 | 内容 |
|---|---|
| **温度** | 約4℃以下ではほとんど働かない（休眠状態）。**約25〜35℃前後** でよく働き、約40℃を超えると弱り始め、**約60℃前後で死滅** する |
| **栄養（糖）** | 糖が栄養になる。ただし、砂糖が多すぎると、浸透圧で酵母の水分が奪われて働きが悪くなる |
| **水分** | 水がないと働けない |
| **pH** | 弱酸性（約pH4〜6）を好む |
| **塩** | 少量は発酵を穏やかに調整するが、**直接触れたり多すぎたりすると働きが弱まる** |

## 3-4 イーストの種類

| 種類 | 水分 | 特徴 | 使い方 | 保存 |
|---|---|---|---|---|
| **生イースト** | 約65〜70％ | 酵母を固めたもの。**糖の多い生地（菓子パン）でも働きやすい** | 水に溶かして使う、または細かくくずして混ぜる | **冷蔵**。日持ちは短め（数週間程度） |
| **ドライイースト** | 約7〜8％ | 酵母を乾燥させた粒状のもの。独特の香りがある | **予備発酵** が必要（40℃前後のぬるま湯に少量の砂糖を入れて溶かし、10〜15分ほど置いて泡が出るのを確認） | 常温（開封後は密閉して冷蔵） |
| **インスタントドライイースト** | 約5％前後 | 細かい顆粒。**家庭で最も使いやすい** | **粉に直接混ぜられる**（予備発酵不要） | 開封後は密閉して冷蔵・冷凍 |
| 耐糖性インスタントドライイースト | ── | 砂糖が多い生地向き（目安：粉に対して砂糖5％以上など） | 同上 | 同上 |

**量の換算の目安**

> **生イーストの量 ÷ 2 ＝ ドライイーストの量**
> **生イーストの量 × 約3分の1〜2分の1 ＝ インスタントドライイーストの量**

※製品によって違うため、パッケージの表示を確認してください。

**イーストを使うときの注意**

- 計量するとき、**塩や大量の砂糖とイーストを直接触れさせない**（ボウルの中で離して置く）。
- 仕込み水が **熱すぎる（約50℃以上）と、イーストが弱ったり死んだり** する。
- 古いイーストは発酵力が落ちる。賞味期限を確認する。

## 3-5 天然酵母（自家製酵母・発酵種）

**天然酵母** という言葉に厳密な定義はありませんが、一般には、果物や穀物などについている **野生の酵母や乳酸菌などを培養したもの** をいいます。市販のイーストも、もともとは自然界の酵母から選ばれたものです。

| 種類 | 原料・作り方 | 特徴 |
|---|---|---|
| **レーズン酵母** | レーズンと水（と少量の砂糖） | 家庭で起こしやすい。ほのかに甘い香り |
| りんご・いちごなどの果実酵母 | 果物と水 | 果物の香り |
| ヨーグルト酵母 | ヨーグルト | |
| **酒種（さかだね）** | 米と麹（こうじ） | 日本独自の発酵種。**あんパン** で有名 |
| **ルヴァン** | 小麦粉やライ麦粉と水 | フランスの伝統的な発酵種 |
| **サワー種（サワードウ）** | 主にライ麦粉と水 | **乳酸菌が多く、酸味がある**。ドイツのライ麦パン、アメリカのサンフランシスコ・サワードウなど |
| **パネトーネ種** | 小麦粉と水など | イタリアのパネトーネに使われる |
| ホップス種 | ホップの煮汁など | 古くからある発酵種。日本の山型食パンに使われたこともある |
| 市販の天然酵母種 | ホシノ天然酵母、白神こだま酵母など | 品質が比較的安定しており、使いやすい |

### 天然酵母の特徴

| 長所 | 短所 |
|---|---|
| 複数の微生物が働くため、**風味が複雑で深い** | **発酵に時間がかかる** |
| 乳酸菌などによる **ほのかな酸味や旨味** | **温度管理が難しく、品質が安定しにくい** |
| もっちり・しっとりした食感になりやすい | 雑菌が増えるリスクがある（カビ・異臭に注意） |
| 日持ちが良くなることがある | 種を維持する手間（**種継ぎ**）がかかる |

## 3-6 レーズン酵母の起こし方（一例）

1. **瓶を煮沸消毒する**（雑菌を防ぐため、とても大切）。
2. 瓶に、**オイルコーティングされていないレーズン**（約100g）と、水（約200〜300ml）、砂糖少量を入れる。
3. ふたをして、**約25〜28℃** の場所に置く。
4. **1日1〜2回、ふたを開けて空気を入れ替え、瓶を軽く振る**。
5. 数日（約4〜7日）で、レーズンが浮かび、**細かい泡** がたくさん出て、**お酒のような甘い香り** がしたら完成（**酵母液**）。
6. 酵母液と粉を混ぜて発酵させ、**元種（もとだね）** を作ってからパンに使う。
7. 冷蔵庫で保存し、早めに使う。

> **注意**　カビが生えた、腐ったような異臭がする、液がにごって糸を引く、などの場合は、**雑菌が増えているので使わずに捨てます**。

> **ここを覚える**
> - パン酵母＝サッカロマイセス・セレビシエ
> - アルコール発酵：糖 → 炭酸ガス＋アルコール
> - アミラーゼ（でんぷん→麦芽糖）、マルターゼ（麦芽糖→ブドウ糖）、インベルターゼ（ショ糖→ブドウ糖＋果糖）、チマーゼ（→炭酸ガス＋アルコール）
> - 酵母はよく働くのが約25〜35℃前後、約60℃で死滅
> - 生イースト＝冷蔵・菓子パンに強い／ドライ＝予備発酵が必要／インスタント＝直接混ぜる
> - 酒種＝米と麹（あんパン）、ルヴァン＝フランス、サワー種＝ライ麦・乳酸菌・酸味

# 第4章 塩・砂糖・油脂・水・卵・乳製品

## 4-1 塩

| 働き | 説明 |
|---|---|
| **グルテンを引き締める** | 生地にコシと弾力が出る。塩を入れ忘れると、ダレてベタつく生地になる |
| **発酵を調整する** | 酵母の働きを穏やかにし、発酵が進みすぎるのを防ぐ |
| **味を整える** | 塩味で、小麦の風味や甘みが引き立つ |
| 雑菌の繁殖を抑える | ── |

- 使う量は、**粉に対して約1.5〜2％** が一般的です。
- 塩を入れないと、ふくらみすぎて形が崩れ、味がぼやけたパンになります。

## 4-2 砂糖

| 働き | 説明 |
|---|---|
| **酵母の栄養になる** | 発酵を助ける |
| **焼き色をつける** | **メイラード反応**（糖とアミノ酸の反応）や **カラメル化**（糖が焦げる反応）で、こんがりした色と香ばしい香り |
| **しっとりさせる（保水性）** | 水分を抱えるので、しっとりして **硬くなりにくい**（老化を遅らせる） |
| 甘みをつける | ── |

- **多すぎると** 発酵が遅くなり（浸透圧のため）、焼き色が濃くなりすぎます。
- 食パンでは粉に対して約5〜8％、菓子パンでは約15〜25％ほどが目安です。

## 4-3 油脂

| 働き | 説明 |
|---|---|
| **生地の伸びを良くする** | グルテンの間に入り込み、生地がなめらかに伸びる → **ボリュームが出る** |
| **ふんわり・しっとりさせる** | きめが細かく、柔らかくなる |
| **老化を遅らせる** | 水分が抜けにくく、硬くなりにくい |
| 風味をつける | バターの香りなど |

| 種類 | 特徴 |
|---|---|
| バター | 風味が良い。リッチなパンに |
| ショートニング | 植物油などから作る固形油脂。風味はないが、軽くサクッとした食感 |
| マーガリン | バターの代用 |
| オリーブオイル | フォカッチャなど |
| 折り込み用油脂 | クロワッサン・デニッシュ用。のびが良い |

- 固形の油脂は、**グルテンがある程度できてから**（こね始めて数分後）加えるのが一般的です。最初から入れるとグルテンができにくくなります。

## 4-4 水

| 働き | 説明 |
|---|---|
| グルテンを作る | 小麦のたんぱく質と結びつく |
| 酵母を働かせる | 水がないと酵母は働けない |
| でんぷんを糊化させる | 焼くときに水とでんぷんが反応して、柔らかい食感に |
| **生地の温度を調整する** | **仕込み水の温度** で、こね上がりの温度を調整する |

**水の硬度**

- パン作りには、**中程度の硬度（約50〜100mg/L程度）の水** が向くといわれます。
- **軟水すぎる** と、グルテンが弱く、ベタついた生地になりやすい。
- **硬水すぎる** と、グルテンが引き締まりすぎて、硬い生地になり、発酵が遅くなることがある。
- 日本の水道水（多くは軟水）でも、問題なくパンは作れます。

**水の量（吸水）**

- 粉の種類によって、吸う水の量が違います。一般に **たんぱく質が多い粉ほど、水をたくさん吸います**。
- 同じ粉でも、季節や湿度で吸水量が変わるので、**水は一度に全部入れず、少し残して** 様子を見ながら加えるのがコツです。

## 4-5 卵

| 働き | 説明 |
|---|---|
| 風味・色 | 卵黄で生地が黄色っぽく、風味が良くなる |
| ふんわりさせる | 卵黄の **レシチン** の乳化作用で、生地がなめらかでしっとりする |
| ボリューム | 卵白のたんぱく質が焼くと固まり、骨組みを助ける（多すぎると硬く、パサつく） |
| つや出し | **溶き卵を表面に塗る** と、つやのある焼き色になる |

## 4-6 乳製品

| 種類 | 働き |
|---|---|
| 牛乳 | 風味が良くなる。乳糖などで **焼き色がつきやすく** なる。きめが細かくなる |
| **スキムミルク（脱脂粉乳）** | 牛乳の代わりに使える。保存しやすい。風味・焼き色 |
| 生クリーム | リッチな風味 |
| ヨーグルト | しっとり・ほのかな酸味 |

- 牛乳を使うときは、**水の量を減らす**（牛乳の約9割は水分）。

## 4-7 ベーカーズパーセント

パンの配合は、**粉の合計を100％** として、ほかの材料の割合を表すのが一般的です。これを **ベーカーズパーセント（ベーカーズ％）** といいます。

**使い方**

> 材料の重さ ＝ 粉の重さ × その材料のベーカーズ％ ÷ 100

**例：基本の食パン（ベーカーズ％の一例）**

| 材料 | ベーカーズ％ | 粉250gの場合 | 粉1kgの場合 |
|---|---|---|---|
| 強力粉 | 100 | 250g | 1,000g |
| 砂糖 | 6 | 15g | 60g |
| 塩 | 2 | 5g | 20g |
| スキムミルク | 2 | 5g | 20g |
| バター | 5 | 12.5g | 50g |
| インスタントドライイースト | 1〜2 | 2.5〜5g | 10〜20g |
| 水 | 65〜72 | 162.5〜180g | 650〜720g |

**例：パンの種類ごとの配合の傾向（目安）**

| 材料 | フランスパン（リーン） | 食パン | 菓子パン・ロール（リッチ） | ブリオッシュ（とてもリッチ） |
|---|---|---|---|---|
| 粉 | 100（準強力粉） | 100 | 100 | 100 |
| 砂糖 | 0 | 5〜8 | 15〜25 | 10〜15 |
| 塩 | 2 | 2 | 1〜1.5 | 2 |
| 油脂 | 0 | 4〜6 | 10〜15 | 50前後（バター） |
| 卵 | 0 | 0 | 10〜15 | 50前後 |
| 水分 | 65〜70（水） | 65〜72 | 50前後 | 少なめ |

※あくまで傾向を示した目安です。

> **ここを覚える**
> - 塩（約1.5〜2％）＝グルテンを引き締める・発酵を調整する・味
> - 砂糖＝酵母の栄養・焼き色（メイラード反応・カラメル化）・しっとり・老化を遅らせる
> - 油脂＝伸び・ボリューム・ふんわり・老化を遅らせる。グルテンができてから加える
> - 水＝温度調整。中程度の硬度が向くとされる。少し残して様子を見る
> - ベーカーズ％＝粉を100％とする。材料の重さ＝粉の重さ×％÷100

# 第5章 パンの製法

## 5-1 製法の全体像

| 製法 | 一言でいうと |
|---|---|
| **ストレート法（直捏法）** | 全部の材料を一度にこねる |
| **中種法** | 粉の一部で「中種」を先に発酵させる |
| **ポーリッシュ法（液種法）** | 粉と水が1：1の液状の種を先に発酵させる |
| **発酵種法** | 前もって作った発酵種（ルヴァン・酒種・自家製酵母など）を使う |
| **サワー種法** | ライ麦粉などから起こした酸っぱい種を使う |
| 湯種法 | 粉の一部を熱湯でこねた種を使う |
| オーバーナイト法（低温長時間発酵） | 冷蔵庫で一晩発酵させる |
| 冷凍生地法 | こねた生地を冷凍しておく |

## 5-2 ストレート法（直捏法：じかごねほう）

**やり方**　すべての材料を **一度に混ぜてこね**、発酵させて焼きます。

**流れの例**　ミキシング → 一次発酵（約60〜90分） → 分割 → ベンチタイム → 成形 → 最終発酵 → 焼成

| 長所 | 短所 |
|---|---|
| 工程が **シンプルで、時間が短い** | 生地の状態が **温度や環境に左右されやすい** |
| **小麦の風味** が出やすい | 生地が硬くなる（老化）のが比較的早い |
| 家庭や小さなパン屋に向く | 大量生産では品質が安定しにくい |

## 5-3 中種法（なかだねほう）

**やり方**

1. 粉の一部（**一般に50〜100％、70％前後が多い**）・イースト・水で **中種（なかだね）** を作る。
2. 中種を **数時間（約2〜4時間程度）発酵** させる。
3. 中種に残りの粉・塩・砂糖・油脂などを加えて **本ごね** する。
4. 短めのフロアタイム（休ませる時間）の後、分割・成形・最終発酵・焼成。

| 長所 | 短所 |
|---|---|
| 生地がよくのびて **ボリュームが出る**、**ふんわり柔らかい** | **時間と手間がかかる** |
| **硬くなりにくい（老化が遅い）** | 工程が増え、場所や設備も必要 |
| 発酵が安定し、**品質が安定する** → **大量生産** に向く（大手製パン会社の食パンなど） | 小麦の風味はストレート法より穏やかになることがある |
| 本ごねの後の作業の時間調整がしやすい（**作業の融通がきく**） | |

## 5-4 ポーリッシュ法（液種法）

**やり方**

1. 粉と水を **ほぼ同じ量（1：1）** にし、少量のイーストを加えて混ぜ、**液状の種（ポーリッシュ）** を作る。
2. 数時間〜一晩（冷蔵）発酵させる。
3. 残りの材料と合わせてこねる。

- **ポーランド** で生まれ、ウィーンを経てフランスに伝わったとされます（名前は「ポーランドの」という意味）。
- 水分の多い種なので、酵母や酵素がよく働きます。

| 長所 | 短所 |
|---|---|
| **伸びの良い生地** になり、クラム（中身）がしっとり | 種の発酵管理が必要 |
| **香り・風味が豊か** | 前もって種を準備する時間が必要 |
| **ハード系のパン**（バゲットなど）に向く | |
| 本ごねの時間を短くできる | |

## 5-5 発酵種法

**やり方**　前もって発酵させた **発酵種**（ルヴァン、酒種、自家製酵母の元種、前日の生地（オールドドウ）など）を使ってパンを作ります。

| 長所 | 短所 |
|---|---|
| **風味が深く、独特の香りと旨味** | 種の管理（**種継ぎ**）が難しい |
| しっとりして **日持ちが良くなる** ことがある | **発酵に時間がかかる** |
| 発酵種ごとの個性が出る | 品質を安定させるのに経験が必要 |

**関連する言葉**

| 言葉 | 意味 |
|---|---|
| 元種（もとだね） | 酵母液と粉を混ぜて発酵させた種 |
| 種継ぎ（かけ継ぎ） | 種の一部に新しい粉と水を足して、種を維持し続けること |
| **ルヴァン** | フランスの発酵種。小麦粉やライ麦粉と水から起こす |
| **オールドドウ（老麺）** | 前日の生地の一部を、次の日の生地に混ぜる方法 |
| **ビガ** | イタリアの硬めの発酵種 |

## 5-6 サワー種法

**やり方**　主に **ライ麦粉と水** から起こした、**乳酸菌と酵母** を含む **サワー種（サワードウ）** を使います。

- **ライ麦粉はグルテンの膜をほとんど作らない** ため、そのままではふくらみにくく、べたついた生地になります。
- サワー種の **乳酸菌が作る酸** によって、ライ麦の生地の性質が変わり（ライ麦に含まれる酵素の働きを抑えるなど）、**ライ麦パンがうまく焼ける** ようになります。
- **ドイツのライ麦パン**（ロッゲンブロートなど）に欠かせない製法です。

| 長所 | 短所 |
|---|---|
| ライ麦の生地をうまくパンにできる | 種の管理が難しい |
| **酸味と深い風味** | 酸味が強くなりすぎることがある |
| **日持ちが良い** | 時間がかかる |

## 5-7 そのほかの製法

| 製法 | やり方 | 特徴 |
|---|---|---|
| **湯種法** | 粉の一部を **熱湯でこねて**、でんぷんを **糊化（こか）** させた種を作り、冷ましてから生地に混ぜる | **もちもち・しっとり** した食感。甘みが増す。**硬くなりにくい**。前日に湯種を作るなど手間がかかる |
| **オーバーナイト法（低温長時間発酵）** | こねた生地を **冷蔵庫（約5〜10℃程度）で一晩ゆっくり発酵** させる | **風味が良くなる**。イーストの量を減らせる。作業時間を分けられる |
| **冷凍生地法** | こねた生地や成形した生地を冷凍しておく | 必要なときに焼ける。冷凍でイーストが傷みやすいので、冷凍に強いイーストを使う |
| **ノーニード（こねない）** | 水分を多めにして、ほとんどこねず、長時間かけてグルテンを作る | 手軽。気泡の多い生地 |

## 5-8 製法の比較表

| 製法 | 時間 | ボリューム | 風味 | 老化（硬くなる） | 品質の安定 | 向くパン |
|---|---|---|---|---|---|---|
| ストレート法 | 短い | 普通 | 小麦の風味 | 早め | やや不安定 | 家庭のパン全般 |
| 中種法 | 長い | **大きい** | 穏やか | **遅い** | **安定** | 食パン、菓子パン（大量生産） |
| ポーリッシュ法 | やや長い | 大きい | **香り豊か** | 遅め | 普通 | バゲットなどハード系 |
| 発酵種法 | **とても長い** | 種による | **深い** | 遅め | 不安定 | カンパーニュなど |
| サワー種法 | とても長い | 小さめ | **酸味** | 遅め | 不安定 | ライ麦パン |
| 湯種法 | 長い（前日準備） | 普通 | 甘み | **遅い** | 普通 | もちもちの食パン |

## 5-9 リーンなパンとリッチなパン

| | リーン（lean：質素な） | リッチ（rich：豊かな） |
|---|---|---|
| 材料 | **粉・イースト・塩・水** が中心 | **砂糖・油脂・卵・乳製品** が多い |
| 例 | バゲット、カンパーニュ、ベーグル、チャバッタ | ブリオッシュ、菓子パン、クロワッサン、パネトーネ |
| 食感 | 外はパリッ、中はもっちり | ふんわり、しっとり |
| 焼成 | **高温**、蒸気を入れることが多い | 中温〜やや低め（糖分が多く **焦げやすい** ため） |
| 日持ち | 硬くなるのが早い | 比較的しっとりが続く |

> **ここを覚える**
> - ストレート法＝全部一度に（簡単・小麦の風味・老化は早め）
> - 中種法＝粉の一部（50〜100％）で中種→数時間発酵→本ごね（ボリューム・老化しにくい・品質安定・大量生産）
> - ポーリッシュ法＝粉と水1：1の液種（ポーランド発祥、ハード系）
> - 発酵種法＝ルヴァン・酒種など（風味が深い、管理が難しい）
> - サワー種法＝ライ麦・乳酸菌・酸味（ドイツのライ麦パン）
> - 湯種法＝でんぷんを糊化させる（もちもち）

# 第6章 パン作りの工程と発酵

## 6-1 基本の工程（ストレート法）

| 順 | 工程 | 目的 |
|---|---|---|
| 1 | **計量** | 材料を正確に量る |
| 2 | **ミキシング（こねる）** | 材料を均一に混ぜ、グルテンを作る |
| 3 | **一次発酵** | 生地をふくらませ、風味を作り、グルテンをのびやすくする |
| 4 | **パンチ（ガス抜き）** | 大きな気泡を抜き、グルテンを強くする（必要に応じて） |
| 5 | **分割** | 決めた重さに切り分ける |
| 6 | **丸め** | 表面を張らせて、形を整える |
| 7 | **ベンチタイム** | 生地を休ませ、グルテンをゆるめる |
| 8 | **成形** | 最終的な形を作る |
| 9 | **最終発酵（ホイロ）** | 焼く前にもう一度ふくらませる |
| 10 | **焼成** | オーブンで焼く |
| 11 | **冷却** | 網の上で冷ます |

## 6-2 計量

- パンは **材料の割合（配合）** で仕上がりが大きく変わるので、**正確に量る** ことが大切です。
- イーストや塩は少量なので、**0.1g単位** で量れるスケールがあると安心です。
- 計量のときは、**塩・砂糖とイーストが直接触れないように** 離して置きます。

## 6-3 ミキシング（こねる）

**ミキシングの段階**

| 段階 | 生地の状態 |
|---|---|
| ① 混ぜる | 粉と水分が混ざり、ボソボソしている |
| ② まとまる | ひとまとまりになるが、ベタつく。生地を伸ばすとすぐ切れる |
| ③ のびる | グルテンができ始め、表面がなめらかになってくる。油脂はこのころ加える |
| ④ こね上がり | **薄くのばすと、向こうが透けるほどの膜ができる** |

**グルテン膜の確認（ウィンドウテスト）**　生地を少し取り、指で薄く広げます。**破れずに、向こうが透けて見えるほどの薄い膜** ができれば、こね上がりの目安です。

- パンの種類によって、こね方の強さは違います。食パンやロールパンはしっかりこね、**バゲットなどのハード系は、こねすぎない** ことが多いです。
- **こね上げ温度** は、一般的なパンで **約26〜28℃** が目安です（パンの種類によって違います）。

**仕込み水の温度の計算式（一例）**

> 仕込み水温 ＝ 3 ×（目標こね上げ温度 − 摩擦による温度上昇）−（室温 ＋ 粉の温度）

**計算例**　目標こね上げ温度27℃、摩擦による上昇5℃、室温20℃、粉の温度20℃の場合

> 3 ×（27 − 5）−（20 ＋ 20）＝ 3 × 22 − 40 ＝ 66 − 40 ＝ **26℃**

※摩擦による温度上昇は、こね方や機械によって違います。この式は、材料（粉・水・室内の空気）の温度が同じように影響すると考えた簡単な目安です。

- **夏** は冷たい水（場合によっては氷水）、**冬** はぬるめの水を使います。
- 仕込み水が熱すぎるとイーストが弱るので、**一般に40℃程度まで** にとどめます。

## 6-4 一次発酵

| 項目 | 目安 |
|---|---|
| 温度 | 約27〜30℃ |
| 湿度 | 約70〜75％ |
| 時間 | 約40〜90分（製法・配合・イーストの量で大きく変わる） |
| 大きさ | 約2〜2.5倍 |

**発酵の確認（フィンガーテスト）**　指に粉をつけて、生地の中心に第2関節くらいまで差し込み、抜きます。

| 穴の状態 | 判断 |
|---|---|
| **穴がそのまま残る**（または少し戻る） | **ちょうど良い** |
| **穴がすぐに戻ってふさがる** | **発酵不足** → もう少し待つ |
| **生地全体がしぼむ、大きな気泡が抜ける** | **発酵しすぎ（過発酵）** |

**一次発酵中に起こること**

1. 酵母がアルコール発酵をして、**炭酸ガス** を出す → 生地がふくらむ
2. **アルコールや有機酸** などができる → 香りと風味
3. グルテンが **のびやすく** なる（熟成） → 成形しやすくなる
4. 酵素が働き、でんぷんやたんぱく質が分解される → 旨味と、酵母の栄養（糖）

## 6-5 パンチ（ガス抜き）

発酵した生地を **押さえたり、折りたたんだり** して、ガスを抜く作業です。

| 目的 | 説明 |
|---|---|
| きめを細かくする | 大きな気泡をつぶし、小さな気泡を分散させる |
| 酵母を活発にする | 生地の中のガス（炭酸ガス・アルコール）を抜き、新しい空気（酸素）を入れる |
| グルテンを強くする | 生地を折りたたむことで、グルテンが引き締まり、ボリュームが出る |
| 生地の温度を均一にする | 外側と内側の温度差をなくす |

- すべてのパンに必要なわけではなく、配合や製法によって行うかどうかを決めます。

## 6-6 分割・丸め・ベンチタイム

**分割**

- **スケッパー（カード）で、押し切るように切る**（引きちぎるとグルテンが傷つく）。
- スケールで量りながら、**同じ重さ** にそろえます（焼き上がりがそろう）。
- 分割の回数はなるべく少なくします（切り口が増えるとガスが抜ける）。

**丸め**

- 切り口を内側に巻き込むように、表面を **なめらかに張らせて** 丸めます。
- 表面が張っていると、**ガスが抜けにくく**、きれいにふくらみます。
- 強く丸めすぎると、表面が切れてしまいます。

**ベンチタイム**

- 丸めた生地を **約15〜20分** 休ませます（生地の種類によって違う）。
- 丸めて縮んだ（緊張した）**グルテンをゆるめて、成形しやすくする** ための時間です。
- 生地が **乾燥しないよう**、濡れ布巾やビニールをかけます。
- 生地がひと回り大きくなり、押すとゆっくり戻る状態が目安です。

## 6-7 成形

- 生地のガスを軽く抜き、最終的な形を作ります（丸形、なまこ形、ロール、型入れなど）。
- **とじ目をしっかり閉じる**（開くと、焼いたときに割れる）。
- とじ目は **下** にして、天板や型に並べます。

**食パンの型の種類**

| 型 | 焼き方 | 特徴 |
|---|---|---|
| 角食パン（プルマン型） | **ふたをして焼く** | 四角い形。きめが細かく、しっとり |
| 山型食パン（イギリスパン） | **ふたをせずに焼く** | 上が山のようにふくらむ。軽い食感、香ばしい |

## 6-8 最終発酵（ホイロ）

| 項目 | 目安 |
|---|---|
| 温度 | 約35〜38℃（バターを多く折り込むクロワッサン・デニッシュは、**バターが溶けないよう約27〜30℃程度と低め** にする） |
| 湿度 | 約75〜85％ |
| 時間 | 約30〜60分（パンによって違う） |
| 大きさ | 約1.5〜2倍。角食パンは型の8〜9分目、山型食パンは型のふちから少し出るくらいなど |

- **ホイロ** は、最終発酵のことや、そのための発酵器のことをいいます。
- 最終発酵が **不足** すると、ふくらみが悪く、詰まった重いパンになり、表面が割れることがあります。
- 最終発酵が **過剰** だと、焼いたときにしぼむ、酸っぱいにおいがする、焼き色が薄い、などの失敗になります。

> **ここを覚える**
> - こね上げ温度＝約26〜28℃。仕込み水温＝3×（こね上げ温度−摩擦熱）−（室温＋粉温）
> - ウィンドウテスト＝薄く透ける膜でこね上がり
> - 一次発酵＝約27〜30℃・湿度約70〜75％・約2〜2.5倍・フィンガーテスト
> - フィンガーテスト：穴が残る＝適正、すぐ戻る＝不足、しぼむ＝過発酵
> - パンチ＝きめを細かく・酵母を活発に・グルテンを強く
> - ベンチタイム＝約15〜20分、グルテンをゆるめる、乾燥させない
> - 最終発酵（ホイロ）＝約35〜38℃・湿度約75〜85％（クロワッサンは低め）
> - 角食パン＝ふたをする、山型＝ふたをしない

# 第7章 焼成と冷却

## 7-1 焼成の温度と時間（目安）

| パン | 温度（目安） | 時間（目安） | ポイント |
|---|---|---|---|
| 食パン（1斤型） | 約190〜210℃ | 約25〜35分 | |
| ロールパン | 約190〜200℃ | 約10〜13分 | 溶き卵を塗ってつや出し |
| 菓子パン（あんパンなど） | 約190〜200℃ | 約10〜13分 | 焦げやすいので注意 |
| バゲット | 約230〜250℃ | 約20〜30分 | **蒸気（スチーム）** を入れる |
| カンパーニュ | 約220〜240℃ | 約30〜40分 | 蒸気を入れる |
| クロワッサン | 約200〜220℃ | 約15〜20分 | |

※家庭用オーブンでは、機種によって差があります。

**オーブンは必ず予熱** します。パンは、焼き始めの数分間の温度が大切です。

## 7-2 焼いている間に生地の中で起こること

| 生地の温度（目安） | 起こること |
|---|---|
| 約30〜50℃ | 酵母が最後に活発に働き、ガスを出す |
| **焼き始め** | **オーブンスプリング** ── ガスや水蒸気が熱でふくらみ、生地が一気に大きくなる |
| 約50〜60℃前後 | **酵母が死滅** して、発酵が止まる |
| 約60℃前後〜 | でんぷんが水を吸ってふくらみ、柔らかくなる（**糊化（こか）**） |
| 約75℃前後〜 | **たんぱく質（グルテン）が熱で固まり**（熱凝固）、パンの形と骨組みが決まる |
| 約100℃ | 水分が蒸発し、アルコールも抜ける |
| 表面（約150℃以上） | **メイラード反応** と **カラメル化** で、**焼き色** と香ばしい香りがつく（クラスト＝皮ができる） |

**クラストとクラム**

| 言葉 | 意味 |
|---|---|
| **クラスト** | パンの外側の **皮**。焼き色がつき、香ばしい |
| **クラム** | パンの **中身**。気泡のある柔らかい部分 |

## 7-3 ハード系パンの焼き方のポイント

**スチーム（蒸気）を入れる理由**

1. 表面が乾いて固まるのが遅れ、**オーブンスプリングが大きくなる**（ボリュームが出る）
2. 表面の **でんぷんが糊化** して、**皮がパリッと薄く、つやが出る**
3. **クープがきれいに開く**

- 家庭用オーブンでは、焼く前に生地に **霧吹き** をしたり、天板に熱湯を入れたりして蒸気を作ります（やけどに注意）。

**クープ（切り込み）**

- 焼く直前に、**クープナイフ（カミソリ状の刃）** で表面に浅く切り込みを入れます。
- **ふくらむ方向を決めて**、生地が無理に割れるのを防ぎ、見た目を美しくします。
- クープが開いて盛り上がった部分を「**エッジ（耳）**」、開いた部分を「クープ」と呼びます。
- 刃を **寝かせ気味に、迷わず一気に** 入れるのがコツです。

## 7-4 焼き上がりの確認

- **焼き色** が全体についている。
- 底を指で **軽くたたくと、コンコンと乾いた音** がする（ハード系や食パン）。
- 持つと **軽い**（水分が抜けている）。

## 7-5 冷却

- 焼けたら **すぐに型から出し**、**網（ケーキクーラー）の上** で冷まします。
  - 型や天板に置いたままだと、**底に水分がこもって湿り、へこむ** ことがあります。
- 食パンは、焼き上がったら **型ごと台に軽く打ちつけて**（ショックを与えて）、中の蒸気を抜きます。これで、側面がへこむ「**腰折れ（ケービング）**」を防げます。
- **熱いうちに切ると、つぶれてしまう** ので、粗熱が取れてから切ります（中のでんぷんが落ち着くまで待つ）。
- ハード系のパンは、焼き上がりに「パチパチ」と皮にひびが入る音（**パンの歌声**と呼ばれることも）がすることがあります。

> **ここを覚える**
> - オーブンスプリング＝焼き始めに生地が一気にふくらむ
> - 約60℃で酵母が死滅・でんぷんが糊化 → 約75℃でたんぱく質が固まる → 表面でメイラード反応・カラメル化
> - クラスト＝皮、クラム＝中身
> - スチーム＝ボリューム・パリッとした皮・つや・クープが開く
> - クープ＝ふくらむ方向を決める切り込み
> - 焼けたらすぐ型から出して網の上へ。食パンは打ちつけて腰折れ防止

# 第9章 よくある失敗と原因

## 9-1 生地づくり・発酵の失敗

| 失敗 | 主な原因 | 対策 |
|---|---|---|
| **ふくらまない** | イーストの量が少ない・古い・**死んでいる（熱すぎる水）**、塩や砂糖が直接イーストに触れた、発酵不足、こね不足、室温が低い | イーストの鮮度と量を確認、水温を守る、発酵温度を保つ |
| **生地がベタベタする** | 水が多い、こね不足、生地の温度が高い、塩を入れ忘れた | 水を少し残して加える、しっかりこねる |
| **生地が硬い・のびない** | 水が少ない、こねすぎ（グルテンが切れる）、生地の温度が低い | 水を調整する |
| **生地が切れる** | こねすぎ、グルテン不足（薄力粉を使った）、ベンチタイム不足 | ベンチタイムをとる |
| **過発酵** | 発酵時間が長すぎる、温度が高い、イーストが多い | フィンガーテストで確認 |

## 9-2 焼き上がりの失敗

| 失敗 | 主な原因 |
|---|---|
| **表面がシワシワになる・焼いた後にしぼむ** | 過発酵、焼き不足 |
| **焼き色が薄い** | 温度が低い、焼き時間が短い、砂糖が少ない、**過発酵**（糖が酵母に使われすぎた）、生地が乾燥した |
| **焼き色が濃すぎる・焦げる** | 温度が高い、砂糖や乳製品・卵が多い |
| **底が焦げる** | 下火が強い（天板を2枚重ねるなどで対策） |
| **中が詰まって重い** | こね不足、発酵不足、粉が多い・水が少ない |
| **大きな穴（空洞）がある** | 成形でガスを抜けていない、とじ目が甘い、打ち粉が多い |
| **酸っぱいにおいがする** | 過発酵 |
| **アルコール臭が強い** | 過発酵、イーストが多い |
| **食パンの側面がへこむ（腰折れ）** | 焼き不足、蒸気が抜けていない、過発酵 |
| **表面が割れる（予定外の場所）** | 最終発酵不足、とじ目が閉じていない、表面が乾燥した |
| **クープが開かない** | 最終発酵が過剰、切り込みが浅い、蒸気が不足 |
| **パサパサしている** | 焼きすぎ、水分不足、発酵不足 |
| **ハード系の皮が硬すぎる・厚い** | 蒸気が不足、焼き時間が長い、温度が低い |

> **ポイント**　失敗したときは、**「材料（量・鮮度）」「温度（水温・室温・発酵温度・オーブン）」「時間（こね・発酵・焼き）」** の3つの面から原因を考えると、見つけやすくなります。

# 第10章 パンの老化と保存・衛生

## 10-1 パンが硬くなる理由（老化）

- パンが硬くなる主な原因は、**でんぷんの老化** です。
- 焼いたときに水を吸って柔らかくなった（**糊化した**）でんぷんが、時間がたつと **水分を放して、元の硬い状態に近づく** 現象です。
- でんぷんの老化は、**冷蔵庫の温度（約0〜5℃前後）で最も進みやすい** といわれています。
- 一方、**冷凍（約−18℃以下）** すると、老化はほとんど進みません。

**老化を遅らせるもの**

| 要因 | 理由 |
|---|---|
| 砂糖 | 水分を抱える |
| 油脂 | 水分の移動を防ぐ |
| 卵・乳製品 | しっとり感を保つ |
| 中種法・湯種法・発酵種法 | 生地の性質が変わる |
| 冷凍保存 | 老化がほとんど進まない |

## 10-2 パンの保存方法

| 食べる時期 | 保存方法 |
|---|---|
| **その日〜翌日** | **常温**。乾燥しないよう、袋に入れる（焼きたては冷めてから袋へ） |
| **それ以上** | **冷凍保存**。1枚（1個）ずつラップで包み、冷凍用の袋に入れて空気を抜く。2〜3週間程度を目安に食べる |
| 冷蔵庫 | **基本的に避ける**（老化が進みやすい）。ただし、生クリームや総菜を使ったパンは、傷まないよう冷蔵する |

**冷凍したパンの食べ方**

- 食パン ── **凍ったまま** トースターで焼く。
- ロールパン・ハード系 ── 自然解凍してから、霧吹きをしてオーブンで温めると、焼きたてに近くなる。
- 硬くなったパンは、フレンチトースト、ラスク、パン粉、クルトンなどに活用できる。

## 10-3 衛生管理

| ポイント | 内容 |
|---|---|
| 身じたく | 作業前に手を洗う、爪を短くする、髪をまとめる、アクセサリーを外す |
| 手洗い | 卵や生肉などを触った後も手を洗う |
| 道具 | 清潔にし、よく乾かす |
| 自家製酵母 | **カビや異臭がしたら使わない**。瓶は煮沸消毒する |
| 体調 | 下痢や手の傷があるときは、調理を控えるか手袋を使う（ノロウイルス・黄色ブドウ球菌などの食中毒予防） |
| アレルギー | **小麦・卵・乳** はアレルギー表示が義務の「特定原材料」。パンの多くに使われる |

**パンを販売するには**

- パンを作って販売するには、**食品衛生法にもとづく営業許可**（菓子製造業など）が必要です。施設の基準があり、**食品衛生責任者** を置く必要もあります。
- 包装して販売する場合は、**食品表示**（名称・原材料・アレルゲン・期限・保存方法・製造者など）が必要です。
- 詳しい条件は地域によって違うことがあるため、**管轄の保健所** に相談してください。

> **ここを覚える**
> - 老化＝糊化したでんぷんが硬くなる。冷蔵（約0〜5℃）で最も進みやすい
> - 1〜2日は常温、それ以上は冷凍。冷蔵庫は避ける
> - 自家製酵母はカビ・異臭なら使わない
> - 小麦・卵・乳は特定原材料

# 第11章 パン作りの道具

## 11-1 基本の道具

| 道具 | 選び方・使い方 |
|---|---|
| **デジタルスケール** | **0.1g単位** で量れるものだと、イーストや塩も正確に量れる。風袋（容器）の重さを引ける機能が便利 |
| **ボウル** | 大きめのもの（生地が2倍以上にふくらむため）。ステンレスやガラス |

| **めん棒** | 生地をのばす、ガスを抜く。ガス抜き用の凹凸のあるものも |
| **温度計** | 水温・生地の温度を測る。デジタル式が便利 |
| **こね台（パンマット）** | 生地をこねる台。木製・大理石・シリコンなど |
| **霧吹き** | 生地の乾燥を防ぐ、焼成時に蒸気を与える |
| **ケーキクーラー（網）** | 焼いたパンを冷ます |
| タイマー | 発酵・焼成時間を正確に |

## 11-2 発酵・焼成の道具

| 道具 | 使い方 |
|---|---|
| **発酵器（オーブンの発酵機能）** | 発酵温度を一定に保つ。ない場合は、発泡スチロールの箱にお湯を入れたコップを置くなどで代用できる |
| **キャンバス布（パンマット・クーシュ）** | ハード系の生地を最終発酵させるときに使う、厚手の布。ひだを作って生地の形を保つ |

| **クープナイフ** | クープを入れる |
| **スリップピール（移動板）** | 生地を天板やオーブンに移す板 |
| **食パン型** | 1斤型、1.5斤型、2斤型など。角食用はふた付き |
| 天板・オーブンシート | 生地を並べて焼く |
| 刷毛（はけ） | 溶き卵を塗る |

## 11-3 機械
