# 第1章 パンの歴史

## 1-1 世界のパンの歴史

- **古代メソポタミア** ── 小麦などの粉を水で練って焼いた、平たい **無発酵パン** が始まりとされます。
- **古代エジプト** ── 生地を置いておいたら自然に発酵してふくらんだことから、**発酵パン** が生まれたといわれます。
- **古代ギリシャ・ローマ** ── 製粉技術やかまどが発達し、パン職人が専門の職業になりました。
- **中世ヨーロッパ** ── パン職人の組合（ギルド）ができ、地域ごとのパンが発展しました。
- **19世紀** ── 酵母の研究（パスツールが発酵は微生物の働きであることを示した）が進み、工業的にイーストが作られるようになりました。

## 1-2 日本のパンの歴史

| 年代 | 出来事 |
|---|---|
| 1543年ごろ | ポルトガル人が種子島に来航。パンが伝わる。「パン」はポルトガル語の **pão** が語源 |
| 江戸時代 | 鎖国やキリスト教の禁止で、パンはほとんど広まらなかった |
| 1842年 | **江川太郎左衛門（江川英龍）** が兵糧（保存食）としてパンを焼いた。「**パン祖**」と呼ばれる。これにちなんで **4月12日が「パンの日」**（毎月12日も「パンの日」） |
| 1869年 | 木村安兵衛が東京で「文英堂」（のちの **木村屋**）を開業 |
| 1874年 | 木村屋が酒種を使った **あんパン** を発売 |
| 1875年 | 明治天皇に桜の花の塩漬けをのせた「桜あんパン」を献上したと伝えられる |
| 1904年 | 新宿中村屋がクリームパンを発売したとされる |
| 戦後 | 学校給食でパンが広まり、家庭の食卓にも定着 |

> **ここを覚える**
> - パンの語源＝ポルトガル語の pão
> - パン祖＝江川太郎左衛門（1842年）→ 4月12日はパンの日
> - あんパン＝木村屋（1874年）、酒種を使用

# 第2章 パンの材料とその働き

パン作りの基本材料は **小麦粉・イースト（酵母）・塩・水** の4つです。これに砂糖・油脂・卵・乳製品などの **副材料** が加わります。

## 2-1 小麦粉

| 種類 | たんぱく質の量（目安） | 原料の小麦 | 主な用途 |
|---|---|---|---|
| 強力粉 | 約11.5〜13.5％ | 硬質小麦 | 食パン、菓子パン |
| 準強力粉 | 約10.5〜12％ | 硬質小麦など | フランスパン（バゲット） |
| 中力粉 | 約8〜10.5％ | 中間質小麦 | うどん、一部のパン |
| 薄力粉 | 約6.5〜9％ | 軟質小麦 | お菓子、天ぷら |

※数値は一般的な目安で、メーカーや製品によって違います。

**グルテンのしくみ**

小麦粉に水を加えてこねると、2つのたんぱく質が結びついて **グルテン** ができます。

- **グルテニン** ── 弾力（ゴムのように元に戻る力）
- **グリアジン** ── 粘り・伸び（のびる力）

グルテンは、イーストが出した **炭酸ガスを風船のように閉じ込めて**、パンをふくらませる役割をします。たんぱく質が多い強力粉ほど、グルテンがたくさんできます。

**そのほかの粉**

- **全粒粉** ── 小麦を丸ごと挽いた粉。香ばしく栄養が多いが、ふくらみにくい
- **ライ麦粉** ── グルテンがほとんどできないため、ふくらみにくい。サワー種と組み合わせて使う
- **米粉** ── グルテンを含まない。パン用米粉にはグルテンを加えたものもある
- **灰分（かいぶん）** ── 小麦粉に含まれるミネラルの量。多いほど色が濃く、風味が強くなる

## 2-2 イースト（酵母）

イースト（パン酵母）は、生地の中の **糖を分解して、炭酸ガスとアルコールを作る** 微生物です。この炭酸ガスでパンがふくらみ、アルコールなどが香りのもとになります。

| 種類 | 特徴 | 使い方 |
|---|---|---|
| 生イースト | 水分を多く含む。冷蔵保存で、日持ちは短め | 水に溶かして使う。菓子パンなど甘い生地に強い |
| ドライイースト | 乾燥させた粒状 | **予備発酵** が必要（40℃前後のぬるま湯に少量の砂糖を入れて溶かし、泡が出るまで待つ） |
| インスタントドライイースト | 細かい顆粒 | **粉に直接混ぜられる**。家庭で最も使いやすい |

- 換算の目安：**生イーストの量の約半分がドライイースト、約3分の1〜半分がインスタントドライイースト**（製品によって違うため、表示を確認する）
- イーストが元気に働くのは **約28〜35℃前後**。**約60℃前後で死滅** します。
- 塩や大量の砂糖に直接触れると働きが弱くなるため、計量のときは離して置くと安心です。

## 2-3 天然酵母（自家製酵母）

果物や穀物などについている酵母や乳酸菌などを培養したものです。

- **自家製酵母** ── レーズン、りんご、ヨーグルトなどから起こす
- **市販の天然酵母** ── ホシノ天然酵母、白神こだま酵母など
- **酒種** ── 米と麹から作る日本独自の酵母（あんパンで有名）
- **ルヴァン** ── 小麦粉やライ麦粉と水から起こすフランスの発酵種
- **サワー種** ── ライ麦粉から起こす。乳酸菌が多く酸味がある

**天然酵母の特徴**　複数の微生物が働くため、**風味が複雑で深い** 一方、**発酵に時間がかかり、温度管理が難しい** という面があります。

## 2-4 塩・砂糖・油脂・水・卵・乳製品

| 材料 | 主な働き |
|---|---|
| 塩（粉に対して約1.5〜2％） | **グルテンを引き締めてコシを出す**、発酵のスピードを調整する、味を整える |
| 砂糖 | イーストの栄養になる、**焼き色をつける**（メイラード反応・カラメル化）、しっとりさせる、パンを硬くなりにくくする |
| 油脂（バター・ショートニングなど） | 生地の **伸びを良くする**、ふんわり・しっとりさせる、**硬くなる（老化）のを遅らせる** |
| 水 | グルテンを作る、イーストを働かせる。**中程度の硬度** の水が向くとされる。水温で生地の温度を調整する |
| 卵 | 風味・色・栄養。卵黄は生地をしっとり、ふんわりさせる |
| 乳製品（牛乳・スキムミルク） | 風味が良くなる、焼き色がつきやすくなる |

## 2-5 ベーカーズパーセント

パンの配合は、**粉の合計を100％** として、ほかの材料の割合を表すのが一般的です。これを **ベーカーズパーセント** といいます。

**例：基本の食パン（ベーカーズパーセントの一例）**

| 材料 | ％ | 粉250gの場合 |
|---|---|---|
| 強力粉 | 100 | 250g |
| 砂糖 | 6 | 15g |
| 塩 | 2 | 5g |
| スキムミルク | 2 | 5g |
| バター | 5 | 12.5g |
| インスタントドライイースト | 1〜2 | 2.5〜5g |
| 水 | 65〜72 | 162.5〜180g |

> **ここを覚える**
> - グルテン＝グルテニン（弾力）＋グリアジン（粘り・伸び）
> - イースト：糖 → 炭酸ガス＋アルコール。約60℃で死滅
> - ドライイースト＝予備発酵が必要、インスタント＝直接混ぜる
> - 塩＝グルテンを引き締める、砂糖＝焼き色・栄養、油脂＝伸び・老化防止
> - ベーカーズパーセント＝粉を100％とする

# 第3章 パンの製法

## 3-1 製法の一覧

| 製法 | やり方 | 長所 | 短所 |
|---|---|---|---|
| **ストレート法（直捏法）** | すべての材料を一度に混ぜてこねる | 工程が簡単で時間が短い。小麦の風味が出やすい | 生地の状態が環境に左右されやすく、硬くなるのが早め |
| **中種法** | 粉の一部（多くは50〜100％）・イースト・水で **中種** を作って数時間発酵させ、残りの材料と合わせて本ごねする | ふんわりとボリュームが出る。硬くなりにくい。品質が安定し、大量生産に向く | 時間と手間がかかる |
| **ポーリッシュ法（液種法）** | 粉と水を **ほぼ1：1** にし、少量のイーストを加えた液状の種を作って発酵させる。ポーランドが発祥とされる | 伸びの良い生地になり、香りが豊か。ハード系パンに向く | 種の発酵管理が必要 |
| **発酵種法** | 前もって発酵させた種（ルヴァン、酒種、自家製酵母など）を使う | 風味が深く、日持ちが良くなることも | 種の管理が難しく、時間がかかる |
| **サワー種法** | ライ麦粉と水から起こした **乳酸菌と酵母を含む酸っぱい種** を使う。ドイツのライ麦パンに多い | ライ麦の生地をふくらみやすくし、酸味と風味が出る | 酸味が強くなりすぎることがある。管理が難しい |
| **湯種法** | 粉の一部を熱湯でこねて、でんぷんを **糊化** させた種を使う | もちもち・しっとりした食感。硬くなりにくい | 前日に湯種を作るなど手間がかかる |
| **オーバーナイト法（低温長時間発酵）** | 生地を冷蔵庫で一晩ゆっくり発酵させる | 風味が良くなる。作業時間を分けられる | 温度管理に慣れが必要 |
| **冷凍生地法** | こねた生地や成形した生地を冷凍しておく | 必要なときに焼ける | イーストが傷みやすい |

## 3-2 リーンなパンとリッチなパン

| | リーン（lean：質素な） | リッチ（rich：豊かな） |
|---|---|---|
| 材料 | 粉・イースト・塩・水が中心 | 砂糖・油脂・卵・乳製品が多い |
| 例 | バゲット、カンパーニュ、ベーグル | ブリオッシュ、菓子パン、クロワッサン |
| 食感 | 外はパリッ、中はもっちり | ふんわり、しっとり |
| 焼成 | 高温、蒸気を入れることが多い | 中温〜やや低め（焼き色がつきやすいため） |

> **ここを覚える**
> - ストレート法＝全部一度に（簡単・風味）
> - 中種法＝中種を先に発酵（ふんわり・老化しにくい・安定）
> - ポーリッシュ法＝粉と水1：1の液種（ポーランド発祥）
> - サワー種法＝ライ麦・乳酸菌・酸味

# 第4章 発酵のしくみとパン作りの工程

## 4-1 基本の工程（ストレート法）

1. **計量** ── 材料を正確に量る（パンはお菓子と同じく計量が大切）
2. **ミキシング（こねる）** ── グルテンを作る
3. **一次発酵** ── 生地を休ませてふくらませる
4. **パンチ（ガス抜き）** ── 必要に応じて行う
5. **分割** ── 決めた重さに切り分ける
6. **丸め** ── 表面を張らせて丸くする
7. **ベンチタイム** ── 生地を休ませる
8. **成形** ── 形を作る
9. **最終発酵（ホイロ）** ── もう一度ふくらませる
10. **焼成** ── オーブンで焼く
11. **冷却** ── 網の上で冷ます

## 4-2 ミキシング

- 生地を薄くのばしたとき、**向こうが透けて見えるほどの膜（グルテン膜）** ができれば、こね上がりの目安です（ウィンドウテスト）。
- **こね上げ温度** は、一般的なパンで **約26〜28℃** が目安です。
- 生地の温度は **水の温度で調整** します。夏は冷たい水、冬はぬるめの水を使います。

**仕込み水の温度の計算式（一例）**

> 仕込み水温 ＝ 3 ×（目標こね上げ温度 − 摩擦による温度上昇）−（室温 ＋ 粉の温度）

※摩擦による温度上昇は、こね方や機械によって違います。

## 4-3 一次発酵

| 項目 | 目安 |
|---|---|
| 温度 | 約27〜30℃ |
| 湿度 | 約70〜75％ |
| 時間 | 約40〜60分（製法・配合で大きく変わる） |
| 大きさ | 約2〜2.5倍 |

**フィンガーテスト**　粉をつけた指を生地に差し込んで抜き、

- 穴がそのまま残る → **ちょうど良い**
- 穴がすぐ戻る → **発酵不足**
- 生地全体がしぼむ → **発酵しすぎ（過発酵）**

## 4-4 発酵のしくみ

- イーストが糖を分解して **炭酸ガス（二酸化炭素）とアルコール** を作ります（**アルコール発酵**）。
- 炭酸ガスはグルテンの膜に閉じ込められ、生地がふくらみます。
- アルコールや有機酸は、パンの **香り** や **風味** のもとになります。
- 発酵中にグルテンがゆるみ、生地が **のびやすく** なります。

## 4-5 パンチ（ガス抜き）

発酵した生地を押さえたり折りたたんだりして、ガスを抜く作業です。

- 大きな気泡をつぶして **きめを細かくする**
- 新しい空気を入れて **イーストを活発にする**
- グルテンを **強くする**

## 4-6 分割・丸め・ベンチタイム・成形

- **分割** ── スケッパーで、**引きちぎらずに切る**（グルテンを傷めないため）。
- **丸め** ── 表面をなめらかに張らせ、ガスを抜けにくくする。
- **ベンチタイム（約15〜20分）** ── 丸めて縮んだグルテンをゆるめ、**成形しやすくする**。乾燥しないように布やラップをかける。
- **成形** ── とじ目をしっかり閉じる。

## 4-7 最終発酵（ホイロ）

| 項目 | 目安 |
|---|---|
| 温度 | 約35〜38℃（バターを多く折り込むクロワッサンなどは、バターが溶けないよう低めにする） |
| 湿度 | 約75〜85％ |
| 大きさ | 約1.5〜2倍 |

## 4-8 焼成

| パン | 温度（目安） | 時間（目安） |
|---|---|---|
| 食パン（1斤型） | 約190〜210℃ | 約25〜35分 |
| ロールパン | 約190〜200℃ | 約10〜13分 |
| バゲット | 約230〜250℃（蒸気あり） | 約20〜30分 |

**焼いている間に生地の中で起こること**

1. **オーブンスプリング** ── 焼き始めに、ガスがふくらみ、イーストが最後に活発に働いて、生地が一気にふくらむ
2. 約60℃前後で **イーストが死滅** し、でんぷんの **糊化（こか）** が始まる
3. 約75℃前後で **たんぱく質（グルテン）が固まり**、パンの形が決まる
4. 表面では **メイラード反応** と **カラメル化** で焼き色と香ばしい香りがつく

**ハード系パンのポイント**

- **スチーム（蒸気）** を入れると、表面が乾くのが遅れて大きくふくらみ、皮がパリッと薄くつやが出ます。
- **クープ** ── 表面に入れる切り込み。ふくらむ方向を決め、見た目を良くします。

## 4-9 冷却

- 焼けたらすぐに型から出し、**網の上** で冷ます（底が湿気るのを防ぐ）。
- 食パンは、焼き上がったら **型ごと台に軽く打ちつけて** 中の蒸気を抜くと、側面がへこむ「腰折れ」を防げます。
- 熱いうちに切ると、つぶれてしまいます。粗熱が取れてから切ります。

> **ここを覚える**
> - こね上げ温度＝約26〜28℃、水温で調整
> - 一次発酵＝約27〜30℃、約2〜2.5倍、フィンガーテスト
> - ベンチタイム＝グルテンをゆるめる（約15〜20分）
> - 最終発酵（ホイロ）＝約35〜38℃、湿度高め
> - 焼成：オーブンスプリング → 糊化 → たんぱく質凝固 → 焼き色

# 第5章 パンの種類

| パン | 国 | 特徴 |
|---|---|---|
| 食パン | 日本（英国・米国の型焼きパンが元） | ふたをして焼く角食パン、ふたをしない山型食パン |
| バゲット | フランス | 「棒」の意味。粉・塩・水・イーストのリーンな配合。クープが特徴 |
| バタール | フランス | 「中間」の意味。バゲットより太く短い |
| ブール | フランス | 「ボール」の意味。丸い形 |
| カンパーニュ | フランス | 「田舎」の意味。ライ麦や全粒粉、発酵種を使うことが多い |
| クロワッサン | フランス（起源はオーストリアとする説も） | 生地にバターを **折り込んで** 層を作る |
| ブリオッシュ | フランス | バター・卵をたっぷり使ったリッチなパン |
| パン・ド・ミ | フランス | フランスの食パン |
| ロッゲンブロート | ドイツ | ライ麦パン。サワー種を使う |
| プレッツェル | ドイツなど | 焼く前に **アルカリ性の液（ラウゲン）** にくぐらせ、独特の色と風味を出す |
| シュトーレン | ドイツ | ドライフルーツ・ナッツ入りのクリスマスの菓子パン |
| フォカッチャ | イタリア | オリーブオイルを使った平たいパン |
| チャバッタ | イタリア | 「スリッパ」の意味。水分が多く、大きな気泡がある |
| グリッシーニ | イタリア | 細長いスティック状 |
| パネトーネ | イタリア | パネトーネ種を使ったクリスマスのパン |
| ベーグル | 東欧・ユダヤ系、米国で普及 | 焼く前に **茹でる**。もっちりした食感 |
| イングリッシュマフィン | イギリス | コーングリッツをまぶし、型で焼く |
| ナン | インドなど | タンドール（窯）の内側に貼りつけて焼く |
| ピタ | 中東 | 中が空洞になるポケットパン |

> **ここを覚える**
> - バゲット＝棒、バタール＝中間、ブール＝ボール、カンパーニュ＝田舎
> - ベーグル＝茹でる、プレッツェル＝アルカリ液、クロワッサン＝バターを折り込む

# 第6章 よくある失敗と原因・パンの保存

## 6-1 失敗と原因

| 失敗 | 主な原因 |
|---|---|
| ふくらまない | イーストの量が少ない・古い・死んでいる（熱すぎる水）、塩が直接イーストに触れた、発酵不足、こね不足 |
| 生地がベタベタする | 水が多い、こね不足、生地の温度が高い |
| 表面がシワシワになる・しぼむ | 過発酵 |
| 焼き色が薄い | 温度が低い、焼き時間が短い、砂糖が少ない、過発酵（糖が使われすぎた） |
| 焼き色が濃すぎる | 温度が高い、砂糖や乳製品が多い |
| 底が焦げる | 下火が強い（天板を2枚重ねるなどで対策） |
| 中が詰まって重い | こね不足、発酵不足、粉が多い |
| 酸っぱいにおいがする | 過発酵 |
| 食パンの側面がへこむ（腰折れ） | 焼き不足、蒸気が抜けていない、過発酵 |

## 6-2 パンの老化と保存

- パンが硬くなるのは、主に **でんぷんの老化**（糊化したでんぷんから水分が抜けて、硬くなる現象）が原因です。
- でんぷんの老化は、**冷蔵庫の温度（約0〜5℃）で最も進みやすい** といわれています。
- そのため、パンは **冷蔵庫に入れない** のが基本です。
  - 1〜2日で食べる → 常温（乾燥しないよう袋に入れる）
  - それ以上 → **冷凍保存**（1枚ずつラップで包み、冷凍用の袋へ）
- 冷凍したパンは、自然解凍するか、凍ったままトーストします。

## 6-3 衛生管理

- 作業前に手を洗い、爪を短くし、髪をまとめる。
- 道具は清潔にし、よく乾かす。
- 自家製酵母は、カビや異臭がしたら使わない。
- 販売する場合は、食品衛生法にもとづく **営業許可** などが必要です（詳しくは保健所に確認）。

## ○×問題

| 番号 | 解答 | 解説 |
|---|---|---|
| 1 | ○ | 強力粉は約11.5〜13.5％、薄力粉は約6.5〜9％ |
| 2 | × | 予備発酵が必要なのは **ドライイースト**。インスタントは粉に直接混ぜられる |
| 3 | ○ | 焼成中に死滅し、発酵が止まる |

| 10 | ○ | 茹でることで、もっちりした食感とつやが出る |
