# 型紙メーカー(簡易原型作成ツール)

採寸値(身長・バスト・ウエストなど)を入力すると、ブラウザ上で
「身頃原型」「袖原型」「スカート原型」「ワンピース原型」の4種類の基本パターンを
その場で作図する静的Webツールです。サーバーやビルド不要、`index.html` を
開くだけで動きます。すべて採寸比率にもとづく自作の計算式で作図しており、
特定サイト・書籍の型紙データを取り込んだものではありません。

## 使い方

1. `pattern-maker/index.html` をブラウザで開く(VSCodeなら「Live Server」拡張で開くのがおすすめ)
2. 左側「1. 採寸値」に自分の(またはお客様の)採寸値をcmで入力する
   - 「背丈」「肩幅」「首周り」「袖丈」「二の腕周り」は実測できない場合、
     隣の「自動」ボタンを押すと身長・バストから目安値を計算します
3. 「2. ゆとり量」でフィット感を選ぶ(フィット / レギュラー / ゆったり)。
   数値を直接編集して細かく調整することもできます
4. 画面上部のタブで「身頃原型 / 袖原型 / スカート原型 / ワンピース原型」を
   切り替えて確認する
   - スカート・ワンピースは「ストレート」「Aライン」を選べます
   - ワンピースは身頃とスカートをウエストで切り替えず一続きに製図したもので、
     バスト~ヒップの寸法差はウエスト位置を中心に上下へ紡錘形(両端がとがった形)に
     とがる1本の内部ダーツ(生地の中で完結し、端まで切り込まないダーツ)で
     吸収しています
5. 気に入った型紙ができたら:
   - **印刷する(実寸・A4分割)**: 実物大でA4用紙に分割印刷します
   - **SVGをダウンロード**: 実寸のSVGファイルとして保存します(Illustrator等でも開けます)
   - **採寸値を保存(JSON)**: 入力した数値を保存し、後で「採寸値を読み込む」で復元できます

## 印刷して型紙をつなげる手順

1. 「印刷する」ボタンを押すとブラウザの印刷ダイアログが開きます
2. **重要:** 印刷設定の「拡大縮小」を必ず **「なし」または「100%」** にしてください
   (「用紙に合わせる」のままだと実寸になりません)
3. 印刷後、1ページ目の左下にある「100mm定規」を実際に定規で測り、
   ちょうど100mmになっているか確認してください。ずれている場合は印刷倍率を見直してください
4. 各ページの左上に「行-列」の番号が書かれています。この番号順に並べ、
   ページ同士が重なっている部分(のりしろ)をテープで貼り合わせてください

## PDF型紙トレース(`trace.html`)

お手持ちの型紙PDF(適法に入手したもの)をブラウザに読み込んで、その上を実際に
なぞることで、印刷・SVG書き出しができる型紙データに変換できるツールです。
`pattern-maker/index.html` 右上の「📄 PDF型紙トレース →」から開けます。

1. 「PDFファイルを選択」でPDFを読み込む(複数ページも可)
2. 「ページ配置」モードでページをドラッグし、位置を合わせる
   (1ページに収まる型紙ならそのままでOK)
3. 「トレース」モードに切り替え、なぞりたい線に沿ってクリックで点を打っていく。
   始点の近くをもう一度クリックすると自動的に輪郭が閉じます
4. 「このパーツを確定する」で1パーツ完成、必要な数だけ繰り返す
5. 「印刷する(実寸・A4分割)」または「SVGをダウンロード」で書き出す

**重要な仕組みと注意点:**

- 読み込んだPDFはこの端末のブラウザ内(JavaScript)だけで処理され、
  どこにも送信・保存されません。ページを閉じれば消えます
- 書き出されるSVG/印刷データには、**あなたが手でなぞった線(座標データ)のみ**が
  含まれます。元のPDFの画像そのものは出力に含まれません
- 多くの型紙PDFは実寸(100%)で作られているため、PDFのページサイズから
  自動的に正しい実寸(mm)で表示されます。印刷して定規で測りズレがある場合のみ、
  「実寸を校正する」で既知の長さの線を2点クリックして補正してください
- PDF表示には [pdf.js](https://mozilla.github.io/pdf.js/)(Mozilla, Apache License 2.0)を
  `vendor/pdfjs/` に同梱しています

## この型紙について(重要)

ここで生成される型紙は、一般的な採寸比率にもとづく**簡易的な近似式**による
「たたき台」の原型です。特定の書籍・スクール・ブランドの製図法をそのまま
再現したものではありません。体型には個人差が大きいため、以下の手順を
おすすめします。

1. まずは安価な布(シーチンなど)で仮縫いする
2. 実際に着用してフィット感を確認する
3. ダーツの位置・分量や着丈などを、必要に応じて手直しする

とくに以下の点は簡易版であることにご注意ください。

- ダーツはバスト・ウエストのみを考慮した基本的な配置です(肩ダーツ・エルボーダーツなどは含みません)
- 縫い代線(赤い破線)は輪郭を均等オフセットした概算表示です。カーブが強い部分(アームホールなど)では
  多少歪む場合があるため、最終的な裁断線は必ず目視で確認してください
- パンツ原型は現バージョンでは未対応です
- ワンピースの前後の脇線の長さ(アームホール下から裾まで)は、厳密には
  完全一致しない場合があります。仮縫い時に脇線の長さを突き合わせて微調整してください

## ファイル構成

```
pattern-maker/
├── index.html         型紙メーカー本体(採寸から作図)
├── trace.html          PDF型紙トレースツール
├── css/
│   ├── style.css       共通デザイン
│   └── trace.css        トレースツール用の追加スタイル
├── vendor/pdfjs/         PDF表示用ライブラリ(pdf.js, Apache License 2.0)
└── js/
    ├── geometry.js     ベクトル計算・曲線サンプリング・縫い代オフセットの共通処理
    ├── drafts.js       採寸値から各パーツの輪郭を計算する製図ロジック
    ├── render.js        SVG描画(型紙メーカー・トレースツール共通)
    ├── print.js         実寸印刷(A4分割・タイル計算、共通)
    ├── export.js        SVGダウンロード・採寸データの保存/読込(共通)
    ├── app.js           型紙メーカーの画面操作(フォーム・タブ・ボタン)
    └── trace.js          PDF読み込み・配置・トレース操作の制御
```

## エラーが出たときの考え方(初心者向け)

- 型紙が真っ白 / 表示されない → ブラウザの開発者ツール(F12)の「Console」タブで
  赤字のエラーを確認してください。`Failed to load resource` はファイルパスの
  タイプミス(大文字小文字違いなど)が多い原因です。
- 数値を入力しても形が変わらない → 入力欄が空になっていないか確認してください
  (空欄のまま他の欄をクリックすると 0 として扱われ、形が崩れることがあります)。
- 印刷した型紙のサイズが合わない → 印刷ダイアログの「拡大縮小」設定を確認し、
  「100mm定規」で実測してください。
